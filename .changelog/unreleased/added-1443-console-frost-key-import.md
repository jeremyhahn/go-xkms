- **Web console FROST Key Import view.** `#/frost/import` (nav: Keys & Crypto, shown where FROST is wired and the identity holds `keys:import`) imports a participant's FROST key package pasted as JSON through `POST /api/v1/frost/keys/import`, and looks up a key's algorithm, threshold, participant id and group public key through `GET /api/v1/frost/keys/{id}`. The pasted package and its secret share are cleared after each import attempt and never shown.
