- **A listener serving an operator `tls.cert_file` accepts the first-boot administrator certificate.** Without `tls.server_cn`, the REST listener advertised only the operator's `ca_file` and `client_cas` as client CAs, so TLS clients held back the administrator certificate issued by the embedded CA and admin calls failed with "no client certificate provided". Once the CA composes, the listener's client-CA pool now also holds the CA's bundle, and the operator's certificate keeps serving. Client certificates are still verified against that pool.
