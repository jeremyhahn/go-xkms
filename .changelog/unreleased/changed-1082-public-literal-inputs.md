- **`scripts/check-public-literals.sh` reads its pattern list from an input.** The script holds no pattern of its own: it takes `class<TAB>regex` lines (the format of the CI `Releasability (private patterns)` step) from `RELEASABILITY_PATTERNS`, or from the file named by `RELEASABILITY_PATTERNS_FILE`, and exits 2 naming both variables when neither is set or the list is malformed. `make check-public-literals` (and so `make lint-gates`) skips with a notice when neither variable is set. Its test uses a synthetic pattern list. Test fixtures and the certificate-authority user guide use documentation address ranges (RFC 5737) and neutral node names. The advisory `qwen-review.yml` workflow is removed (ruling 1132).
