- **An archive outage no longer reddens a CI image build.** Every stage of the images under `build/docker/` that runs `apt-get` (the devcontainer `Dockerfile`'s tools, native, base, toolchain and devcontainer stages, `Dockerfile.softfido` and `Dockerfile.virt-piv`) now installs one shared apt configuration, `build/docker/devcontainer/apt-retries.conf`, before its first `apt-get`, or inherits it from the stage it is built `FROM`. It retries each failed fetch ten times with exponential backoff capped at 60 s and bounds each connect and stalled transfer at 30 s, replacing the five-retry setting the devcontainer `Dockerfile` wrote inline in three stages. The file is a `TOOLCHAIN_INPUTS` entry, so changing it rebuilds the toolchain image. New `internal/buildgates/apt_test.go` (`make test-buildgates`) fails a Dockerfile apt layer that runs before the shared file is installed, sets apt options inline, splits `apt-get update` from the install or installs recommends, and fails the shared file when a retry or timeout setting is missing or disabled. Refs #342.
