- **Tenant creation refuses an ID that is not a SPIFFE trust-domain name.** `CreateTenant` on the admin service now refuses a tenant ID outside the trust-domain grammar (lowercase letters, digits, `.`, `-`, `_`; at most 255 bytes) as a malformed input error on field `id`, before go-qrdb records the tenant. Such a tenant could never hold an SVID; the refusal used to surface only at its first issuance.
