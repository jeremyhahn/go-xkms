- **Confidential-VM provider (#2380, ruling 1234)** — go-enclave's `backends/confidentialvm` moved into go-xkms with its history as `pkg/enclaveprovider/confidentialvm`, a package of the root module: `NewAttester` returns an Attester whose `Attest` reads an SEV-SNP report or TD quote over the Linux configfs-tsm report interface, and `NewKeyProtector` returns an SEV-SNP derived-key `enclave.KeyProtector` (`ModePerOperation`) over /dev/sev-guest, sealing under AES-256-GCM with the firmware-derived key. It builds on go-xkms's go-enclave v0.8.0-alpha with a package-local `Evidence` and `ErrInvalidNonce`; hardware tests run in an SNP guest with `-tags confidentialvm_hardware`, and the design is `docs/plans/2380.md`. The key protector seals with the random-nonce GCM construction (`cipher.NewGCMWithRandomNonce`, usable in FIPS 140-only mode) and builds it inside `runtime/secret.Do` under `GOEXPERIMENT=runtimesecret`.
