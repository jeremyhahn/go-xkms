- **A same-repo pull request builds its CI images once, on the pool, and a hung apt fetch fails in minutes.** When main has not published the toolchain or integration image for a pull request's content, `ci-images` now builds each one once on the self-hosted docker pool and pushes it to the in-network pool registry (`scripts/ci-registry.sh pool`); consumer jobs pull it by digest instead of each running `make docker-build-toolchain`. Every Dockerfile `apt-get` runs under `timeout 300`, and each "Take the toolchain image" step is bounded at 30 minutes, so a stalled fetch from the apt cache no longer holds a job for hours (#2299). Main and fork pull requests keep the GHCR path.
