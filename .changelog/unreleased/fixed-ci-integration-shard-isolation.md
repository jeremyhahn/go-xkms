CI: `make clean-test-containers` no longer runs `docker image prune -f` and `docker builder prune -f`. Both act on the whole Docker daemon, and each of the six Integration shards on one runner host ran them at its start and teardown, breaking another shard's `compose build` mid-bake (run 76161, shards 2 and 5). The cleanup now only tears down this shard's own compose projects (#1870).
