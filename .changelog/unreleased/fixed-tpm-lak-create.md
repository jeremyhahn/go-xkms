- **`xkey tpm lak create` names the missing enrolment instead of failing with TPM_RC_HANDLE** -- after `xkey tpm provision` the LAK's parent, the Platform SRK, is not yet enrolled (provision creates only the TCG-default EK and SSRK plus the IAK; the xkey setup wizard enrolls the Platform SRK with the user PIN). `lak create` now checks for it first and returns `ErrLAKPlatformSRKNotEnrolled`, naming the setup wizard. Two `CreateLAK` bugs behind that error are fixed too: a TPM opened without a key backend (the xkey CLI) panicked staging the LAK's blobs and now stages them in scratch memory, and `--force` failed with TPM_RC_NV_DEFINED because the existing LAK was never evicted before its replacement was persisted.
