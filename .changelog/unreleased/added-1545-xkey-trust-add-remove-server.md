- **`xkey trust add` and `xkey trust remove` use the server's trust-root store in server mode.** With an xkmsd endpoint configured, `trust add` imports the PEM roots through `TrustRootImport` (with `--purpose` and `--source`; no purpose lets the server classify) and `trust remove` deletes through `TrustRootRemove`. Neither touches the local store in server mode and neither falls back to it; without an endpoint both work on the local store as before.
