- **The tenant release signing key signs release CoRIMs and images, and a tenant can name another key per repository.** `SignReleaseCoRIM` signs a repository's unsigned CoRIM as COSE_Sign1 with the repository's bound key, or with the tenant's release key when it has none; it is served at REST/QUIC `POST /api/v1/attestation/signing-keys/sign`, the gRPC and Unix `SignReleaseCoRIM` RPC and MCP `attestation.signing_key.sign` (permission `attestation_signing_keys:sign`), and every client transport calls it (usb returns `ErrNotSupported`). `xkmsctl key signing-key sign|set|get|list|delete|resolve` drives it and the per-repository bindings from the CLI, and sdk/go re-exports `NewRepositoryImageSigner` so a repository's images are signed by the same key (go-xkms#2190, folds #2103).
