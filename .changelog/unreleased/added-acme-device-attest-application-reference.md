- **device-attest-01 application reference at finalize (acme-issuance, SPEC.md:41)** — a DICE device's provisioning record can register a 32-byte `ApplicationReference`; finalize re-reads it from the registry and `VerifyPossessionCSR` refuses, as `ErrPossessionApplicationEvidenceMismatch`, a possession request whose application evidence is not that reference (constant-time compare). A record with a reference of any other length is invalid. A device registered without a reference is always refused, with the same sentinel. `RegisteredDeviceVerifier` gains `RegisteredApplicationReference`.
