- **A real arduino-generic device could not enroll through `device-attest-01`: its identity was invisible to the server, and nothing proved the path end to end** (#737). The AVR alias certificate has room for one extension, so it states the device's ueid as CWT claim 256 of its `tcg-dice-UCCS-evidence` and carries no `tcg-dice-Ueid` extension. `DeviceIdentity` and `dice.Verify` read only the extension, so the identity gate refused every genuine AVR device (and `RequireUeid` could never be met by one).
  - **`dice.DeviceUeid` reads both.** It returns the `tcg-dice-Ueid` extension when present and the UCCS claim 256 otherwise, and refuses a certificate stating two different values (`dice.ErrUeidConflict`) rather than choosing one. `dice.Verify`, `deviceattest01` (`DeviceIdentity`, `DeviceIdentityFromCertificate`) and the AVR backend (`Attestation.Ueid`) use it. SDK: `DICEDeviceUeid`, `DICEClaimUeid`, `ErrDICEUeidConflict`.
  - **End-to-end proof against the real firmware.** `TestDeviceAttestDICEEnrollsTheRealFirmware` and its refusals (`pkg/acme/client/device_attest_dice_e2e_test.go`) run arduino-generic's element-tier simulator (`agsim.StartElement`: the real firmware compiled for the host, with a model of the ATECC608A that does real P-256) through `Client.DeviceAttest` and the real ACME handlers, with the production `TrustAnchorVerifier` anchored on the DeviceID key. The device mints its alias certificate over `DICENonce(keyAuthorization)`; the order's identifier is the hex ueid; finalization binds the CSR to the alias key and the issued certificate carries the ueid as its `permanentIdentifier`. Refused: an order for another ueid (`unauthorized`), evidence over another challenge's nonce and untrusted roots (`incorrectResponse`, told apart by the reason the verifier recorded), and a CSR for another key (`badCSR`).
  - **The simulator is built, never skipped.** `make agsim` builds `agsim` and `agsim-atecc608a` from the arduino-generic module at the version `go.mod` pins into `AGSIM_DIR` (`scripts/build-agsim.sh`), refusing source whose module hash is not the one in `scripts/agsim.sum`; `make test`, `make race` and `make coverage-full` depend on it, and the `test-changed` and `race` CI jobs run it. A missing binary fails the test with the command to run.
  - Pins `github.com/jeremyhahn/arduino-generic/sdk/go` to v0.7.0-alpha (root and `sdk/go`), which returns the 164-byte `Device.Attest` frame with its fields in place and adds the `sdk/go/agsim` launcher.
  - **Open (arduino-generic):** a physical AVR cannot finish this enrollment. The alias key is the DeviceID key and `Client.DeviceAttest` must sign the CSR with the attested key, but the firmware has no command that signs a host-supplied digest or CSR (`Backend.Signer` returns `ErrSigningUnsupported`). The end-to-end test signs the CSR with the simulator's published test private key, which exists only for the simulator. Closing it takes either a signing command in the firmware or an alias key distinct from the DeviceID key, both arduino-generic decisions.
  - Closes #737.
