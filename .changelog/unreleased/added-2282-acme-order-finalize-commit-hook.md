- **ACME order finalize commit hook (#2282)** — `handlers.OrderFinalizeCommitHook` (`Params.OrderFinalizeCommitHooks`, `RestService.SetOrderFinalizeCommitHooks`; SDK `ACMEOrderFinalizeCommitHook`, `ACMEOrderFinalizeCommitHookRegistry`, `NewACMEOrderFinalizeCommitHookRegistry`) runs once per finalized order, for both TCG-CSR and standard x509 orders, after the certificate and order saves, with the same hook context the `OrderFinalizeHook`s saw and the persistence error: nil when both saves succeeded, the save error when either failed. A consumer such as go-trusted-platform (#1896) stages its enrollment state in the finalize hook, which still runs before persistence and may veto issuance, and commits or undoes it in the commit hook, so a failed save no longer leaves state behind for a certificate that was never delivered.
