- **Session-token signing key JWK, SPKI `kid` (#1724)** — `sdk/go` `ServiceModuleSessionSigningJWK(ctx, svc, opts)` (`rest.SessionSigningJWK`, `pkg/api/rest/session_jwk.go`) returns the public RFC 7517 JWK (RFC 7518 §6.2.1 EC, `alg` ES256) of the key that signs the embedded module's session tokens, so a composer publishes it in its JWKS. Typed errors: `ServiceModuleSessionSigningKeyMissingError`, `ServiceModuleSessionSigningKeyExportError`, `ServiceModuleSessionSigningKeyTypeError`. The private key stays in the backend. The JWK's `kid` (RFC 7517 §4.5) and every session token's `kid` header (RFC 7515 §4.1.4) are now `jwk.SPKIKeyID` (sdk `JWKSPKIKeyID`): unpadded base64url of SHA-256 over the key's DER SubjectPublicKeyInfo, the identifier go-quicbaas publishes JWKS keys under; before, the token's `kid` was the signing key's CN. A key with no SPKI encoding fails with `*jwk.KeyIDError` (sdk `JWKKeyIDError`).
