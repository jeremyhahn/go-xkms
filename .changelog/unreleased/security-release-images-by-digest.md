- **Release builds and their Trivy gates run images by digest** (#1332) -- the release workflow's build container (`golang:<GO_VERSION>-bookworm`), the generated server Dockerfile's builder stage and both release Trivy gates (`aquasec/trivy:0.75.0`) are pinned by `@sha256` digest, pulled by that digest before `docker create`/`docker run`, and run by it. A tag re-pointed in the runner's shared Docker daemon can no longer substitute the compiler or the scanner of a release. Bump `GO_IMAGE_DIGEST` with `GO_VERSION`.
