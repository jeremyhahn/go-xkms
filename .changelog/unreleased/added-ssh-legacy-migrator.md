- **SSH store migrator into the DAO catalogs (#1748)** — `sdkssh.MigrateLegacyStores` (`sdk/go/client/ssh/stores.go`, over `pkg/ssh/migrate.Run`) moves the pre-DAO sealed-KV records of all five SSH stores (keys, known_hosts, authorized_keys, sessions and profiles, with folder markers) into the DAO catalogs, through new `ImportLegacy` methods on each store and `records.Table.Import`. It deletes each old key only after its import succeeds, is idempotent (a second run reports zero), and returns `Migrated`/`Skipped`/`Failed` counts with typed per-record errors; a failed record stays in place for the next run. Tenant-prefixed sessions and profiles are skipped and left in place. The consumer calls it at store open; documented in `docs/ssh-keys/` and `docs/ssh-sessions/`.
- **The SSH migrator refuses a tenant-prefixed source and migrates the tenant named `ssh` (#1962)** — `MigrateLegacyStores`/`migrate.Run` return `ErrMigratePartitionedSource`/`ErrPartitionedSource`, before listing anything, when the legacy backend is a tenant-scoped `storage.PrefixBackend` (whose keys would read as system records and move tenant); a key `ssh/ssh/...` now migrates into tenant `ssh` instead of failing as a system record.
