- **A general SPIFFE ID builder and validator.** `pkg/spiffe` adds `TrustDomain`, `WorkloadID`, `ParseTrustDomain`, `ParseWorkloadID`, `WorkloadIDFromURL`, `ValidatePath`, `ValidatePathPrefix` and `HasPathPrefix`, enforcing the SPIFFE-ID specification for any trust domain and path, with `InvalidIDError` wrapping a sentinel per rule. The new `sdk/go/spiffe` re-exports it together with the existing tenant-scoped identity helpers.
