- **The Go SDK can wire the embedded node's user service.** `WithServiceModuleNodeUsers` (with the `ServiceModuleNodeUserSource` alias) re-exports `apimodule.WithNodeUsers`, so a host building on `NewServiceModule` resolves users on its public WebAuthn, invite and refresh routes through the node instead of reaching go-qrdb with no credentials.
- **The FIDO2 integration suite builds with the JSON codec.** `make integration-test-fido2` and `integration-test-fido2-cli` now pass `codec_json` to `go test`, so the `webauthntest` credential stores build instead of failing every ceremony test with "codec json is not supported in this build".
- **The bootstrap integration stack turns healthy.** The xkms-server healthcheck probes `/health` with a GET (it answers HEAD with 405, so `wget --spider` never passed) and waits longer than the admin-client enrolment; a failed `make integration-test-bootstrap` now prints the stack state, the server logs and its health record.
- **A refresh token issued before the upgrade is revoked with its user.** A refresh record saved before records carried a tenant now fails closed: disabling or deleting its user in any tenant revokes it, so re-enabling the account cannot revive the old refresh token.
- **A PIV invitation binds only a certificate of the invited tenant.** Activation reads the certificate's tenant with the rule and trust-domain pin PIV login uses and refuses a trusted certificate that names another tenant before the invitation is claimed; a self-built module gives the service its PIV login pin when the host set none.
- **Concurrent first requests on a self-built module build one REST host.** The build and publish run under one lock, and the token issuer, WebAuthn service and invite user client the build sets on the shared service are stored atomically.
