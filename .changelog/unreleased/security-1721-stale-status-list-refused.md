- **An Android attestation status list that arrives already stale is refused (#1721).** A response whose `Age` has reached its freshness lifetime (RFC 9111 §4.2) is fetched once more with `Cache-Control: no-cache` (§5.2.1.4); if that answer is stale too, `HTTPStatusList.Current` fails closed with `ErrStatusListUnavailable` wrapping the new `ErrStatusListStale`, and nothing is cached.
