- **CI cache trim now bounds in-use cache volumes.** `scripts/trim-ci-caches.sh` used to keep every cache volume a container mounted, so one runner host's Go build cache volume reached 57G and filled the disk. When the caches are still over the bound with only in-use volumes left, it now trims inside them through a read-write, network-less toolchain container: whole Go build-cache entry directories oldest first (or `go clean -cache` when that volume alone is over the bound), the golangci-lint cache emptied whole, and the module cache never trimmed per file, only reported. `REAP_DRY_RUN=1` still changes nothing and the trim never fails the job.
