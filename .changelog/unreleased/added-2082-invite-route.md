- **The web console redeems invite links.** `/#/invite/<tenant>/<token>`, the link the server mints when an operator creates a user, now opens a passkey enrolment screen: it shows the tenant and invited address, registers a passkey bound to the invite through the shared svelte-auth credential provider and signs the new user in. An unusable link reads "This invite link is not valid"; with `webauthn.enabled` off the screen names the setting and starts no ceremony. `@go-xkms/sdk` gains `InvitesClient` (`client.invites`).
