- **An interrupted PKCS#8 key delete no longer leaves metadata a new key inherits.** `DeleteKey` now removes the key's metadata record before its blob, so a failure or stop part-way leaves a blob a retry still finds and deletes, and a delete of a key whose blob is already gone still removes its record. A key generation whose metadata write fails also drops any stale record under the identifier. Before, a delete that removed the blob but not the record made every retry answer key-not-found, and a later key of the same identifier inherited the orphan's tenant and Exportable flag (#2231).
