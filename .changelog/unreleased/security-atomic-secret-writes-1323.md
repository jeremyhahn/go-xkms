- **Secret files are written atomically, with a fixed mode** -- new `sdk/go/fsutil` (`WriteFileAtomic`, `CreateExclusive`, typed `ErrWriteFile`/`ErrSymlinkTarget`/`ErrTargetNotRegular`/`ErrExists`) writes a 0600 temp file in the target's directory, fsyncs it, chmods it to the requested mode, renames it over the target and fsyncs the directory; a crash leaves the old file intact, an existing wider-mode file ends at the secret mode, and a symlink at the final path is refused. Every secret write in `xkmsctl`, `xkey`, the cluster-CA sealed blobs, the first-boot admin key, the unified TLS key and the ACME deploy now goes through it, replacing the hand-rolled temp-then-rename copies and the plain `os.WriteFile` calls. `xkmsctl bootstrap noise generate-key` keeps its create-only semantics via `CreateExclusive`. Closes #1323.
