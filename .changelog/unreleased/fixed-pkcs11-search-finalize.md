PKCS#11: every object search now finalizes after a failed `C_FindObjectsInit`, so one failed search no longer poisons a session with `CKR_OPERATION_ACTIVE` for every later key, certificate, symmetric, ECDH or attestation lookup. The fix covers the backend's object, key and certificate lookups, the PIV slot model's refresh and the mTLS key/certificate lookup. They all share one helper, `hardware.ClearFailedPKCS11Search`, which also reports a failure of `C_FindObjectsFinal` alongside the Init failure instead of discarding it (DS-3769).
