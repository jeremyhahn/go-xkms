- **The xkms session JWT authenticates on every transport and the admin plane refuses anonymous callers** -- xkmsd now builds on go-qrdb v0.48.0-alpha and registers its authenticator in the node's unified chain (`WithAuthenticators`), so a session JWT reaches xkms module RPCs over gRPC, MCP and HTTP/3 as well as REST. The `/admin` and `/api/v1/tenants` routes are permissioned module routes instead of public ones, and `auth.enabled: false` / `auth.type: none` are refused at boot (`ErrAuthenticationDisabled`) rather than falling back to a no-op authenticator. A clustered xkmsd waits for its shard leader as the node service principal, which now holds `admin:shard_state`. Tenant-scoped user and role management by the platform admin returns 403 under strict tenant isolation (go-xkms#1380).
