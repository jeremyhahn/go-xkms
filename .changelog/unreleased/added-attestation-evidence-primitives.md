- **Attestation evidence primitives are one exported package.** The new `pkg/attestation/evidence`, re-exported with `pkg/tpm2`'s `VerifyCertify*` and `pkg/attestation/peer`'s IAK/IDevID checks in `sdk/go/evidence`, verifies TPM2_Quote signatures, qualifying data and PCR digests, AK certificates (tcg-cap-verifiedTPMRestricted) and EK certificates (tcg-kp-EKCertificate), and parses and replays TCG PC Client crypto-agile event logs from bytes with digest sizes taken only from the Spec ID header. Every failure is classified forged or absent. The attested-peer verifier and the CA's EK check now run these primitives instead of private copies.
