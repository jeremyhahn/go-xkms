- **CI follows ci-template v1.49 (handbook 83).** The preflight job runs on the bigdisk pool by default; the repository variable `CI_PREFLIGHT_RUNS_ON` moves it to a hosted runner. The agent token reaches the preflight only off github.com. The Devcontainer image job now reads the preflight's `runner_docker` choice like the other Docker jobs, and a pull request from a fork always stays on GitHub-hosted runners.
