- **`pkg/tpm2/vtpm`: `Config.Binary` is validated once, at `NewManager`, instead of trusted at every `Start`.** A bare name (no path separator) is resolved through `exec.LookPath`; a path is confirmed to exist and be a regular, executable file with `os.Stat`. Either way the resolved path is fixed for the Manager's lifetime, not re-searched on `PATH` per vTPM start. A node whose `backends.tpm2.vtpm.binary` is missing or not executable now fails closed at startup with the typed `vtpm.BinaryError`, instead of at the first tenant's `Start` (gosec G204).
