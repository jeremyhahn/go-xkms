- **Web console SSH Key Import screen.** A new Security entry, `#/ssh/import`, imports an existing PEM private key (with an optional passphrase) through `POST /xkms/v1/ssh/keys/import` and prints a stored key's `authorized_keys` line through `GET /xkms/v1/ssh/keys/{scope}/{owner}/{name}/public`. The pasted PEM and passphrase stay only in the form, are cleared after each attempt and never appear in a toast or an error. The entry shows only where SSH is wired and the identity holds `ssh:write`.
