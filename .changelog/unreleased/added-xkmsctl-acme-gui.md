- **`xkmsctl acme gui` hosts the desktop ACME admin GUI (`gui` build tag).** `pkg/acme/gui/admin` had no host binary since go-trusted-ca's `cactl` was never migrated. `xkmsctl acme gui` opens the Wails window, connected through the same SDK client and `--acme-server`/`--acme-transport`/`--tls-*` flags as every other `acme` verb, and refuses a missing server (`ACMEAdminAddressRequiredError`) or mTLS identity (`ACMEGUIIdentityRequiredError`) before connecting. The verb is compiled only with `-tags gui`; `make build-cli-gui` builds it (cgo, webkit2gtk-4.1). The default `xkmsctl` is unchanged. The window's Linux program name is now `xkmsctl`. The desktop router now serves the ACME admin API's paths, which the embedded admin SPA calls: `/admin/{status,stats,certificates,accounts,orders}` replace `/api/v1/{status,stats,certificates,accounts,orders}`, intermediate-CA status moves to `PUT /api/v1/tenants/{id}/intermediate-cas/{caId}/status`, `/admin/certificates` takes `expires_days`, and the routes the SPA never called (`/certificates/expiring`, listing and getting intermediate CAs, getting one EAB) are gone. `GET /admin/audit` and `PUT /api/v1/tenants/{id}/default-intermediate-ca` stay unserved on the desktop until the SDK has operations for them.
