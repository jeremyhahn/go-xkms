- **Android appraisal through xkmsd honours a per-tenant application allow-list.** `server.New` now composes the Appraiser with `attestation.android_applications` (tenant ID -> package name -> hex SHA-256 signing-certificate digests); before, every `AppraiseAndroidKeyAttestation` through a composed server was refused with `ErrNoApplicationAllowList`. A tenant absent from the list stays refused; a blank key or a digest that is not 64 hex characters fails startup.
