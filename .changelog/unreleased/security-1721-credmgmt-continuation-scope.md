- **A credential management enumeration continues only under a token that covers it (#1721).** Per CTAP 2.1 §6.8 and §6.5.5.7, issuing a new pinUvAuthToken by PIN or built-in UV discards the enumeration in progress, and enumerateRPsGetNextRP and enumerateCredentialsGetNextCredential answer CTAP2_ERR_PIN_AUTH_INVALID when the current token's permissions RP ID does not cover the enumeration, so a token minted for one RP can no longer read another RP's credentials or the RP list.
