- **Session-token signing key JWK (#1724)** — `sdk/go` `ServiceModuleSessionSigningJWK(ctx, svc, opts)` (`rest.SessionSigningJWK`, `pkg/api/rest/session_jwk.go`) returns the public RFC 7517 JWK (RFC 7518 §6.2.1 EC, `alg` ES256) of the key that signs the embedded module's session tokens, with `kid` equal to the token header's `kid` (the resolved `SigningKeyCN`, default `xkms-jwt-signing`), so a composer publishes it in its JWKS. Typed errors: `ServiceModuleSessionSigningKeyMissingError`, `ServiceModuleSessionSigningKeyExportError`, `ServiceModuleSessionSigningKeyTypeError`. The private key stays in the backend.
