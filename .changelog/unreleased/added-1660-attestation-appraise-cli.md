- **`xkmsctl attestation appraise` appraises a TPM quote against stored reference values.** `--reference-values <name> --ak-cert <file> --quote <file> --signature <file> --nonce <hex> --pcr <index>=<hex> [--event-log <file>]` sends the evidence to the sdk/go `Client` verb `AppraiseAttestationQuote` and prints the attestation result (`-o json` prints it as JSON). Malformed input is refused before any call, and the command exits non-zero unless the result is verified, so a provisioning script can gate on it (go-xkms#1660).
