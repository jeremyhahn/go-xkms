- **Key resolution binds the tenant to the caller.** Every key operation that takes a `TenantID` (sign, verify, encrypt, decrypt, get public key, key versions, rotate, revoke, key metadata and policy) resolves the tenant through the caller's own identity: an omitted `TenantID` means the caller's tenant, not the system tenant, and any caller, the system tenant included, that names another tenant is refused with `*TenantBindingError`.
