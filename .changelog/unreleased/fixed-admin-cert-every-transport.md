- **The `xkmsd init` admin certificate authenticates on gRPC, MCP and unix, not only REST and QUIC (go-xkms#794).** The unified listener now carries its client-CA pool, the init ceremony root among it, as the static `ClientCAs` that go-qrdb's client-trust pool verifies every client chain against, so the node's mTLS authenticator accepts the bound admin on every transport. `/api/v1/auth/me` reports `auth_method: mtls` for an identity that mTLS authenticated. The SPIFFE trust domain the CA issues under is resolved in one place and always pinned on the node. Docs: `docs/init-ceremony/architecture.md`.
