fido2: `WebAuthnRegistrationOptions` carries the Relying Party's resident-key requirement as `RequireResidentKey`. `ParseWebAuthnRegistrationOptions` sets it from `authenticatorSelection.residentKey` (`required` or `preferred`, WebAuthn Level 2 §5.4.4 and §5.4.6) or the legacy `requireResidentKey`, and `RegisterWebAuthn` sends it as the CTAP2 `rk` option. Before this, a server asking for a passkey got a non-discoverable credential, and a login with an empty allow list failed with `authenticator: no credentials` (#1758).
