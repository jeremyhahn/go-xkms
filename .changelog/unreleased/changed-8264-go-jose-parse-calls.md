- **JWS and JWE parsing calls the serialization-specific functions of go-jose v4.1.9** -- go-jose v4.1.9 deprecates `ParseSigned` and `ParseEncrypted` (staticcheck SA1019), so `make lint` failed on the three ACME handler call sites (`key_change.go`, `service.go`, `tenant_auth.go`) and on `pkg/encoding/jwe`. Two unexported helpers, `parseSignedAny` and `parseEncryptedAny`, call the `...JSON` function when the input starts with `{` after white space and the `...Compact` function otherwise, which is what the deprecated functions did: no call site changes what it accepts. `web/desktop` follows the root module's dependency bumps (`go mod tidy`).
