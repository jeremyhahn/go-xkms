- **The Android attestation status list is fetched only over HTTPS.** The list carries no signature, so `NewHTTPStatusList` (SDK `NewAndroidHTTPStatusList`, the phone backend's `status_list_url`, xkey's `phone.attestation_status_url`) now refuses a plaintext `http` URL with `ErrInvalidStatusListURL` unless it names a loopback IP literal, and refuses a redirect that leaves HTTPS whatever the client's redirect policy. An offline copy is configured with `status_list_file` / `phone.attestation_status_file`. SPEC: `phone-verify-user`.
