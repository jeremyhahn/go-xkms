- **The web console shows and edits key metadata.** A Key Metadata screen at `#/keys/metadata` (Keys & Crypto, shown to identities with keys:get) loads a key's metadata by key ID and backend through `GET /api/v1/keys/{id}/metadata`: status, algorithm, usage, version, the exportable and deletion-protection flags, dates, owner and the rotation policy. It edits the name, description and tags and saves only what changed through `PUT /api/v1/keys/{id}/metadata`.
