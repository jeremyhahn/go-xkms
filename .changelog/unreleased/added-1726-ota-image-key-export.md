- **Export of a board's OTA verification public key (#1726, rulings 210 and 213)** — `ExportOTAImageKey` returns the current version of a trusted-firmware board's ES256 key as the raw 64-byte `X || Y` and as an RFC 9052 §7 / RFC 9053 §7.1.1 COSE_Key (kty 2, kid the key ID, alg -7, crv 1, x, y) in RFC 8949 §4.2.1 deterministic CBOR, with the board id, key ID and `key_version`; never the private key. It is tenant-scoped and checked as `keys:get` on REST `POST /api/v1/ota-image-keys/{board}/export`, gRPC/Unix `ExportOTAImageKey`, QUIC, MCP `xkms.exportOTAImageKey`, the embedded transport, `sdk/go` and `xkmsctl key ota-image export`. **SDK change:** `transport.Client` gained the method, so every implementation of the interface must add it. Docs: `docs/key-management/engineering.md#per-board-ota-image-keys`.
