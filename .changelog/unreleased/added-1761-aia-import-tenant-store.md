- **Tenant-scoped AIA issuer import (#1761)**: `CA.ImportIssuingCAsInto(ctx, cert, store)` walks a certificate's AIA chain under the same fetch limits, signature check, loop and depth refusals as `ImportIssuingCAs`, but looks for and stores each issuer only in the caller-owned `certstore.CertStore`. It never touches the CA's shared certificate or key stores, so one tenant cannot claim an issuer common name and block another tenant's issuer (go-quicbaas#1993). A nil store returns `ErrTargetCertStoreRequired`. The method is on `CAChainImporter`, and so on `TrustedCA` and the `sdk/go` alias. `ImportIssuingCAs` stays for system-scope callers.
