- **A removed trust root stays removed, and `xkey trust fetch` uses the server store.** Removing any trust root now leaves a tombstone, so a config import racing the removal, or the next verifier rebuild, never trusts the root again. With an xkmsd endpoint configured, `xkey trust fetch` and `xkey trust import-platform` import the fetched bundle into the server's trust-root store (and `--install-system` installs from it) instead of the local store.
