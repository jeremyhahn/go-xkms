- **WebAuthn assertion over a caller-held challenge** — `webauthn.Service.VerifyAssertion(ctx, *AssertionVerification)` (`pkg/webauthn/assertion.go`) verifies an assertion over a challenge the caller issued, outside the Begin/Finish login ceremony (WebAuthn L3 §7.2): ceremony type `webauthn.get`, challenge, origin, RP ID hash, required UP/UV flags, signature over the stored COSE key and the sign counter, which must exceed the stored value unless both are zero. Each check fails with its own typed error matching `ErrVerificationFailed` (`AssertionChallengeMismatchError`, `AssertionOriginError`, `AssertionRPIDHashError`, `AssertionUserPresenceError`, `AssertionUserVerificationError`, `AssertionSignatureError`, `AssertionSignCountError`, …); the new counter is saved. The qrdb FIDO2 factor verifier (`pkg/auth_factors/webauthn.go`) uses it when a `VerifyChallenge` carries a `Nonce` and no `session_id`.
