- **The symmetric and Azure Key Vault backends now bind an import token to the wrapping algorithm it was issued for, and the RSA-OAEP/RSA-AES-KEY-WRAP unwrap logic is shared, not copied** (#1342). `pkg/backend/software.SoftwareBackend.UnwrapKey` already refused key material wrapped under a different algorithm than `GetImportParameters` issued the token for; `pkg/keyprovider/symmetric.Backend` and `pkg/backend/azurekv.Backend` did not check this at all, so a caller could request an RSA-OAEP wrapping key and unwrap RSA-AES-KEY-WRAP ciphertext (or vice versa) against it. All three backends also carried their own copy of the `SealedRSAKey.Use` plus algorithm switch that turns a resolved wrapping key and `WrappedKeyMaterial` into plaintext.
  - `pkg/backend/importtoken` gains `Unwrap(sealed, issued, algorithm, wrapped)`, the one place that switch lives now, and `Entry{Key, Algorithm}`, the store value type that binds a `SealedRSAKey` to the algorithm it was issued for. A mismatch is refused with a typed `*importtoken.AlgorithmMismatchError` (wrapping `backend.ErrInvalidAlgorithm`) before the wrapping key's enclave is ever opened. `Entry.Unwrap` is a convenience method callers use instead of the package-level function.
  - `pkg/keyprovider/symmetric.Backend.wrappingKeys` and `pkg/backend/azurekv.Backend.importTokens` are now `importtoken.Store[*importtoken.Entry]` instead of `importtoken.Store[*importtoken.SealedRSAKey]`, recording the algorithm `GetImportParameters` issued alongside the sealed key. `pkg/backend/software.SoftwareBackend` keeps its own richer per-token struct (it also tracks `keySpec`) but now calls `importtoken.Unwrap` instead of duplicating the switch.
  - A non-RSA enclave -- previously only translated to `backend.ErrInvalidKeyType` by the software backend -- is now translated the same way for all three, since the check lives in the one shared helper.
  - Files: `pkg/backend/importtoken/{unwrap,errors}.go`, `pkg/backend/software/software.go`, `pkg/keyprovider/symmetric/backend.go`, `pkg/backend/azurekv/{azurekv,azurekv_importexport}.go`.
  - Verified by: new `pkg/backend/importtoken/unwrap_test.go` (every wrapping algorithm round-trips through `Unwrap`; a mismatched algorithm is refused with `*AlgorithmMismatchError` before the enclave opens; corrupt ciphertext reports the same wrapped-error shape for every algorithm; a non-RSA enclave reports `backend.ErrInvalidKeyType`); new algorithm-mismatch tests in `pkg/keyprovider/symmetric/import_token_bounds_test.go` and `pkg/backend/azurekv/import_token_handle_test.go`; `go vet` and `go test -race` under `-tags "codec_cbor codec_json codec_msgpack tpm_simulator frost"` for `pkg/backend/importtoken`, `pkg/backend/software`, `pkg/keyprovider/symmetric`, and under `-tags azurekv` for `pkg/backend/azurekv`.
  - Fixes #1342.
