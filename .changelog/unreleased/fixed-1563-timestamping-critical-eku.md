- **The `timestamping` certificate profile issues its extended key usage critical** -- RFC 3161 section 2.3 requires a TSA certificate to carry id-kp-timeStamping as its sole, critical extended key usage, and the image verifier refuses one that does not. crypto/x509 encodes the usage non-critical, so certificates from the profile failed the verifier. The profile now supplies a critical extension listing id-kp-timeStamping alone (go-xkms#1563).
