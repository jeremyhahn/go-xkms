- **xkey: `TestApp_RegisterPKCS11XKMSBackend_FactoryNotRegistered` no longer fails in a `pkcs11` build.** The test assumed its binary was built without the `pkcs11` tag, but xkey's Makefile builds tests with it by default (`WITH_PKCS11=1`), so the factory existed and the precondition failed. The case now lives in `app_pkcs11_absent_test.go` (`!pkcs11`), and a `pkcs11` build runs `app_pkcs11_present_test.go` instead, which proves registration fails closed when the PKCS#11 module cannot be loaded.
