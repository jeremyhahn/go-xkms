- **Backend credential values can no longer be read through the platform-secrets API** -- under a hardware or cloud credential strategy a submitted credential is kept in the platform store under `credentials/<name>`, and `SealStoreGet` on every transport returned it to any platform-scope reader, breaking the write-only contract of the credential API. The seal-store service now refuses Put, Get, Delete and Reseal of a name in that namespace (dot-segment spellings included) with `xkms.ErrReservedSecretName` -- REST 403, gRPC/Unix `PermissionDenied`, MCP forbidden -- and List and Status leave those names out. Files: `pkg/xkms/servicer_seal_store.go`, `pkg/server/credentials/service.go`, `pkg/api/apierrors/tables.go`, `pkg/api/rest/seal_store_handlers.go` (go-xkms#1465).
