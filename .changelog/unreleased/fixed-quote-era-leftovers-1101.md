- **Removed the quote-era `service.SetupDeviceAttest01Challenge` stub and the integration suite that still exercised the retired TPM2_Quote flow; the swtpm integration fixtures now provision what the certify model requires** (#1101, follow-up to #1059).
  - `service.SetupDeviceAttest01Challenge` (`pkg/acme/client/service/challenge.go`) always returned `ErrTPMModuleRequired` and had no caller anywhere in the tree: the real device-attest-01 path is `DeviceManager.Attest` → `Client.DeviceAttest` → `XKMSTPMAdapter.CreateAttestedKey`, which needs a `client.TPMModule` this stub's signature never accepted. It is deleted along with `ErrTPMModuleRequired` and their dedicated tests.
  - `test/integration/challenges/device_attest01` is deleted: eight of its nine tests were `t.Log`-only narration describing the retired TPM2_Quote/AK/PCR/event-log design with no assertions, and its one real test checked device-attest-01 availability for a plain `dns` identifier, which the challenge is never offered for. `test/integration/acme-tpm/permanent_identifier_test.go` and `client_enrollment_integration_test.go` already cover the same ground against the correct `permanent-identifier` authorization with real assertions, and `pkg/acme/challenges/device-attest-01/setup_simulator_test.go` plus `pkg/acme/client/tpm_simulator_test.go` cover the certify statement itself.
  - `test/integration/acme-tpm`'s swtpm fixture (`swtpm_helper_test.go`) provisioned only the TCG-standard EK/Shared-SRK/IAK, so every device-attest-01 swtpm test failed past `CreateAttestedKey`: it parents the certificate key under the Platform SRK and `deviceattest01.Setup` reads the IAK certificate, and swtpm's `Provision()` created neither. `SwtpmConnection.Provision` now also calls `xkmssdk.EnrollSimulatorPlatformSRK` and the new `xkmssdk.ProvisionSimulatorIAKCertificate`, the same helpers `pkg/acme/client/service.openDeviceTPM` uses to provision the in-process simulator, so both provisioning paths share one implementation. The IAK certificate minting code that used to live unexported in `device_tpm.go` moved to `pkg/tpm2/tpm2test.ProvisionIAKCertificate`, re-exported from `sdk/go` next to `EnrollSimulatorPlatformSRK`.
  - Files: `pkg/acme/client/service/{challenge,errors,device_tpm}.go`, `pkg/tpm2/tpm2test/iak_cert.go`, `sdk/go/tpm.go`, `test/integration/acme-tpm/swtpm_helper_test.go`.
