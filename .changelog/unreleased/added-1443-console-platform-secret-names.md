- **The web console lists the platform secret names.** A new Secret Names screen at `#/platform/secrets` (Settings section, shown when the platform seal store is wired and the identity holds `keys:list`) lists the names in the store through `GET /api/v1/platform/secrets`, sorted, with a filter, the total and a Refresh button, so an operator can find the exact name to reseal or delete. No secret value is fetched or shown.
