- **A node accepts mTLS quorum share holders** -- the embedded go-qrdb node was built with the xkms `mtls` factor, which shadowed go-qrdb's own. That factor expects a PEM certificate and a signature over the bare nonce, so it refused every mTLS share holder the node's ceremony enrols. As a result, a quorum could never count an mTLS holder. The node now uses `factor.NewNodeRegistry`, which carries every factor except `mtls`, so go-qrdb's own factor verifies its share holders. Administrator enrolment keeps the xkms `mtls` factor. Files: `pkg/factor/registry.go`, `pkg/server/server.go`, `docs/auth-factors/`, `docs/sealing-and-barrier/`.
