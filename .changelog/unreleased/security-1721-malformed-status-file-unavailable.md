- **A local Android status-list file that does not parse is unavailable (#1721).** `LoadStatusListFile` now wraps a parse failure as `ErrStatusListUnavailable` as well as `ErrStatusListMalformed`, the way the HTTP source treats a body that does not parse. A corrupt `attestation_status_file` is therefore an outage of the list: phone verify-user answers `ErrUserVerificationUnavailable`, and the authenticator spends no uvRetries on it (CTAP 2.1 §6.5.5.7.3).
