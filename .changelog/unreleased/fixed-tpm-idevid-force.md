- **`xkey tpm idevid create --force` replaces the existing IDevID** -- a forced run on a device that already had an IDevID kept the certificate stored for the old one, and a failure to evict the key persisted at the IDevID handle was only logged at debug level. A forced run now removes the stored IDevID certificate, and the IDevID key is evicted and re-persisted at its handle; an eviction failure returns `ErrEvictIDevID`. The key is a primary derived from the endorsement seed, so its public key does not change. Without `--force`, an existing IDevID now returns the typed `ErrIDevIDExists`. Files: `xkey/cmd/xkey/cmd/tpm_idevid.go`, `pkg/tpm2/key.go`.
