- **One node builder: `pkg/daemon` is merged into `pkg/embeddednode`** -- `embeddednode.NewNode` is now the only code that constructs the embedded go-qrdb node, standalone or clustered (Raft mTLS plus the cluster-enrollment advertiser). `xkmsd`, `pkg/datastore` and SDK embedders all go through it. The package's types are renamed to `NodeOptions`, `NodeResult` and `ErrNilNodeOptions`. Its errors now read `embeddednode: ...` instead of `daemon: ...`. The SDK keeps `NewDaemonNode`, `DaemonOptions`, `DaemonNodeResult` and the related names, which now point at the merged builder. CI's raft matrix now also runs the builder's tests, including a three-replica cluster formed over Raft mTLS.
