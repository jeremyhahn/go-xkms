- **The MCP tool client no longer goes through mcp-go's `client.Client` (GO-2026-6911).** `pkg/mcptool` now runs the handshake (`server/discover`, falling back to the legacy `initialize`) and `tools/call` directly on its own streamable HTTP transport. That transport never follows a `Location` header, so the bearer token and the configured extra headers are never sent to another origin. mcp-go's `client.Client` calls its transport through an interface that can resolve to the vulnerable `transport.StreamableHTTP`, so it is no longer used. `NewClientWithSession` takes a `Session` interface. govulncheck still reports GO-2026-6911 through go-qrdb's MCP replica forwarder, which needs a go-qrdb release.
