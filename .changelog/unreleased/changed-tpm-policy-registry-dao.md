- **The TPM policy registry stores go-qrdb DAO entities** -- `pkg/tpmpolicy` moved to `pkg/tpm2/policy`, and `policy.NewRegistry` now takes the go-qrdb DAO factory instead of a `storage.Backend`. Scopes, policies and assignments are entities in the registry's own `tpmpolicy` database. A store failure is a `*policy.StoreError`. `compose.TPMPolicyParams` and `compose.Deps` gain a required `DAOs` field; when it is missing, `compose.Build` says so. A factory that does not serve the `tpmpolicy` database fails with `*dao.DatabaseUnavailableError`. `compose.Databases(deps)` names the databases a host must open first. A host without a go-qrdb node builds its factory over one KV store with `dao.NewStoreFactory`. The `tpm-policies` compose store name is gone. Existing registry data is not migrated.
