CI: `make deps-check` runs on the PR tier as a lint-class gate (ci-template v1.28, ruling 220(3)). Its step in the image job no longer waits for `CI_FULL_TIER`: it runs on every event, a docs-only PR included, as `make lint` does, so a module behind its dependency floor fails the PR rather than main after the merge. It keeps `IN_IMAGE_NETWORK=bridge` for the module proxy and still runs on the full tier.
