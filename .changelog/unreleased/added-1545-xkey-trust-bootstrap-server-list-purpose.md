- **`xkey trust bootstrap` files the bundle on the server, and `xkey trust list` takes `--purpose`.** With an xkmsd endpoint configured, `trust bootstrap` fetches the CA bundle as before and imports it into the server's trust-root store through `TrustRootImport` as `bootstrap-ca` with the `platform:<host>` source, writing no local store. `trust list --purpose <purpose>` lists only the roots of that purpose, locally and against a server, and refuses an unknown purpose before any call.
