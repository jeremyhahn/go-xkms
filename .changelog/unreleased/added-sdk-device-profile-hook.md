- **SDK re-exports the device-profile hook and the TPM auth-failure sentinel** -- `sdk/go/acme` now exports `NewACMEDeviceProfileHook` (the pre-issuance hook that validates a TCG-CSR enrollment against a looked-up device profile) with its `ACMEDeviceProfile` and `ACMEDeviceProfileError` types, and `sdk/go` exports `ErrTPMAuthFailed`, identical to `pkg/tpm2.ErrAuthFailed` so `errors.Is` holds against errors the library returns. Consumers no longer import `pkg/acme/server/handlers` or `pkg/tpm2` for either.
