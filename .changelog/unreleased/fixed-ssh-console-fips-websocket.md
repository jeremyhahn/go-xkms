- **The SSH console refuses the WebSocket upgrade under `fips140=only` instead of panicking (go-xkms#23).** RFC 6455 §4.2.2 requires SHA-1 for the `Sec-WebSocket-Accept` header, which the Go Cryptographic Module refuses under `GODEBUG=fips140=only`. The `pkg/ssh/console` handler now asks `crypto/sha1` before the upgrade and answers `501 Not Implemented` with a typed `*console.UpgradeRefusedError`; outside `fips140=only` the console is unchanged.
