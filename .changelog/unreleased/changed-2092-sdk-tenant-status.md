- **The sdk/go ACME admin client refuses a tenant status set and filter.** Until go-qrdb carries a tenant status, `TenantCA().UpdateTenantStatus` and `Tenant().List` with a non-empty `Status` return a `*TenantStatusUnsupportedError` (field `status`, an invalid input error) that matches `ErrTenantStatusUnsupported`, and send no request. The admin GUI API answers that refusal with 400 `TENANT_STATUS_UNSUPPORTED`.
