- **xkey authorizes audit reads through the embedded xkms service's go-qrdb authorizer.** `XKMSService.Authorizer()` returns the service's qrdb-backed `Authorizer`, or the nil interface when none is wired or RBAC is disabled (a disabled authorizer allows everything, so it is never handed out). xkey wires it into `AdminService` only when it is non-nil, so standalone xkey without go-qrdb RBAC still refuses every audit read.
