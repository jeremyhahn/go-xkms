- **Web console assets under /ui/ and clean build-web (#2286)** — `apimodule.WithWebUI` trims one trailing slash from its prefix, so the `webui.NormalizePrefix` form `/ui/` that `pkg/server` passes registers `/ui` and `/ui/*` instead of `/ui/` and `/ui//*`; every `/ui/assets/*` request now reaches the SPA instead of answering 401/404. `make build-web` runs `npm ci` in `sdk/ts/svelte-auth` before the `web/app` build, so a clean checkout resolves `@go-xkms/sdk` from `svelte-auth`.
