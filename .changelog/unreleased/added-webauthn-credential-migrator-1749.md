- **WebAuthn legacy credential migrator (go-xkms#1749)** — `sdk/go.MigrateWebAuthnLegacyCredentials` (re-exporting `pkg/webauthn.MigrateLegacyCredentials`, `pkg/webauthn/legacy_migration.go`) moves credentials enrolled under the shared pre-tenant keyspace `__xkms:webauthn/credentials/` into the per-tenant credential store. The consumer calls it at each tenant store open. The tenant is resolved from the credential's qrdb user through `go-qrdb/sdk/go`. The old key is deleted only after a successful save, so a second run migrates nothing. Records that cannot be moved stay in place and are reported as typed errors (`WebAuthnLegacyCredentialCorruptError`, `WebAuthnCredentialOwnerUnresolvedError`, `WebAuthnCredentialMoveError`, `WebAuthnLegacyCredentialScanError`, wrapped in `WebAuthnCredentialMigrationIncompleteError`). The report counts migrated, skipped and failed. Documented in `docs/webauthn/api.md` and `docs/webauthn/engineering.md`; unit tests are in `pkg/webauthn/legacy_migration_test.go` and `sdk/go/webauthn_migration_test.go`.
