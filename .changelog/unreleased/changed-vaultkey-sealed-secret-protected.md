- **`vaultkey.Sealed.Secret` is a `*secure.Secret`, not a `[]byte`.** A freshly sealed key-factor secret is plaintext key material; v0.48.0-alpha returned it in an ordinary slice, which the secure-analyzer's rule 3 rejects. `vaultkey.Seal` now computes the key-check value and moves the secret straight into protected memory (`secure.NewSecret` wipes the drawn bytes), returning `*vaultkey.ProtectError` if that fails; the caller owns the Secret and must `Destroy` it. `pkg/staticpw`'s key-factor enrollment and `pkg/vaulttoken.SelfTest` hold it that way end to end. Breaking for any caller that read `Sealed.Secret` as bytes.
