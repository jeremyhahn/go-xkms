- **Web console Bootstrap Keys view.** `#/bootstrap/keys` (Security, needs `bootstrap:read`) shows the trust-bootstrap listener's Noise_NK X25519 and P-256 public keys from `GET /api/v1/bootstrap/keys`, each with a copy button and the client setting that takes it (`--noise-key` / `trust.bootstrap.noise.server_key`, `--p256-key`). A server without the listener is reported as information, not as an error.
