- **A barrier over an xkms storage backend now performs its guarded compare-and-swap.** go-qrdb's `StorageBarrier.CompareAndSwap` asserts its base for the two-value `CompareAndSwap(...) (bool, error)`; `pkg/seal`'s `guardedStorageBackend` forwarded only xkms's three-value shape, so every swap on a barrier over an xkms backend -- xkmsd's system barrier among them -- failed with "storage backend has no guarded swap". The wrapper now adapts the backend's `storage.CompareAndSwapper` to the barrier's shape (a base without the capability is still refused, never approximated by read-then-write). The OIDC credential service persists rotating refresh tokens with it. Tests: `pkg/seal/barrier_adapter_compareanddelete_test.go`.
