- **A tenant's first `SignCoRIM` generates a release key only on backends that keep the tenant.** Vault, PKCS#11 and the phone backend generate and list keys without the tenant, and Vault stores key metadata under the common name alone, so first use created a global release key the tenant could not see and could overwrite another tenant's release-signing metadata. Provisioning now allows only the software backend and a TPM with tenant scopes, and refuses every other backend before generating anything, with a `ReleaseKeyProvisionError` wrapping `ErrReleaseKeyBackendUnsupported` (go-xkms#1956).
