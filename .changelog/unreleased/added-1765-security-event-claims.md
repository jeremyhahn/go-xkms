- **Device security-event record format and capability (#1765)** — `pkg/attestation/securityevent` encodes and decodes an HSM device's tamper-response record as one CBOR Claims-Set in RFC 8949 core deterministic encoding (`Record`, `Entry`, `Encode`, `Decode`) under the go-xkms private-use claim key `ClaimKey` (-71765) until EAT registers one; `Decode` refuses malformed, non-deterministic, unknown-key, missing-key, out-of-range and count-mismatched input with typed errors. The optional backend capability `types.SecurityEventProvider` (`AttestSecurityEvents(ctx, nonce)`) returns that Claims-Set, or `ErrNotSupported`; no backend implements it yet, and the binding of the record to the device is still open.
