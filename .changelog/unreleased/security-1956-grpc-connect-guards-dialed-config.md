- **gRPC `Connect` runs the plaintext guard on the configuration it dials.** `NewWithConfig` keeps the caller's `Config`, so one built with `TLSEnabled` and switched to plaintext before `Connect` used to dial plaintext TCP with `AllowInsecureTransport` unset, and `SetUserPIN` or `PasswordStoreUnlock` then sent their credentials over it. `Connect` now reads the `Config` once, takes the credentials, target and bearer token from that snapshot, and refuses with `ErrInsecureTransport` before dialing when the snapshot is plaintext to a non-unix endpoint (go-xkms#1956).
