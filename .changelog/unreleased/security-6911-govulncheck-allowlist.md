- **`make vuln` checks reached vulnerabilities against a checked-in allowlist with expiry dates (GO-2026-6911).** `scripts/govulncheck-allow.sh` runs govulncheck with JSON output and fails on any reached vulnerability that `.govulncheck-allow` does not list. It also fails on an entry past its expiry date (UTC) and on an entry that is no longer reached. Each entry names a tracking issue. The only entry is GO-2026-6911 until 2026-12-04 (#2326), for the trace inside go-qrdb's MCP replica forwarder, which needs a go-qrdb release.
