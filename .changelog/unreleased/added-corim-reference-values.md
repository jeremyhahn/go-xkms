- **Signed reference values (CoRIM) are verified as an attestation evidence primitive.** The new `pkg/attestation/refvalue`, re-exported as `VerifySignedCoRIM` and its types in `sdk/go/evidence`, verifies a COSE_Sign1-signed CoRIM against a pinned key or an x5chain certificate chain, enforces the corim-meta and RIM validity windows, and returns each CoMID's reference-value triples in a flat form, with `PCRDigests` for TPM PCR reference values. It adds the dependencies `github.com/veraison/corim` v1.1.2, `github.com/veraison/go-cose` v1.3.0 and `github.com/veraison/swid`, with `github.com/lestrrat-go/jwx/v2` raised to v2.1.7 over corim's v2.0.8.
