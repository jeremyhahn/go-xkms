- **The SSH console's `Dial` returns a typed `*console.DialError` when the connection or SSH handshake fails (go-xkms#23).** Under `GODEBUG=fips140=only` the `curve25519-sha256` key exchange fails when `crypto/ecdh` refuses X25519; `Dial` now wraps that refusal, and every other dial or handshake failure, in `*console.DialError` instead of passing the `pkg/ssh/session` error through bare. The cause stays reachable through `errors.Is` and `errors.As`.
