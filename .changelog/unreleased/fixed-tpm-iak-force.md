- **`xkey tpm iak create --force` now replaces an existing IAK** -- Before this fix, on a device that already had an IAK, the command went straight to `CreateIAK`, whose `TPM2_EvictControl` failed with `TPM_RC_NV_DEFINED` because the IAK persistent handle was occupied. The new `TrustedPlatformModule.DeleteIAK` evicts the persisted IAK under the Owner hierarchy, removes its certificate (certificate store or NV index) and drops the cached attributes, treating anything already absent as removed. `--force` calls it first, so every run behaves like the first. Without `--force`, an existing IAK is refused with the new typed `ErrIAKAlreadyExists`. Files: `pkg/tpm2/key.go`, `pkg/tpm2/tpm.go`, `xkey/cmd/xkey/cmd/tpm_iak.go`. Docs: `docs/tpm2/engineering.md`.
