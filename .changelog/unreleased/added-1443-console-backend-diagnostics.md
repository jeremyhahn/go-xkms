- **Web console Backend Diagnostics view.** A new screen at `#/backends/diagnostics` (Overview, needs `backends:read`) shows one backend's status card (type, status, device, region, key ID, PCR banks and registers, capabilities), lists the algorithms it supports and runs its self-test on demand, through `GET /api/v1/backend/status`, `GET /api/v1/backend/algorithms` and `POST /api/v1/backend/test`. Operators no longer need curl to check a misbehaving PKCS#11 token, TPM or cloud KMS.
