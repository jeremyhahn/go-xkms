- **Built-in user verification that could not reach a decision no longer spends `uvRetries` (#1721).** A verifier error wrapping the new `keybackend.ErrUserVerificationUnavailable` (SDK re-export, with `SentinelCauseError`) answers CTAP1_ERR_OTHER and leaves the retry counter unchanged; `PhoneKeyBackend.VerifyUser` marks no verifier, no session, an unanswered exchange and an unavailable revocation status list this way, while a refusal or mismatch still counts as a failed verification.
