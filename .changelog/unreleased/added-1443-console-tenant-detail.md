- **The web console has a Tenant Detail view.** `#/tenants/detail` (Identity & Access, `tenants:read`) loads one tenant's record (sealed state, isolation type, created and updated times) through `GET /api/v1/tenants/{tenantID}` and deletes it through `DELETE /api/v1/tenants/{tenantID}` only after the operator types the tenant's ID to confirm. A tenant the identity cannot see shows "Tenant not found".
