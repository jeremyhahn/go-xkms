- **The CLI protocol matrix covers the password, pin and piv families.** `TestCLISecretsMatrix` runs every `xkmsctl password` (including `password vault`), `pin` and `piv` verb over unix, REST, gRPC, QUIC, MCP and embedded, each after the steps it needs (vault unlock before add, SO PIN before user PIN, `piv generate` before csr and export); a cell that cannot run, such as a passkey enrollment without a security key, names its reason (row cli-protocol-matrix, slice d).
