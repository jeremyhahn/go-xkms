- **TPM 2.0 backend: RSA keys decrypt.** `Backend.Decrypter` used to refuse every key ("does not implement crypto.Decrypter") and its unreachable decrypter loaded the key without authorizing it. An RSA key now returns a decrypter that runs `TPM2_RSA_Decrypt` (RSA-OAEP, SHA-256, empty label) authorized by the key's own policy session through the new `TrustedPlatformModule.RSADecryptKey`, so it works for keys under a named TPM policy; other schemes are refused with `ErrDecryptionNotSupported` rather than answered with a different one, and EC keys report that they agree (`DeriveKeyECDH`) instead.
