- **The daemon's unified API surface applies the `cors` policy.** The xkms module mounts each REST route by itself on the go-qrdb registrar, so the REST router's CORS middleware never ran there and a browser preflight got the auth chain's 401. With `cors.enabled`, each module route now carries the configured CORS headers, and each route pattern gets a public OPTIONS route that answers a preflight from an allowed origin before authentication. A refused origin still gets no CORS headers (#2329).
