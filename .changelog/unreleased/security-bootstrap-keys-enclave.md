- **Bootstrap P-256 keys move from memguard to go-enclave** -- go-truststrap v0.6.0-alpha's P-256 encoder and decoder take a go-enclave `MemoryEnclave`, so `xkmsctl bootstrap noise generate-p256-key` / `show-p256-key` and the server's P-256 key custody build the hex key in a locked enclave from the process allocator, which every library in the process shares under one `RLIMIT_MEMLOCK` ceiling. go-xkms no longer imports `github.com/awnumar/memguard` directly, and a failure to wipe an enclave is now returned instead of ignored. `bootstrap.NoiseServerStaticKey` is removed from `pkg/trust/bootstrap` and `sdk/go/bootstrap`: `NoiseServerConfig.StaticKey` takes the protected `NoiseStaticKey` directly.
