- **`xkey oidc login --provider <aws-provider> --no-browser` no longer opens a browser.** The login of a saved AWS provider passed a hard-coded `false` for `--no-browser`, so the flag was ignored and a browser was started on headless and SSH sessions. The flag now reaches the AWS login, which prints the authorization URL instead. `TestRunOIDCLogin_AWSProviderHonoursNoBrowser` pins it. SPEC: oidc. (#704)
