- **The AVR backend holds a device to its registered application.** `attestation.application_reference` (`AttestationConfig.ApplicationReference`) names the 32 bytes the alias certificate's application evidence (273) must equal; with it set, an alias certificate from a device running another application is refused with `dice.ErrApplicationEvidenceMismatch`, and `NewBackend` refuses a reference that is not 32 bytes with `dice.ErrInvalidApplicationReference`. Unset, attestation behaves as before.
