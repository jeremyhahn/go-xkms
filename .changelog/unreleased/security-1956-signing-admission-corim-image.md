- **`SignCoRIM` and `SignImage` admit the signing key through its key policy, as `Sign` does.** The release or bound key a repository resolves to, whether it already exists or the tenant's release key was just provisioned on first use, is admitted for signing before its signer is taken: a revoked or disabled key, a caller the key's policy does not allow, an expired policy or an exhausted usage count refuses the signature with the error `Sign` returns. Reading a repository's public key (`SigningPublicKey`) is not a signature and is not admitted (go-xkms#1956).
