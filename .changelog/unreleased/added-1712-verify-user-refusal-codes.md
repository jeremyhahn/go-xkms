- **`local.verifyUser` refusals have their own wire codes (#1712).** The phone answers a prompt the user cancelled with `-32001` `ErrorCodeUserCancelled`, no biometric or device credential enrolled with `-32041` `ErrorCodeVerifyUserNotEnrolled`, a lockout with `-32042` `ErrorCodeVerifyUserLockout`, and a desktop it is not paired with with `-32043` `ErrorCodeNotPaired`. `pairingproto.MapVerifyUserRPCError` maps each to its typed error (`ErrUserCancelled`, `ErrUserVerificationNotEnrolled`, `ErrUserVerificationLockout`, `ErrNotPaired`, re-exported by `sdk/go/pairingproto` and `xkey/pkg/phone`), and `PhoneKeyBackend.VerifyUser` returns it, so the caller can tell the four apart.
