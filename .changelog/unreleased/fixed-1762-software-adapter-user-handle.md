WebAuthn client: the software adapter's `GetAssertion` now returns `response.userHandle` (WebAuthn Level 2 §5.2.2) from the CTAP2 `user` member (0x04) the authenticator returns for a discoverable credential, so a discoverable login (empty `allowCredentials`) passes go-webauthn's `ValidateDiscoverableLogin` instead of failing with a blank user handle. A malformed `user` member is an `ErrCTAPOperationFailed` (#1762).
