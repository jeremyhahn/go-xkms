- **Fourteen discarded errors across xkey and go-xkms now fail closed instead of being silently swallowed** (#1346). In every case a `_ :=`/`_, _ :=` (or similarly ignored) error meant a caller proceeded as if an operation had succeeded — sealing without the requested password, importing a duplicate the store failed to report, skipping owner-hierarchy auth on an EK certificate NV write — when it had actually failed or its outcome was unknown.
  - `xkey/pkg/gui/services/seal_service.go`: `SealData` now returns the new `ErrSealPasswordUnavailable` before calling the SDK client if `opts.Password.String()` fails, instead of sealing with an empty password.
  - `xkey/pkg/oidc/aws/response.go`: `TokenResponse.ToTokenData` now propagates a `GetExpirationTime` failure instead of silently zeroing `Expiration`.
  - `xkey/cmd/xkey/cmd/seal.go`: a staging-directory cleanup failure during a failed migration copy is now joined into the returned `*SealError` and the staging path reported, instead of being discarded.
  - `xkey/pkg/luks/volume.go` and `detect.go`: `IsMounted` now returns `(bool, error)` instead of swallowing the underlying mount-check error to `false`. Propagated through every caller: `pkg/storage/luks` (`VolumeOperator` interface and `Backend.Attach`, with the new `VolumeMountCheckError`), `xkey/pkg/gui/services/storage_service.go` (`RequireUnlocked`, `GetStatus`), and the `xkey/cmd/xkey/cmd` LUKS commands (`root.go`, `lock.go`, `unseal.go`, `seal.go`, `wipe.go`, `migrate.go`, `import_data.go`) — each now fails closed (never proceeds as if unmounted) when the mount state can't be determined.
  - `xkey/pkg/audit/store.go` and `dao_store.go`: a failure writing to the configured `slog.Logger` is now joined into the write-failure path (so a `SeveritySecurity` operation still surfaces `*ErrAuditWriteFailed`) instead of being dropped. The `slog` field is now the new package-internal `entryLogger` interface so tests can inject a failing logger.
  - `xkey/cmd/xkey/cmd/device_enroll_phone.go`: every `device enroll-phone` flag is now bound with `*Var` (e.g. `StringVar`, `DurationVar`) instead of read back with `f.GetString`/`GetDuration`/`GetBool`/`GetStringSlice`, which discarded lookup errors and could leave `enrollPhoneOptions` at its zero value.
  - `xkey/pkg/gui/app.go`: `NewApp` now fails setup (panics, matching its sibling init failures) if `os.UserHomeDir()` fails, instead of building the browser-trust directory under an empty path. Extracted to the testable `resolveBrowsersDir`.
  - `xkey/pkg/gui/services/tpm_service.go`: `ProvisionIDevID` now tolerates only `xkms.ErrTPMEndorsementCertNotFound` from `EKCertificate()`; any other failure (e.g. a TPM communication error) fails provisioning instead of silently proceeding without the EK certificate.
  - `xkey/cmd/xkey/cmd/oidc.go`: the auto-refresh exec hook now skips its cycle and logs when `parseIDToken` fails, instead of running the hook with an empty `Subject`/`Email`/`Name`.
  - `xkey/pkg/gui/services/platform_policy_service.go` and `auto_unseal_service.go`: `PlatformPolicyStatus` gained an `Error` field so `GetStatus` keeps `verifyDigests`'s failure reason instead of reporting `Valid: false` indistinguishably from a confirmed digest mismatch; `AutoUnsealService.Enable` now wraps `ErrAutoUnsealTPMNotAvailable` with the underlying `CanSeal` cause via `SentinelCauseError` instead of discarding it.
  - `xkey/pkg/pwimport/importer.go`: a `store.Get` failure other than `xkms.ErrStaticPasswordNotFound` now records the entry as a failed import, instead of being treated as "no existing entry" and imported anyway.
  - `xkey/cmd/xkey/cmd/tpm_idevid_cert.go`: `runIDevIDCSRExportPEM` now tolerates only "no OpenSSL config file found" (`LoadOpenSSLConfig` returning `(nil, nil)`); a config file that exists but fails to parse now fails the command. Extracted to the testable `buildCSRSubjectFromOpenSSLDefaults`.
  - `xkey/cmd/xkey/cmd/tpm_ek.go`: `runEKRestore` now calls `tpm.ProvisionEKCert(hierarchyAuth, ...)` (via the new `restoreEKCert`) instead of `tpm.WriteEKCert`, which always passed a nil hierarchy auth — an EK certificate NV index protected by owner/platform hierarchy auth could not previously be restored. `hierarchyAuth` is wiped via `enclave.Wipe` after the call.
  - `xkey/cmd/xkey/cmd/fido2.go`: the `/dev/urandom`-backed `cryptoRandRead` now uses `io.ReadFull` (via the new `readCryptoRandomFrom`) instead of a single `Read`, so a short read no longer silently yields fewer random bytes than requested for the FIDO2 serial number.
