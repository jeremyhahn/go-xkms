- **`types.Password.String()` no longer returns the secret** -- `String()` is now `String() string` (it was `String() (string, error)`) and every implementation (`ClearPassword` in `pkg/types`, `pkg/password` and `pkg/tpm2/store`, `RequiredPassword`, `PlatformPassword`, `backend.StaticPassword`, `backend.NoPassword`) returns `types.PasswordRedacted`, so formatting or logging a Password cannot leak it and no unwipeable Go string is minted from protected bytes. The interface gains `WithBytes(func([]byte) error) error`, a borrower that also carries the "unreadable" signal the error of `String()` used to (`RequiredPassword` returns `ErrPasswordRequired`, a cleared `pkg/password` password `ErrPasswordZeroed`, an unsealable `PlatformPassword` `ErrPlatformPasswordUnavailable`), so TPM session setup still fails closed. `Bytes()` is documented as a caller-owned copy the caller must wipe. Custom `Password` implementations must be updated. Closes #1401.
