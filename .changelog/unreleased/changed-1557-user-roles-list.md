- **Users carry every role they hold** -- `UserInfo` (Go transport, gRPC, TS SDK) replaces the single `role` with a `roles` list, and the server resolves role names with qrdb's `SystemRoleID` and `GetRoleByName` instead of reading only the first role ID and scanning `ListRoles`. A user with several roles keeps all of them; `xkmsctl user list` shows a ROLES column and its JSON carries `roles` (go-xkms#1557).
