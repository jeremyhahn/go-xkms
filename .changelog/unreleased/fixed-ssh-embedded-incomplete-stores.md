- **The embedded SSH client refuses an incomplete store bundle at construction** -- `sdkssh.NewEmbedded` checked only that `Stores` was non-nil, so `&Stores{}` or a bundle missing one store built a client holding a typed-nil DAO store that panicked on first use. It now returns `*NilInputError` naming the missing store (`Stores.Keys`, `Stores.KnownHosts`, `Stores.Authorized`). File: `sdk/go/client/ssh/embedded.go`.
