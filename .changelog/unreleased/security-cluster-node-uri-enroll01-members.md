- **The cluster CA stamps a node URI only for configured members validated by enroll-01** -- the ACME pre-sign hook stamped `spiffe://<td>/node/<id>` from any order's client-declared `permanent-identifier`, so any TPM the CA trusted could name itself a cluster peer (the open item of go-xkms#828). `NewPermanentIdentifierURISANHook` / `sdk/go/acme.NewACMEPermanentIdentifierURISANHook` are replaced by `NewClusterNodeURISANHook(trustDomain, members)` / `NewACMEClusterNodeURISANHook`. It stamps the URI only on a TCG-CSR-IDEVID order whose sole validated challenge is `enroll-01` and whose identifier is a configured member's Raft `host:port`. `OrderPreSignHookContext` gains `ValidatedChallenges`. `xkmsd` registers the hook with `cluster.peers` as the membership, so the serving node's `peers` must list every joiner. Files: `pkg/acme/server/handlers/`, `sdk/go/acme/`, `cmd/xkmsd/acme.go`, `docs/clustering/`.
- **A cluster joiner's enroll-01 identity is its full Raft address** -- the joiner sent its Raft host as the identifier but expected `host:port` in the node URI, so every ACME-attested join ended in `ErrSPIFFEMismatch`. It now sends its full `raft_address`. enroll-01 dials the identifier's host on the challenge port; the identity it compares and records stays `host:port`. Files: `pkg/trust/clusterca/`, `pkg/acme/server/handlers/challenge.go`.
- **A cluster joiner with `key_backend: tpm2` can reach its TPM** -- the node-local `tpm2` backend hid the shared TPM behind the composed `xkms.Backend`, so a joiner failed enroll-01 with `ErrNoTPM`. It now exposes the TPM and its key-blob store. A new integration suite, `make integration-test-clusterca`, joins a simulated-TPM node end to end. Files: `pkg/trust/clusterca/backends.go`, `test/integration/clusterca/`, `Makefile`.
