- **`make release-alpha` no longer fails to assemble a changelog over 128 KiB.** `scripts/changelog-assemble.sh` handed the assembled release notes to `awk` in one environment variable, and Linux caps a single environment string at 128 KiB (`MAX_ARG_STRLEN`). The 46 entries pending for this release total about 140 KiB, so the assembler failed with `awk: Argument list too long` and the release could not be cut. The block now reaches `awk` through a temporary file read line by line, which has no size limit and still splices every entry byte for byte, backslashes included.
  - Files: `scripts/changelog-assemble.sh`.
  - Verified by `test/scripts/changelog-assemble.test.sh` (new case: 40 entries of 4 KB each, spliced whole and in heading order; it fails on the previous script), plus a rehearsal over this release's real entries.
