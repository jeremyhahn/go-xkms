- **PKCS#11: ECDH finds a PIV slot's key.** `Backend.DeriveKeyECDH` looked its private key up by `CKA_LABEL` built from the common name and algorithm, while `Signer` and `Decrypter` resolve the `CKA_ID` (a PIV slot's own ID for a slot key). A slot 9d key generated by `xkey piv generate` was therefore found for its public half but not for the agreement, so a PIV vault factor on a PKCS#11 token could not unlock. The agreement now resolves the key exactly as the other operations do.
