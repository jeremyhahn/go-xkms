- **The Unix-socket transport presents the login JWT.** `transport.WithJWTToken` reached the server on REST, QUIC, gRPC and MCP, but the Unix transport's gRPC channel carried no call credentials, so a token-authenticated caller lost its identity over the socket. The bearer credentials now live in one shared package, `pkg/api/transport/grpcauth`, used by both the gRPC and Unix transports. The Unix transport dials with gRPC local credentials instead of insecure ones, which states what the socket is (no network path) and lets the bearer token ride it.
