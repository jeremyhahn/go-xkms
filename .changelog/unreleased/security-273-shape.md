- **device-attest-01 holds the measurements claim to its one shape** -- a possession request's measurements (273) must be exactly one measurements-format `[258, bstr .cbor evidence CoSWID]` whose evidence holds one file `"app"` with a SHA-256 hash-entry of 32 bytes, in core deterministic CBOR and with no other field; the device and the server refuse anything else with `ErrPossessionMeasurementsShape`, where before only the claim's presence was checked. The CoSWID's tag-id, tag-version, software-name and tag-creator entity are the producer's (RFC 9393 §2.3, CA m463): a missing or mistyped one is refused, but their values are not compared, so arduino-generic's alias certificates enroll. `ParsePossessionCSR` returns the 32 bytes as `PossessionRequest.ApplicationEvidence`.
