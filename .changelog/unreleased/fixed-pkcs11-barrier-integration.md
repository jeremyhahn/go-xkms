Tests: the TPM-sealed PKCS#11 barrier PIN integration test (`make integration-test-pkcs11-barrier`) reads the barrier state as the first-boot administrator, trusting the CA the server publishes for first contact. It had used the sealed-window client, but the PKCS#11 node seal unseals before the server serves, so there is no sealed window: the unsealed node answers barrier status only to an authenticated caller (HTTP 401), and presents its CA-issued certificate instead of the configured one once the CA composes (`tls: bad certificate`). New helper `xkmsdtest.AdminClient` (DS-3754).
