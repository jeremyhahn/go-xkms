- **`xkmsctl key get` names the key algorithm and curve (#2257)** — a P-256 key no longer prints `Algorithm: 0`: the get path maps the response's algorithm, curve and RSA size onto the printed attributes (`cmd/xkmsctl/key_info.go`), and the Unix, gRPC, REST and QUIC clients now carry `key_size`, `curve` and `partition` on a key get, guarded by `TestGetKey_P256NamesAlgorithm` and `TestGetKey_CarriesCurveAndKeySize`.
