- **The cluster integration suite runs on its own from a fresh checkout** -- `make integration-test-cluster` (3-node Raft cluster plus the standalone server) stages the module-fetch secret itself (`stage-gomodauth`), its test runner gets the `GOMODAUTH_*` credential precedence and a per-run image tag (`go-xkms-cluster-test:$XKMS_IMAGE_TAG`, removed by `clean-run-images`), and its compose file loads before `gen-certs.sh` has run, so `clean-test-containers` tears the project down from a fresh checkout. The standalone server is bootstrapped with `xkmsd init` and starts sealed. The suite stays out of `make integration-test` until the clustered nodes can initialize their barriers: each node needs to be initialized without its own first boot, against a shared bootstrap CA. Files: `Makefile`, `test/integration/cluster/docker-compose.yml`.
