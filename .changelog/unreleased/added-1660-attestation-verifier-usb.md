- **Attestation Verifier on USB, and one appraisal error table.** The USB transport implements `AttestationAppraisalService`; a USB device holds no tenant endorsements or reference values, so each of the eight appraisal verbs returns `ErrNotSupported`. The REST, MCP and gRPC appraisal handlers now classify errors through one table, `apierrors.AttestationAppraisalSentinelClasses`, so a new appraisal sentinel is added once.
