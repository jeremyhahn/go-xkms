- **qrdb node shutdown synchronised with node start (#2332)** — `initEmbeddedQRDBNode` publishes the embedded node's lifecycle fields (node, client, audit sink) under the server mutex, and `stopQRDBNode` snapshots and clears them, with the TPM seal close, under the same lock before closing outside it in the same order (node, audit sink, seal close), so shutdown no longer reads them unsynchronised against the node start.
