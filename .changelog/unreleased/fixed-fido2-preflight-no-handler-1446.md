- **Init preflight refuses a planned FIDO2 admin factor when no FIDO2 handler is configured** -- `NewAdminFactorRegistry` kept the browser-path fido2 factor when `FIDO2Handler` was nil, and that factor reports itself available, so `PreflightAdminFactors` passed and enrollment then panicked on the nil handler after first boot had written state. The registry now always wires the local CTAP2 ceremony; with no handler it reports `fido2.NoHandlerReason` and preflight fails with `*AdminFactorUnavailableError`, as an unattached PIV generator already did. `NewLocalCeremony(nil, ...)` no longer stores the handler as a typed-nil interface, so enrollment that skips preflight returns `ErrLocalCeremonyUnavailable` instead of panicking. Files: `pkg/init/admin_enrollment.go`, `pkg/factor/fido2/ctap2.go`, `pkg/factor/fido2/errors.go`. (#1446)
