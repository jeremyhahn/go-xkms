- **Go builds and tests run with `-trimpath`, so the shared Go build cache stops growing per clone directory.** The Makefile exports `GOFLAGS` with `-trimpath` for every go build/test target (the `coverage` `-p=2` line extends it) and every `GOFLAGS` env in `.github/workflows/ci.yml` carries it. Without it cmd/go hashed the package directory into each action ID, so every lane and verify clone built new cache keys (#2309).
