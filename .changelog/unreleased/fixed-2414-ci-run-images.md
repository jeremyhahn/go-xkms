- **CI teardown removes the images its run built.** The integration and soak jobs' always-run teardown now calls `make clean-test-containers CLEAN_RUN_IMAGES=1`, which removes only this harness's image repositories at the run's own tag (`XKMS_IMAGE_TAG`, never the shared `IT_IMAGE` nor another job's tag), so self-hosted Docker hosts no longer fill with 4 GB per-run images.
