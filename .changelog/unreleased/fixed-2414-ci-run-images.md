- **CI teardown removes the images its run built.** The integration and soak jobs' always-run teardown now calls `make clean-test-containers CLEAN_RUN_IMAGES=1`, which removes every image whose name or tag carries the run's `IT_PROJECT` (never the shared `IT_IMAGE` nor the soak job's images), so self-hosted Docker hosts no longer fill with 4 GB per-run images.
