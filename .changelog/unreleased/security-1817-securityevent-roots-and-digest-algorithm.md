- **A security-event appraisal requires DICE trusted roots and refuses a non-hashable detached-digest algorithm instead of panicking.** `securityevent.Appraise` accepted an unanchored signer chain when `Options.DICE.TrustedRoots` was nil, and a signed detached digest whose algorithm was a CBOR array or byte string panicked the Verifier on the map lookup; a nil `TrustedRoots` is now `ErrUntrustedSigner` and such an algorithm is `ErrUnsupportedHashAlgorithm` (go-xkms#1817).
