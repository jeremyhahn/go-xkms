- **The gRPC and CLI images ship `xkmsd` and `xkmsctl` under their own names.** The gRPC image runs `/app/xkmsd` (was `/app/xkms-grpc-server`) with the default command `--config /etc/xkms/config.yaml`, as the REST, MCP, QUIC and server images do; its old default (`--port 9443 --data-dir /var/lib/xkms`) named flags `xkmsd` does not accept. The CLI image installs `/usr/local/bin/xkmsctl` (was `/usr/local/bin/xkms-cli`). Image names are unchanged. A build gate (`internal/buildgates`) pins the names.
