- **Web console Data Keys view.** `#/keys/data-keys` (Keys & Crypto, shown with `keys:encrypt`) asks a key to generate a fresh data key through `POST /api/v1/keys/{id}/wrapped-data-key`, with a backend, a key size of 32, 24 or 16 bytes and optional additional data, and shows only the wrapped form (ciphertext, nonce, tag, key version) with a "Copy as JSON" button. The plaintext `/keys/{id}/data-key` route is never called from the browser.
