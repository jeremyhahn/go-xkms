- **`pkg/ssh/session`'s `DialClient` returns the SSH handshake error without a stray closed-connection error (go-xkms#23).** `golang.org/x/crypto/ssh` closes the connection itself when the handshake fails, so the second `Close` returned `net.ErrClosed` ("use of closed network connection"), which was joined to the `*session.HandshakeError`. That expected error is now dropped, so under `GODEBUG=fips140=only` the caller sees only the module's X25519 refusal; any other close error is still returned.
