- **Web console PIN Setup screen.** `#/pin/setup` sets the initial SO PIN (from the factory default) and the user PIN, and verifies either PIN, through `POST /api/v1/pin/{so,user}/{set,verify}`; before this an operator needed xkmsctl for both. PIN inputs are password fields without autocomplete, cleared after every call, and no PIN appears in a toast or alert. A failed verify warns that it counts toward the PIN lockout. The nav entry needs `pin:write`.
