- **The web console looks up a key's TPM policy.** A new TPM Key Policy screen (`#/tpm/key-policy`, Keys & Crypto) takes a key or sealed object id, a kind and an optional tenant and shows the named TPM policy the object was created under, its authPolicy digest and the creation time, through `GET /api/v1/keys/{id}/tpm-policy`. The nav entry shows only where TPM policies are wired and the identity holds `tpm_policy:get`.
