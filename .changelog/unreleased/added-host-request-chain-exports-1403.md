- **`sdk/go` exports the request chain a host composes around an embedded go-qrdb node: the bearer bridge, the pre-authentication IP limiter, request correlation and the object scope rule.** `NewQRDBBearerAuthenticator` (`pkg/auth`, moved from xkmsd's internal `pkg/server/qrdb_bearer.go`) carries a host's session tokens into the node's chain through `WithAuthenticators`, reading the authenticator in force from an `AuthenticatorSource` (`*LiveAuthenticator` is one; `Authenticator`, `LiveAuthenticator` and `NewLiveAuthenticator` are exported too) and never admitting through the no-op authenticator or none (`ErrBearerNotAccepted`); xkmsd registers the same type. `NewIPRateLimiter`, `IPRateLimitMiddleware`, `IPRateLimit{Unary,Stream}ServerInterceptor`, `IPRateLimitKey`, `ParseTrustedProxies`/`TrustedProxies` and their errors export `pkg/ratelimit`. `CorrelationMiddleware`, `Correlation{Unary,Stream}ServerInterceptor` and the context helpers export `pkg/correlation`, which now owns the HTTP middleware and gRPC interceptors xkmsd's REST router and gRPC server install (they moved out of `pkg/api/rest` and `pkg/api/grpc`; a metadata key present with an empty value now counts as absent). `ObjectScope*`, `ScopePrincipal`, `ScopeTarget`, `ScopePrincipalOf` and the keyspace helpers and errors export `pkg/scope`. Exported-API growth.
