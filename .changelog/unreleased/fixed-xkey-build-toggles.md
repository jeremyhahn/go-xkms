- **Root `WITH_*` toggles reach the xkey build** -- `make build-xkey` read xkey's tag set from a `$(shell)` sub-make that inherited neither the root's makefile assignments (such as the `WITH_AWS` umbrella's resolved toggles) nor, before GNU make 4.4, its command-line variables, so `make WITH_PKCS11=0 WITH_AWS=0 build-xkey` still built xkey with `pkcs11`, `awss3` and `glacier`. The root now passes every resolved `WITH_*` toggle to that sub-make explicitly; `make test-scripts` checks the root and xkey tag sets agree. Files: `Makefile`, `test/scripts/xkey-build-tags.test.sh`.
