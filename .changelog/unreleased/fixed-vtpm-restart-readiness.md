- **`pkg/tpm2/vtpm`: a restarted vTPM is no longer reported `Running` before its command socket exists.** The supervisor's restart path spawned the replacement `swtpm` process and marked it running immediately, without the readiness wait `Start` already performs for the first process; a `Transport` dial landing in that window got a raw `dial unix: ... no such file or directory` instead of the documented `ErrConnectionLost` retry-once contract. `Manager.supervise` now awaits the replacement's socket exactly as `Start` does before marking it running, bounded by the same `readyTimeout` and ended early if `Stop` is called while the wait is outstanding.
