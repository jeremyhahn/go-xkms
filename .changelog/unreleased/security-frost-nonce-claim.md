- **FROST claims each signing nonce atomically, and its keys persist as go-qrdb DAO records** -- `SignRound` used to check whether a nonce commitment had been used and then record it in two separate steps, so two concurrent signing rounds could both pass the check and sign with the same nonce, which reveals the private key. `NonceTracker.Claim` now writes a `FrostNonce` record through the DAO's atomic `SaveIfAbsent`: exactly one claim wins and every other returns `*NonceReuseError` (`ErrNonceAlreadyUsed`). `frost.Config` takes a go-qrdb DAO factory (`DAOs`) in place of `PublicStorage` and `NonceStorage`, and keeps keys, verification shares, sealed secret shares and nonce claims in the `frost` database (`frost_keys`, `frost_verification_shares`, `frost_secret_shares`, `frost_nonces`). Secret shares are still stored only sealed. A nil factory is refused with `ErrNilDAOFactory`, and store failures return `*StoreError`. Keys written by the old layout are not read.
