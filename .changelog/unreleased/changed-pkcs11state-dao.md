- **Remote PKCS#11 token state is stored as go-qrdb DAO entities, written as xkms's service principal** -- `pkcs11state.NewStore(daos)` now takes a `*qrdbsdk.DAOFactory` serving the `pkcs11state` database (`pkcs11state.DatabaseName`) instead of a `storage.Backend`, and keeps each record as one `pkcs11_state_records` entity named `<tenant>/<token>/<key>`. `PutIfAbsent`, `CompareAndSwap` and `CompareAndDelete` are the DAO's `SaveIfAbsent`, `CompareAndSwap` and `DeleteIfMatch`, so they work on every datastore; `pkcs11state.ErrNilBackend`, `ErrCompareAndSwapUnsupported` and `ErrCompareAndDeleteUnsupported` are gone (`pkcs11state.ErrNilDAOFactory` and `*pkcs11state.StoreError` replace them). `CompareAndSwap` now follows `storage.CompareAndSwapper`: an absent record refuses, where a nil `expected` used to mean "only if absent". xkmsd opens the database on its datastore, whose `datastore.WithCallContext` runs the records' calls as the embedded node's service principal; the principal's grant gains `kv:range`, which `List`'s paged scan needs. `signserver.Config.StateStorage` is replaced by `StateDAOs`, a DAO factory serving `signserver.StateDatabase`. State written under the old `pkcs11state/` storage prefix is not read; re-provision remote tokens.
