- **Signer store reachable through the SDK** -- `sdk/go` now re-exports the signer store, so a consumer that imports only the SDK can implement the full `xkms.ServiceBackend` contract (whose `SignerStore` method returns it) and return such a backend from a `TrustedCAKeyStoreFactoryFunc`. New names: `xkms.SignerStorer`, `xkms.SignerStoreOpts` (the store's key/blob options; `xkms.SignerOpts` remains the signing options), `xkms.NewSignerStore` (opened over the DAO factory `xkms.NewBackendDAOFactory` or a Datastore yields), `xkms.ErrSignerStoreNilDAOFactory` and `xkms.ErrSignatureNotFound`.
