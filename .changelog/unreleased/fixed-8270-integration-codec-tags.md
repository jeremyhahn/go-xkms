- **The sshagent and fido2 integration suites build with the codec tags.** `make integration-test-sshagent`, `make integration-test-fido2`, `make integration-test-fido2-cli`, `make integration-test-fido2-webauthn` and `make integration-test-fido2-multiprotocol` now pass `codec_cbor codec_json codec_msgpack` to their builds, as `integration-test-sdk-go` does. Without them the stores the suites open failed with `codec "json" is not supported in this build`, which the `Integration` job would have hit at the next target once the module fetch was fixed. A build-gate test keeps the five recipes on the codec tags. The fido2 virtual-authenticator ceremony tests now run on a test surface that sets `AllowPublicRegistration`: they register a fresh account without a session, which the closed-by-default registration rule refused.
