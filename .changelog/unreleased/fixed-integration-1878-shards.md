- **The API integration suite authenticates every CLI command.** The suite's xkmsd now uses `tls.client_auth: request`. With `none` the server never asks for a client certificate, so xkmsctl's admin credential was never sent and composite auth turned the calls away. The CLI runner now fails a test, naming the path, when the admin credential written by `xkmsd init` is missing, rather than running the command anonymously. The suite's xkmsctl is built with `codec_json`, which the FROST commands need, and `integration-test-api-unix` and `integration-test-pkcs8` now stage `gomodauth.env` before building their images.
