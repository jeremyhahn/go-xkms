- **The ACME admin plane panicked on every certificate/account/order/status/stats route when ACME was disabled, and would have accepted every request unauthenticated-through-authorized if the embedded qrdb client were ever absent.** Two defects, both introduced alongside go-xkms#1069's admin-plane authorization fix, surfaced during that work's review. First, `cmd/xkmsd/admin.go` `finalizeAdminModule` always constructs the ACME admin surface's `AdminService`/`TenantAwareAdminService` with `acme.CA()` and `acme.StorageFactory()`, both nil for a nil `*acmeServer` (ACME disabled, the default). Every `AdminService` method that reads the CA or storage factory — `ListCertificates`, `GetCertificate`, `RevokeCertificate`, `ListExpiringCertificates`, `ListAccounts`, `GetAccount`, `DisableAccount`, `ListOrders`, `GetOrder`, `GetStatus`, `GetStats` — and `TenantAwareAdminService.CreateTenantIntermediateCA`'s global-parent branch dereferenced the nil interface value the moment a request reached it. Each now guards its dependency and returns a typed `ErrCANotConfigured` or `ErrStorageNotConfigured` (`pkg/acme/admin/types.go`), which `pkg/acme/admin/handlers.go`'s new `writeUnavailableIfNotConfigured` answers with RFC 7807's 501 Not Implemented — the same shape `ListAuditLogs` already used for a missing audit trail — instead of a panic. Second, a nil qrdb client made `finalizeAdminModule` build the admin authorizer as `auth.NewAuthorizer(nil)`, which is deliberately "RBAC disabled: allow all" everywhere else in the stack, but has no such meaning on the admin plane: `pkg/acme/admin/authz.go`'s `PermissionGate` has no "authorization is optional" mode. `finalizeAdminModule` now refuses to build the admin surface at all when `srv.QRDBClient()` is nil, returning the typed `ErrAdminQRDBClientRequired` wrapped in `*acmeInitError`, rather than silently allowing every request. `cmd/xkmsd/admin_nildeps_test.go` walks the published admin router with ACME disabled and proves no route panics, that the CA/storage-backed routes answer 501, and that construction is refused without a qrdb client; `pkg/acme/admin/service_nildeps_test.go` and `handlers_nildeps_test.go` cover the same guards at the service and handler layers (go-xkms#1075).
