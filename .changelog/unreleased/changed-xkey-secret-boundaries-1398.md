- **xkey and phone-backend secrets leave Go strings** -- the last string boundaries the securecheck v0.25 sweep found are now wipeable bytes or protected memory, with every JSON and archive wire format byte-identical (proved against records and archives written with string fields, including a backup whose checksum covers the encoded bytes). Go types change: `phone.Config.NoiseStaticKey` is `types.SecretBytes`; `oath.Credential`, `backup.OATHCredentialInfo`, `backup.PasswordInfo` and `cdp.StoredCredential` replace `SecretString()`, `PasswordString()` and `PrivateKeyString()` with `Secret()`, `Password()` and `PrivateKey()` returning a caller-owned `[]byte` copy the caller wipes, and `SetSecret`, `SetPassword` and `SetPrivateKey` take `[]byte` and copy it; `oath.Credential.ToURI` returns `(string, error)`; `OIDCStoredToken` token accessors return `[]byte`; and `backup.Archive`, `sync.OATHDelta` and `sync.PasswordDelta` and the pairing sync and OATH messages carry their secrets as the new `types.SecretText` (protected memory with `Destroy`), whose owner destroys it after use. `types.SecretText` and `types.SecretBytes` (now also a `TextMarshaler`, escaping like a string) are exported through `sdk/go` with `SecretTextError` and `SecretBytesError`. Part of #1398.
