- **WebAuthn registration no longer writes the email into the go-qrdb `Username`.** The qrdb user store's `Create` sets `Username`, the certificate CN, to the record's go-qrdb user ID, so the CN carries no PII; the email stays in `Email`, the login key, and login still resolves by email (owner ruling 166). A failed rename deletes the new record and returns `*QRDBUsernameAssignError`. (#1468)
