- **The standalone REST server routes on the decoded path, so an escaped `{name}` addresses the record it names.** chi routed on `URL.RawPath`, so `DELETE /api/v1/attestation/endorsements/ak%3Aroot` (the TypeScript client's encoding of `ak:root`) deleted a record literally named `ak%3Aroot` and left the intended trust anchor trusted; the reference-values GET and DELETE had the same mismatch. The router now clears `RawPath` before routing, as the qrdb host of the unified API server does, so every URL parameter is the decoded name (go-xkms#1608).
