- **Web tests: jsdom localStorage under Node 26 (#2167).** Node 26 enables Web Storage by default, and its global `localStorage` shadows the one jsdom installs, so `window.localStorage` was undefined under vitest and 90/111 svelte-auth tests failed at `window.localStorage.clear()`. The vitest workers in `sdk/ts/svelte-auth`, `web/app` and `xkey/frontend` now run with `--no-experimental-webstorage` (`test.poolOptions.{forks,threads}.execArgv`), so the suites pass without a `NODE_OPTIONS` override. A jsdom test in each package pins the storage round-trip.
