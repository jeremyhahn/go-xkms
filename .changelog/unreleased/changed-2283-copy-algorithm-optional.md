- **`xkmsctl key copy` no longer sends a fixed wrapping algorithm.** Without `--algorithm` the request carries none; REST, gRPC and MCP accept an omitted `algorithm` and the service picks `TPM2_DUPLICATE` for a TPM2 destination and `RSAES_OAEP_SHA_256` otherwise (#2283).
- **A software key copies to a TPM2 destination without naming an algorithm.** The software backend wraps exportable keys whose encoding fits a 128-byte TPM sealed object for the TPM's `TPM2_DUPLICATE` import parameters, which now carry the SRK public area in `import_token` (#2283).
- **Copying onto an existing TPM2 key is refused.** TPM2 `ImportKey` returns `ErrKeyAlreadyExists` and never overwrites the stored key's blobs (#2283).
- **A symmetric key copy to TPM2 is refused.** The TPM2 backend cannot yet encrypt or decrypt with an imported key, so software `ExportKeyTo` and TPM2 `ImportKey` refuse a symmetric key with `ErrExportToUnsupported` (#2283).
