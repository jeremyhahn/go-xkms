- **`sdk/go` re-exports the keyversion, webauthn, ssh/scope and acme entity symbols go-quicbaas imported from internal packages** — the root package adds `KeyVersion*` (`KeyVersionBaseKeyID`, `KeyVersionCheckKeyID`, `KeyVersionImplicit`, `KeyVersionIsReserved`, `KeyVersionTenantSegment`, `ErrKeyVersionNilRecord` and the invalid version/record key errors), `WebAuthn*` (`WebAuthnUserStore`, `WebAuthnUserIDFromHandle`, the not-found helpers, the ceremony HTTP request/response types, `WebAuthnHeaderSessionID`, the `WebAuthnErrorCode*` constants and the `WebAuthnMount*` route helpers) and `SSH*` (`SSHKind` and its constants, `SSHBuildKeyID`, `SSHValidateFilter` and the scope, kind and key ID errors); `sdk/go/acme` adds the tenant CA, settings, signing CA, EAB, serial and subproblem entities with their status, purpose and type constants. Each is an alias of the internal symbol, so a host can depend on `sdk/go` alone.
