- **`xkey trust install` and `trust uninstall` work against the server's trust-root store.** With an xkmsd endpoint configured, `trust install` takes the root from `TrustRootGet`, checks its fingerprint and installs it into the OS trust store under `xkey-<fp[:16]>`; `trust uninstall` removes that OS entry, also for a root the server no longer holds. Neither opens or writes the local store in server mode, and no installed flag is recorded; without an endpoint both work on the local store as before.
