- **`server.New` releases the datastore when invite or attestation config is invalid** — a bad `invite.default_ttl`/`invite.max_ttl` or a broken `attestation.formats` trust store made `New` return without closing the embedded qrdb node and backends, so the Pebble lock stayed held and any retry in the same process failed with "lock held by current process". These three exits now cancel the server context and call `closeBackends`, like every other failure path in `New` (`pkg/server/server.go`); `pkg/server/new_failure_cleanup_test.go` covers both.
