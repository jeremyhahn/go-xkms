- **`secure.HardenProcess` disables core dumps again.** Since go-enclave v0.11, importing it no longer lowers RLIMIT_CORE, and go-qrdb's `HardenProcess` never did, so every xkms binary that hardens at startup could again write its memory, unsealed secrets included, to a core file. `HardenProcess` now also calls go-enclave's `HardenProcess`, which sets RLIMIT_CORE to zero (soft and hard), unless the process opted out with `AllowProcessInspectionEnv`. If that step fails, the new `*CoreDumpHardeningError` is returned. Platforms where go-enclave does not support it (Windows) are unaffected.
