- **The OIDC core is one shared package, `pkg/oidc`, used by xkey and xkmsd alike.** The client (authorization code + PKCE, refresh, DPoP, userinfo, revocation), discovery, provider templates, the loopback callback and the token-store abstraction (`TokenStore`, `MemoryTokenStore`, the barrier-backed `BackendTokenStore`, the DAO store) moved from `xkey/pkg/oidc` to `pkg/oidc`, and the URL-safety helpers it depends on from `xkey/pkg/urlsafety` to `pkg/urlsafety`. xkey's local OIDC is unchanged: same providers, flows, refresh loops and storage; only its imports moved. The AWS-specific login and the output handlers stay in `xkey/pkg/oidc/aws` and `xkey/pkg/oidc/handlers`.
