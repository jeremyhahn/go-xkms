- **CI: the Devcontainer stages run in parallel** — the serial `Devcontainer image [lint, build, test, security, deps-check, trivy image]` job (147-180 minutes on main runs 75696 and 75748) is six parallel jobs: `Devcontainer: lint`, `checks` (fmt, vet, gate tests, the releasability test, the build-tag assertion), `build`, `coverage`, `security` (make security, make deps-check) and `trivy image` (full tier). Each takes the toolchain image from `ci-images` by digest and mounts the repository's named Go build, golangci-lint and module cache volumes, so none rebuilds an image or starts cold; only `trivy image` takes the integration image. The wall time becomes the longest stage, `make coverage` (timeout 120 minutes; the others 60). CI Gate needs all six in place of the image job (#1871).
