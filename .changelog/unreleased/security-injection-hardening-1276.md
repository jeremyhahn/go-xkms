- **Four server- and frontend-supplied values reached a filesystem path or a generated shell script without validation.** (#1276)
  - `pkg/acme/client/service/challenge.go`'s `WriteHTTP01TokenFile` and `CleanupHTTP01TokenFile` joined the ACME server's HTTP-01 challenge token directly into a webroot path. A malicious or compromised ACME server could have supplied a token carrying `../` segments to write or delete files outside the configured webroot. Both functions now call a new `validateHTTP01Token`, which enforces RFC 8555 Section 8.3's base64url token format (`^[A-Za-z0-9_-]+$`, non-empty, bounded length) before the join, returning the new typed `ErrInvalidHTTP01Token`.
  - `pkg/acme/storage/objstore/tenant_aware_factory.go`'s `(*TenantAwareFactory).ForTenant` built the `acme/tenants/<id>` key prefix from a caller-supplied tenant ID without validation. It now calls `storage.ValidateTenantID`, the same tenant ID validator already used by `pkg/ssh/tenancy`, `pkg/keyprovider/frost`, and `pkg/xkms`, rejecting IDs carrying `..`, `/`, `\`, or `:` with a `qrdbsdk.DAOInvalidConfigError`.
  - `xkey/pkg/gui/services/seal_service.go`'s `blobPath` joined a frontend-supplied blob ID into the sealed-blob storage path. `UnsealData` and `DeleteBlob` — the two exported methods that resolve an ID to a path — now call a new `validateBlobID`, which restricts IDs to `[A-Za-z0-9_-]` (matching every ID `SealData` generates, a 32-character hex string, and every hand-assigned legacy ID already exercised by the test suite) and refuses anything else with the new `ErrSealInvalidBlobID`.
  - `xkey/pkg/nativemsg/manifest.go`'s `GenerateLauncherScript` rendered the instance home directory and binary path into a generated `sh` launcher with Go's `fmt` `%q` verb, which escapes for a Go string literal, not a POSIX shell one: `$` and backticks pass through unescaped, so either would have been subject to shell expansion when the launcher ran. It now uses a new `SingleQuote` in `xkey/pkg/shellquote`, moved out of `xkey/pkg/gui/services/secure_browser_extensions.go` (which already had its own copy for the extension-import wrapper script) so both packages share the one implementation.
  - Files: `pkg/acme/client/service/challenge.go`, `pkg/acme/client/service/errors.go`, `pkg/acme/client/service/challenge_test.go`, `pkg/acme/storage/objstore/tenant_aware_factory.go`, `pkg/acme/storage/objstore/tenant_aware_factory_test.go`, `xkey/pkg/gui/services/seal_service.go`, `xkey/pkg/gui/services/seal_service_test.go`, `xkey/pkg/gui/services/secure_browser_extensions.go`, `xkey/pkg/nativemsg/manifest.go`, `xkey/pkg/nativemsg/profile_manifest_test.go`, `xkey/pkg/shellquote/shellquote.go` (new), `xkey/pkg/shellquote/shellquote_test.go` (new).
  - Verified by new tests for each fix, including one that plants a sentinel file outside the target directory and asserts a traversal ID/token never touches it, and one that runs the generated launcher script through `sh` with a path containing `$HOME`, a backtick pair, a single quote, and a space, asserting the literal path reaches the child process unexpanded; `go vet` and `gofmt` clean under `codec_cbor codec_json codec_msgpack tpm_simulator frost` (root) and `codec_json tpm_simulator ble` (xkey).
  - Fixes #1276.
