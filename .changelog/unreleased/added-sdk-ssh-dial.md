- **SDK re-exports the SSH session dial primitives** -- composers that resolve their own signer (hardware key, remote signing proxy) no longer need `pkg/ssh/session` to dial. `sdk/go` adds `xkms.SSHSessionDialClient` and `xkms.SSHSessionClientParams` (the signer-based TCP dial + handshake + host-key verification), `xkms.SSHNewSession` (wraps the dialed client as an `xkms.SSHSession`), `xkms.SSHKnownHostsCallback` (the fail-closed host-key callback over an `xkms.SSHKnownHostsStore`), and the errors a caller matches with `errors.As`: `xkms.SSHKnownHostsNotFoundError` (unknown host), `xkms.SSHKnownHostsMismatchError` (host key mismatch), `xkms.SSHSessionHandshakeError` (wraps a signer's own error), `xkms.SSHSessionDialError`, `xkms.SSHSessionTimeoutError` and `xkms.SSHSessionNilInputError`. All are aliases of the `pkg/ssh` types.
