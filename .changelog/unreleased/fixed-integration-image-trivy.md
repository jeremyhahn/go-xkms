CI: the integration image passes its `trivy image` gate again. A 106 MB `xkey/skillgen` binary built with Go 1.27.2 had been committed by accident, and `COPY . /src` shipped it into the image, where trivy flagged its standard library (CVE-2026-111943). The binary is deleted and git now ignores it. The image's Go module cache moves from `/gomodcache` to `/opt/go/mod`, the directory the scan's `--skip-dirs` names (handbook devops.md §8). Example secrets and test keys in third-party module sources no longer fail the gate, and a secret in the repository's own layers still does (DS-3769).
