- **LUKS passphrase enclaves count against the locked-memory budget** -- `pkg/luks` and xkey's USB image formatter now create the enclave that passes the passphrase to go-luks2 through go-enclave's process `Allocator`. Before, they used the unadmitted `NewMemoryEnclave` / `NewMemoryEnclaveCopy` constructors, so those pages were locked outside the process budget. If the budget is full, formatting or unlocking now fails with `enclave.ErrBudgetExhausted` (wrapped in the package's typed error) instead of locking memory beyond the budget.
