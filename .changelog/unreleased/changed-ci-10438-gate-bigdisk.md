- **The review guard, the Code Review gate and the CI Gate of a same-repo pull request run on the bigdisk pool on github.com (DS-10438)**. In `code-review.yml` the `scope` and `gate` jobs, and in `ci.yml` the `ci-gate` job, run on the bigdisk pool for a push to main and for a pull request whose head is in this repository, including the `pull_request_target` runs of the review workflow. A fork's pull request stays on ubuntu-latest. None of these jobs checks out or builds the pull request's code. Off github.com nothing changes.
