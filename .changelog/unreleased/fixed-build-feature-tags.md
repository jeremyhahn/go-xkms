- **The PKCS#11 module build compiles in the TPM 2.0 backend** -- `make build-pkcs11-module`, `build-pkcs11-module-fips` and the module builds the integration targets run passed no build tags, so `WITH_TPM2=1` reached every binary except the module and `pkg/pkcs11/module/backend_tpm2.go` was silently left out. They now build with the same tag set as the rest of the build. Files: `Makefile`, `docs/pkcs11-provider-module/`.
- **The root xkey build keeps xkey's default features** -- `make build-xkey` and `integration-test-xkey-luks` built xkey with a hardcoded tag list that dropped the six default-on object-store backends (S3, MinIO, GCS, Azure Blob, Glacier, Azure Archive). They now read xkey's tags from `xkey/Makefile` (`print-build-tags`), so xkey's `WITH_*` toggles apply to them too; `usb`, which only the root list carried, moves into xkey's own tag set beside `ble`. Files: `Makefile`, `xkey/Makefile`.
- **`release-alpha.sh` accepts scp-like remotes with no user** -- a `host:owner/repo` remote named no forge, so the release aborted; only `user@host:owner/repo` was recognised. File: `scripts/release-alpha.sh`.
