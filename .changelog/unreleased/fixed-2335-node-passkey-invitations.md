- **The node passkey browser suite enrols its operators through administrator-issued invitations.** An auth-enforcing embedded node refuses anonymous sign-up (403 registration_refused), so the suite could never register its operators. Each operator is now created by the administrator over mTLS and redeems its invitation with a passkey before signing out and back in. The passkey account test helper takes the server origin and state directory as settings, and config-node.yaml requests the admin client certificate the way config.yaml does. The node fixture also raises its login limiter (auth.session.login_rate_per_min 6000) so the suite's serial invitation ceremonies are not refused at the 10/min default.
