- **The web console sets the password store's access mode.** A new Password Access Mode screen at `#/passwords/access-mode` (Security section, shown where the password store is wired and the identity holds `passwords:write`) switches the store between `pin_per_operation` and `session_based` through `POST /api/v1/passwords/access-mode` after a confirm step, and shows the API's error message (for example when the wired store cannot enforce the mode).
