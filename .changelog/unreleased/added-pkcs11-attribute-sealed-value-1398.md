- **A backend-held secret key's `CKA_VALUE` stays sealed until the C boundary** -- `pkcs11/module.Attribute` gains `Secret *secure.Buffer`, `ValueLen`, `WithValue` and `Release`, and `ReleaseAttributes` releases a slice of them. `GetAttributeValue` returns a revealable backend key's value in `Secret` rather than `Value`, the C export copies it out and releases it, and a Go caller reads it with `ValueLen` or `WithValue` and releases it with `ReleaseAttributes`. The value never sits on the ordinary heap between the backend and the C caller. Part of #1398.
