- **An audit query reads only the caller's own tenant, the system tenant included.** go-qrdb v0.28 removed `audit:read:cross` and confines every audit query to the caller's tenant on every transport, with no system-tenant exception. `XKMSService.QueryAudit` now does the same before the query reaches the node: the filter's tenant is always the caller's own (normalized; `system` for an absent identity or one with no tenant), whatever `tenant_id` the request named, and no Authorizer decision is consulted. A system-tenant Admin no longer reads other tenants' events or an empty "every tenant" filter; it reads the system tenant's events plus the untenanted platform events. `auth.ActionReadCross` is removed (breaking for a caller that named it). A narrowed query still succeeds with the narrower result rather than an error, on REST, gRPC, Unix, QUIC and MCP. Docs: `docs/audit-log/`, `docs/rbac/`.
