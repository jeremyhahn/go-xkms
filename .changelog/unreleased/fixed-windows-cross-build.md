- **`pkg/tpm2` no longer blocks Windows cross-builds** -- the Unix domain socket transport (swtpm `*.sock` devices) was imported unconditionally, and go-tpm builds it only off Windows. It now sits behind a `!windows` constraint; on Windows a `.sock` device reports the new `tpm2.ErrDeviceTransportUnsupported` (re-exported as `xkms.ErrTPMDeviceTransportUnsupported`). Files: `pkg/tpm2/`, `sdk/go/tpm.go`.
- **File storage's cross-process lock builds on Windows** -- it used `flock(2)` only. Windows takes a `LockFileEx` lock on a `<store-dir>.lock` file beside the store directory, since Windows cannot lock a directory handle. Files: `pkg/storage/file/`.
- **The authenticator's stale-input drain builds on Windows** -- it flushes the console input buffer where Unix reads the descriptor non-blocking. Files: `xkey/pkg/authenticator/`.
- **`make build-cross-check`** compiles `./sdk/go/...` with `CGO_ENABLED=0` for Windows and macOS. It is not yet part of `make lint` or CI: go-qrdb (`pkg/discovery`, `pkg/config`) and go-luks2 (`anatol/devmapper.go`) still fail to compile there. File: `Makefile`.
