- **A TPM key pair is never left with one writer's public blob beside another's private blob.** `SaveKeyPair` with overwrite now replaces the pair under the same fence protocol as the create-only recovery of an incomplete pair: each writer claims the public slot with a unique fence, writes the private blob only if it is still the one it observed, and publishes only while it holds the fence. The steps are conditional writes, atomic across processes on a key backend that implements the new `tpm2.KeyBlobSwapper` and serialised per `TPM2` otherwise; a writer that loses returns `ErrBlobExists` and leaves the other writer's pair untouched.
