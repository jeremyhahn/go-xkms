- **`RequestCodeSigningCertificate` names the signer's tenant** -- `TrustedCA.SignCSR` refuses a request without a tenant (`ca.ErrTenantRequired`), so a code-signing certificate for image signing could not be issued by a real `TrustedCA`. The function now takes a `tenantID`, passes it to the code-signing profile, which stamps it as the certificate's first OU, and refuses a blank one (go-xkms#1546).
