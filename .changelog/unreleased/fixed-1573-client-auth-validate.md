- **An unknown `tls.client_auth` stops xkmsd at startup.** The server listeners mapped any value other than `none`, `request`, `require`, `verify` or `require_and_verify` to "no client certificate", so a misspelt value (`requre`, `Require_And_Verify`) silently served without mTLS. Config validation now refuses any other value, matched exactly, with an error that names `tls.client_auth` and the value (#1573).
