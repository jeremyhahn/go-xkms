- **`xkey trust classify` uses the server's trust-root store in server mode.** With an xkmsd endpoint configured, `trust classify --purpose synced` quarantines the root through `TrustRootQuarantine`; any other purpose is refused with `ErrTrustClassifyFailed` (remove the root and add it again with `--purpose` to change it). The local store is never written in server mode; without an endpoint classify works on the local store as before.
