- **`pkg/staticpw`: `NewTenantPasswordStoreManager` takes functional options, starting with `WithPassphraseKDFParams`.** The Argon2id cost a new passphrase vault factor wraps its DEK with was a package-private variable only `pkg/staticpw`'s own tests could override; every other package that builds a `TenantPasswordStoreManager` ran passphrase enrollment and unlock at the production cost (`kdf.DefaultParams`: 64 MiB, t=3, p=4), and running that many times over in parallel (`pkg/api/mcp`'s password-vault tests) exhausted a CI job's memory. Production callers are unaffected -- the manager defaults to `kdf.DefaultParams(kdf.AlgorithmArgon2id)` exactly as before; `pkg/testutil/kdftest.CheapPassphraseParams` is the cheap cost every package's test fixtures now pass explicitly.
