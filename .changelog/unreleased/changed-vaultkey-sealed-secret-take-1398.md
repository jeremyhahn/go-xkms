- **`vaultkey.Sealed.Secret` becomes protected memory read through `TakeSecret`** -- the exported `Secret []byte` field is replaced by an atomically held `*secure.Buffer` that stays in locked memory until `TakeSecret` hands it to the caller exactly once (the caller wipes the returned slice) or `Destroy` discards it unread; a second `TakeSecret` returns `*SecretTakenError`, and a failed read returns `*ProtectError`. `staticpw` takes the secret this way. Every `Sealed` must end in one of the two calls. Part of #1398.
