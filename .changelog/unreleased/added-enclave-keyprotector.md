- **go-enclave keys under a TPM, HSM or KMS** (#1415) -- new package `pkg/enclaveprovider` implements go-enclave v0.8's provider seam over any `types.Sealer` (TPM 2.0, PKCS#11, AWS KMS, GCP Cloud KMS, Azure Key Vault, Vault Transit, software): `NewKeyProtector` for `ModePerOperation` (also an `enclave.HealthReporter`), and `ProvisionRoot` plus `NewRootUnsealer` for `ModeRootKey`. Blobs are a versioned envelope with a purpose-bound AAD and an HMAC tag over every byte; a blob the provider did not write fails with `enclave.ErrSealedAuthentication`, while backend and context failures keep their own errors. `pkg/enclaveprovider/enclaveprovidertest` runs go-enclave's `providertest` conformance suite over a backend, and every backend runs it.
