- **WebAuthn public registration finish completes on an auth-enabled embedded node.** The refresh-token store runs its qrdb KV calls as the embedded node's service principal (`token.WithCallContext`, `TokenIssuerParams.ServiceContext`, `HostConfig.ServiceContext`), because a public ceremony's request context carries no identity and the node refuses it. Finish's user lookup by ID and display-name update go through the node user service (`NodeUsers`), the same route as begin; the service principal's grant is unchanged. An unmapped WebAuthn service error is logged at Error (error chain only) before the client gets `internal_error` (rulings 742, 1035, 1038).
