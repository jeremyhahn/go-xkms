- **WebAuthn registration finish no longer loses its refresh token on an auth-enabled embedded node.** The refresh-token store now runs its qrdb KV calls as the embedded node's service principal (`token.WithCallContext`, `TokenIssuerParams.CallContext`, `HostConfig.ServiceContext`), because a public ceremony's request context carries no identity and the node refuses it. An unmapped WebAuthn service error is now logged at Error (error chain only) before the client gets `internal_error` (ruling 742).
