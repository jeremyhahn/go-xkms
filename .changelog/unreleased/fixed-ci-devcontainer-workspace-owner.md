CI: the Integration job's devcontainer can write its own workspace again. `ci_sync_devcontainer_workspace` populated the CI devcontainer's `/workspace` volume with `docker compose cp`, which creates every file as root, while the devcontainer runs as `vscode`, so `integration-test-pkcs11-module` failed at `mkdir -p build/lib` ("Permission denied"). The checkout is now streamed as a tar archive and unpacked inside the devcontainer by its own user, so the tree belongs to the user every devcontainer target runs as (`integration-test-pkcs11-module-all`, `-utils`, `-webauthn`, `-fido2`, `-sdk-go`, `-sshagent`, `-initceremony`) (DS-3754).
