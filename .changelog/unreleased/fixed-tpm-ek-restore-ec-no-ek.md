- **`xkey tpm ek restore --force` works on a TPM that is not initialized** -- restore opens the TPM configured with the index it writes, so on a TPM with no persistent EK, or an empty target index (for example an empty EC index beside a stored RSA certificate, with `--ec`), the open reported `ErrTPMNotInitialized` and restore returned before writing. A forced restore now proceeds and writes the certificate, since `ReplaceEKCert` needs neither a persistent EK nor a stored certificate; without `--force` the open error is still returned.
