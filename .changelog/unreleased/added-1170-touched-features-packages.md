- **Touched-test selection scripts.** `scripts/touched-features.sh <base> <tip>` prints the `test/integration/<feature>` directories whose `make integration-test-<feature>` a diff needs, from the integration tests' imports, or `ALL` when a change is outside every feature; `scripts/touched-packages.sh <base> <tip>` prints the changed packages and their direct importers for the new `make test-pkg PKG=<dir>`. A buildgates test fails when a `test/integration/` directory with tests has no target that runs it, or when an explicit `integration-test-<name>` names a missing directory (Tenant rulings 1170 and 1171).
