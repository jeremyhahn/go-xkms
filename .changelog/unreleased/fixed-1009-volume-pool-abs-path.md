- **A relative `datastore.path` no longer leaves the tenant volume pool unserved.** xkmsd now resolves the datastore path to an absolute path before it becomes qrdb's raft data directory and default volume pool (`<path>/tenant-volumes`). qrdb refuses a relative pool path, so with a relative `datastore.path` the default pool was never opened and WebAuthn registration answered 500 `internal_error`. On a clean start the default pool directory did not exist either, and qrdb refuses a missing pool directory, so the embedded node now creates every configured volume pool directory (owner-only, 0700) before it opens the node.
