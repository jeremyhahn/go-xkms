- **The web console shows and edits a key's access policy.** A new Key Access Policy screen (`#/keys/access-policy`, under Keys & Crypto, for identities holding `keys:get`) loads a key's policy by key ID and backend, and sets or removes it: allowed operations, allowed and denied principals, expiry, usage cap, rotation required and MFA. It calls the existing GET, PUT and DELETE `/api/v1/keys/{id}/policy` routes; removing the policy returns the key to the default policy.
