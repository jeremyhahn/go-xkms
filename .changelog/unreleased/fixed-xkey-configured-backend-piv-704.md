- **A backend configured in xKey holds PIV certificates without a restart.** `AdminService.ConfigureBackend` gave new TPM 2.0 and PKCS#11 backends no PIV capability, so they were not listed as PIV-capable until the next start, and the PIV register hook never fired. A certificate imported in the meantime went to an on-demand `backends/<id>/` namespace and was gone after the restart, which reads `backends/<category>/`. The hook also registered the shared software store, so if it had fired, the new backend would have listed software certificates. Configured backends are now PIV-capable, and the hook registers the same isolated `backends/<category>/` store that `initLocalPIV` gives them at start (`newNamespacedPIVStore`). `TestApp_ConfigureTPM2Backend_PIVStoreMatchesRestart` pins it.
