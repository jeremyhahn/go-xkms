- **xkey runs no IPC socket unless local app access is on** -- one setting, "Let other apps use my keys while xKey is open" (Settings → Browser, `local_app_access_enabled` in `gui.json`, off by default), replaces `BrowserExtensionEnabled`. The GUI opens its socket only while the setting is on and xKey is unlocked, and removes it at once on lock, seal, disable and shutdown (`syncIPCServer`, driven by the app-lock and barrier seal hooks). The new `xkey app-access status|enable|disable` changes the setting from the CLI. `xkey extension serve` refuses with `ErrServeLocalAppAccessDisabled` while it is off. `xkey usb device start` opens keys in-process when it is off and uses the unlocked GUI over IPC when it is on, failing with `ErrUSBDeviceGUINotListening` instead of falling back. The PKCS#11 IPC transport now carries every `PKCS11Transport` operation -- `generate_key`, `sign`, `verify`, `encrypt`, `encrypt_asym`, `decrypt`, `derive_key`, `derive_key_ecdh`, `wrap_key_by_id`, `unwrap_key_by_id`, `export_key_material`, `get_import_parameters`, `import_key`, `list_piv_slots`, `get_piv_certificate`, `generate_piv_key`, `store_piv_certificate`, `delete_piv_certificate`, `import_piv_certificate`, `export_piv_certificate`, `generate_piv_csr` -- with the SDK transport request/response types as payloads, each gated on the barrier and delegated to the embedded transport; `ErrIPCNotImplemented` is gone. `EmbeddedTransport.Sign`/`Verify`, and so `sign`/`verify` over the socket, now go through the xkms service's signing rules and honour `data_is_digest`, `padding` and `salt_length` instead of ignoring them; an Ed25519 key handed a digest fails with the new `ServiceErrEd25519DigestInput` (`ErrEd25519DigestInput`) on every transport, and `xkeysigner` marks the digest it sends with `data_is_digest` (PSS options add `padding` and `salt_length`; an unnamed hash fails with `ErrUnsupportedHash`). `IPCTransport` waits 3 minutes for `generate_key` and `generate_piv_key` (`keyGenerationTimeout`), so on-card RSA-4096 generation no longer times out; every other operation keeps 10 seconds. Socket hardening is unchanged: `0600` socket, `0700` directory, peer credentials checked, `ReclaimSocket` refuses other users' sockets. Docs: `xkey/docs/gui/`, `autofill/`, `pkcs11/`, `usb/cli.md`.
