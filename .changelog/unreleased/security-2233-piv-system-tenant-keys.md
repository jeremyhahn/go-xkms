- **PIV slot operations no longer sign with, report or delete another tenant's key of the slot's name.** PIV is platform-scoped, but its key generator works on the unscoped backend view, whose listing carries every tenant's keys; a dedicated tenant's key stored under a slot CN (for example `piv-9a`) could be picked as the slot key. Signing (`GetPIVSigner`), provenance (`PIVKeyOrigin`, also read back by PIV import), rekey (`deleteSlotKeys`) and `SelfSignExistingPIVKey` now match only system-tenant keys (`pkg/xkms/piv_keygen_backend.go`, `pkg/xkms/piv_manager.go`); covered by `pkg/xkms/piv_tenant_exact_test.go` (#2233).
