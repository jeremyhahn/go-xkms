- **go-qrdb v0.25.1-alpha.** Every module moves to go-qrdb and its `sdk/go` v0.25.1-alpha, go-quicraft v0.15.0-alpha and go-enclave v0.6.1-alpha. Consumer-visible changes: `sdk/go/secure` drops the memguard-era `CatchInterrupt`, `EnablePurge`, `Purge`, `PurgeOrPanic` and `NotInitializedError` for `WipeAll` (a binary defers it at startup; xkmsd's teardown is now the single `enclave.WipeAll`); `types.NewLiteralSecretValue` returns `(*SecretValue, error)`, failing when the value cannot be sealed; `xkmsctl cluster add` takes `--identity` (the replica's `spki:` Raft member identity); the `sdk/go/dek` re-export and `QRDBTenantKeyManager` alias are removed, as go-qrdb removed what they aliased. In xkmsd, go-qrdb now owns `GET /health` (its node health) and `GET /v1/ca/bootstrap`, which it serves from xkmsd's CA bundle (`WithBootstrapCABundle`); the xkms module no longer registers either, and the bootstrap route no longer takes the `store_type`/`algorithm` filters. go-qrdb v0.25.1 changes the Raft WAL format: an existing data directory does not open, so upgrade from an empty one.
