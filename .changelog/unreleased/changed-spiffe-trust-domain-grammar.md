- **The `x509-svid` profile refuses a SPIFFE ID whose trust domain is not the tenant** (go-xkms#1602): the one URI SAN must be `spiffe://<tenant>/...`, the tenant being the subject's OU[0], so a tenant's SVID subordinate is name-constrained to its own trust domain. Tenant SPIFFE synthesis under a cluster trust domain that names the tenant fails with `ErrSigningFailed` wrapping `spiffe.ErrTenantIsClusterTrustDomain`. SPEC: trust-domain-grammar.
