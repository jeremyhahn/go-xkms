- **`scripts/release-assets.sh` speaks the GitHub releases API.** With an `api.github.com` API root (or `RELEASE_FORGE=github`) it uploads the raw file to the uploads host (`RELEASE_UPLOAD_API`, default `https://uploads.github.com`), deletes and downloads an asset by its id at `/repos/<owner>/<repo>/releases/assets/<id>` (downloads as `application/octet-stream`, so private assets work), and keeps its skip / replace / add upload table. Gitea calls are unchanged (go-xkms#1082).
