- **`xkey device`'s `--trust-new-devices` and `--timeout` (`device pair`/`device scan`) now actually read the config file and `XKEY_DEVICE_*` environment variables that were always documented as their sources, instead of silently ignoring them** (#1071). Both flags, plus `device pair --device`/`--force` and `device status --device`, were bound only with `viper.BindPFlag` against the package-level `viper` singleton `cmd/xkey/cmd` never calls `ReadInConfig`/`AutomaticEnv` on -- the binding made `viper.GetString`/`GetBool` on that key mirror the flag, but nothing ever called either, so a `device.trust_new_devices`/`device.scan_timeout` entry in `xkey.yaml` or an `XKEY_DEVICE_*` variable had no effect. `xkeyconfig.DeviceConfig` (`xkey/pkg/config/config.go`) is now the typed home for the two settings that have real config-file meaning -- `trust_new_devices` (default `false`) and `scan_timeout` (default `30s`, shared by `device pair`'s auto-discovery and `device scan`) -- resolved through the same flag-then-config-then-default precedence `device relay --listen` already used (`GetTrustNewDevices`, `resolveDeviceScanTimeout`, `cmd/xkey/cmd/device.go`), with a `Changed`-based flag check (`commandFlagChanged`, `cmd/xkey/cmd/xkmsd_client.go`) so an explicit `--trust-new-devices=false` still overrides a config file that turned the setting on. `device pair --device`/`--force` and `device status --device` have no config-file meaning -- they are per-invocation choices -- and now have no viper binding at all; they are read directly off the flag, as they already were in practice. Files: `xkey/pkg/config/config.go`, `xkey/cmd/xkey/cmd/device.go`, `device_pair.go`, `device_pair_stub.go`, `device_scan.go`, `xkmsd_client.go`. Verified by `xkey/pkg/config`'s `TestLoadFromPath_EnvOverride_DeviceSettings`, `TestLoadFromPath_DeviceSettings_FileBeatsDefault` and `TestValidate_*DeviceScanTimeout`, and `xkey/cmd/xkey/cmd/device_config_test.go`'s flag-beats-config-beats-default precedence tests and proof that the four per-invocation flags no longer mirror into viper.
