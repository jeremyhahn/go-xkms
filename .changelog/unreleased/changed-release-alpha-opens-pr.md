- **`make release-alpha` opens the release pull request itself** -- after pushing `release/vX.Y.Z-alpha` it opens the pull request into `main`, titled exactly `chore(release): vX.Y.Z-alpha`, on the forge the `dev` remote's own URL names (ssh, scp-like or http(s) form; an SSH remote maps to the forge's HTTP port, `GITEA_HTTP_PORT`, default 3001), and prints its URL. It previously printed a compare link built from the `origin` remote's host, which pointed at the wrong server when `origin` and `dev` differ. The project agent's forge token must be in `FORGE_TOKEN`; a missing or rejected token, or a remote that names no forge, is refused before anything is fetched or written, in a dry run too.
