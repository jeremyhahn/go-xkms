- **The web console takes a boot credential.** A Boot Credentials screen at `#/credentials/boot` (Security, shown with `credentials:strategy`) shows the server's credential strategy and auto-unseal state and submits a boot credential (an unseal secret or PIN) through `POST /api/v1/credentials/submit`. The secret field is a password input, cleared after each attempt and never shown or echoed in a message. On a server that does not wait for a boot credential the screen says so.
