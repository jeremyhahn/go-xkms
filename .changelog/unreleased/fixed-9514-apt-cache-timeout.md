- **Pool image builds no longer hang on a stalled LAN apt cache (DS-9514)** — every proxied `apt-get` in `Dockerfile`, `build/docker/devcontainer/Dockerfile` and `Dockerfile.softfido` now adds `-o Acquire::http::Timeout=30 -o Acquire::Retries=3` to the `p=${APT_PROXY:+...}` option string, so a cache that stops answering fails the fetch and retries instead of holding the Integration image build until the CI job times out. `internal/buildgates` enforces the options on every RUN that sets the apt proxy.
