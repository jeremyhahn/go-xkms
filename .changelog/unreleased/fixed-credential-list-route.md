- **`xkmsctl credential list` no longer gets a 404** -- the CLI calls `GET /api/v1/credentials` but xkmsd registered the collection as `/credentials/`, which chi treats as a different path. The route is now `GET /api/v1/credentials`, the one canonical path, and a CLI test drives the verb against the real REST router so the two cannot drift again. Files: `pkg/api/rest/routes.go`, `cmd/xkmsctl/credential_router_test.go` (go-xkms#1464).
