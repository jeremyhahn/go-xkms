- **Published images build on digest-pinned base images** -- the xkms-server and xkms-cli images now take their runtime base (`debian:bookworm-slim`) and, for xkms-cli, their Go builder (`golang:1.27.2-bookworm`) by `@sha256:` digest from `release.yml`'s env, passed to `Dockerfile.cli` as the `GO_IMAGE` and `RUNTIME_IMAGE` build args. A pull_request job that re-tags an image on the shared runner daemon can no longer swap the base of the next release. The runtime stages still run `apt-get upgrade -y`, so the pinned base is still patched at build time (go-xkms#1332).
