- **TPM key-pair recovery never leaves a mixed public/private pair across processes.** `store.BlobStore` now implements `CompareAndSwapBlob` with the qrdb DAO's atomic compare-and-swap, so two TPM2 instances sharing one store can no longer interleave a recovery and an overwrite into public-B/private-A; a key backend that cannot swap blobs atomically is refused with `store.ErrKeyBlobSwapUnsupported` instead of a read followed by an overwrite.
