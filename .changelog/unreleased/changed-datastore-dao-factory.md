- **The datastore hands out the go-qrdb client and a DAO factory** -- `datastore.Open` now returns a `*datastore.Datastore` instead of a `storage.Backend`, in standalone and remote mode alike. It carries `Client()` (the go-qrdb SDK client) and `DAOFactory()` (go-qrdb's DAO factory over the default database and every named database it has opened). `datastore.New` builds one over a client the caller owns. `DatabaseKVStore(ctx, name)` is now a method, and `DialRemote` returns the `*qrdbsdk.Client`; `ClientBackend` and `ErrClientUnavailable` are gone. New `dao.New` builds a go-qrdb `GenericDAO` from the factory and refuses a named database that is not open instead of falling back to the default one. Features not yet on DAOs get a `storage.Backend` over the factory from `compose.FactoryBackend` / `compose.FactoryStorage`; the API-module host's `"xkms/"` stores now open this way. The SDK's `OpenDatastore` returns the `*Datastore`; `DatastoreStorage(ds.DAOFactory())` gives the `StorageBackend` for `AutoConfig.Datastore`.
