- **No in-house `GOPRIVATE` default.** The Makefile's `GOMODAUTH_GOPRIVATE`, the devcontainer compose file and the integration compose files no longer default `GOPRIVATE` to the first-party module path: it is the caller's `GOPRIVATE`, empty when unset, so first-party modules resolve through proxy.golang.org and sum.golang.org like any other (DS-7944). A caller that names private modules still has them fetched with the module credential. A `buildgates` test fails on any `GOPRIVATE`, `GONOSUMDB`, `GONOPROXY`, `GOINSECURE` or `GOMODAUTH_GOPRIVATE` default naming the in-house module path.
