- **Three places in xkey and the SSH client SDK could put a secret where it did not belong: an OTP-secret leak in an error message, a full-token print in a "truncated" CLI display, and a passphrase wipe that wiped a copy instead of the real bytes** (#1257).
  - `xkey/pkg/oath.ParseURI` wrapped `url.Parse`'s `*url.Error` directly (`&SentinelCauseError{Sentinel: ErrInvalidURI, Cause: err}`). `*url.Error`'s message embeds the full input URL, so a malformed `otpauth://` URI — a trailing control character, a bad `%` escape — returned an error whose text contained `secret=...` in the clear. `ParseURI` now reports a fixed `&DetailError{Err: ErrInvalidURI, Detail: ": malformed URI"}` on a parse failure; `errors.Is(err, ErrInvalidURI)` still holds, but the URI and secret never reach the error text. The rest of the package's error paths were audited and already used fixed detail strings.
  - `xkey/cmd/xkey/cmd/oidc.go`'s default (non-`--full`) token display printed a token whole whenever it was 40 characters or fewer — `truncateToken` only truncated past its `maxLen` argument. `truncateToken` now always returns at most an 8-character prefix plus the token's total length (`abcd1234… (1234 chars)`), never the token itself regardless of length; `--full` is unchanged.
  - `sdk/go/client/ssh/rest.go`'s `Import` base64-encoded the passphrase into a `string` field (`restImportRequest.PassphraseB64`) and then called `secure.Wipe([]byte(wire.PassphraseB64))` — a `[]byte(string)` conversion allocates a fresh copy, so the wipe zeroed that copy and left the string (immutable, unwipeable, and the value `encoding/json` actually marshaled) untouched. `Passphrase` is now `[]byte`, matching `sdk/go/client/ssh/mcp.go`'s existing pattern: `encoding/json` base64-encodes a `[]byte` field the same way the manual encoding did, so the wire form and the server's `passphrase_b64` decoder (`pkg/api/rest/secureio.PasswordField`, standard base64) are unchanged; `secure.Wipe(wire.Passphrase)` now zeroes the exact backing array that was marshaled.
  - Files: `xkey/pkg/oath/credential.go`, `xkey/cmd/xkey/cmd/oidc.go`, `sdk/go/client/ssh/rest.go`, `sdk/go/client/ssh/rest_types.go`.
  - Verified by `TestParseURI_MalformedURIDoesNotLeakSecret`, `TestTruncateToken_NeverPrintsFullToken`, `TestRunOIDCToken_TruncatesSecretsByDefault`, `TestRestImportRequest_PassphraseWipeReachesMarshaledBytes`, and `TestRESTKeys_ImportSendsProviderPassphraseAsBase64`; `go vet` and `gofmt` clean on the affected packages; `make secure-analyzer` clean.
