- **gRPC returned raw internal error text to clients; it is now withheld and logged server-side instead, matching REST's behavior since #1139** (#1258). `errorHandlingUnaryInterceptor`/`errorHandlingStreamInterceptor` (`pkg/api/grpc/server.go`) wrapped every non-`status` error as `status.Errorf(codes.Internal, "internal error: %v", err)`, and individual handlers across the package (`mapBarrierError`, `mapPINError`, `service_ca.go`, `service_user.go`, and others) built their own `status.Errorf(codes.Internal, "...: %v", err)`, so a storage path, a backend library message, or a barrier state reached the client verbatim on any of those RPCs. Both interceptors now route every outgoing error through a new `Server.scrubInternalError`: a `codes.Internal` or `codes.Unknown` status, or a plain non-`status` error, has its message replaced with the fixed text `"internal error"` (its original code is preserved), while the original error is logged at `Error` level with the RPC's full method name via the server's existing `slog.Logger`. A status error carrying a client-facing code (`InvalidArgument`, `NotFound`, `PermissionDenied`, and so on) passes through unchanged. Because the scrub happens centrally in the two interceptors that already sit last in every RPC's chain, no individual handler's `codes.Internal` call site needed to change. MCP already withheld internal error text the same way (`pkg/api/mcp/errors_keyops.go`'s `ErrInternal`/`ClientError`, logged by `InvokeMethod` in `pkg/api/mcp/module_support.go`, go-xkms#1118) and required no change.
  - Files: `pkg/api/grpc/server.go`, `pkg/api/grpc/server_test.go`.
  - Verified by new `TestErrorHandlingUnaryInterceptor`/`TestErrorHandlingStreamInterceptor` subtests: a handler returning a leaked-detail `codes.Internal` or `codes.Unknown` status yields exactly the fixed client message while the original detail and the RPC method name are captured in the logger; a `codes.InvalidArgument` status keeps its own message untouched. `go vet` and `go test` clean under `codec_cbor codec_json codec_msgpack tpm_simulator frost` for `pkg/api/grpc`, `pkg/api/mcp`, and `pkg/api/rest`.
