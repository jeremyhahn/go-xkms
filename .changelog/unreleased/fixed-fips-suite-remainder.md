- **The AWS KMS, Azure Key Vault and PKCS#11 backend suites pass under `GODEBUG=fips140=only`.** These backends run the SHA-1 signatures, PKCS#1 v1.5 decryption and SHA-1 RSA-OAEP that the remote KMS or token performs, so the tests' software oracles stand in for that remote party and run outside the local module's enforcement (`fips140.WithoutEnforcement`). A local SHA-1 wrap (Azure `RSA_AES_KEY_WRAP_SHA_1`, PKCS#11 `WrapKey`) is checked to fail with the stdlib's refusal. The AWS KMS nil-options decrypt test checks that the backend asks KMS for `RSAES_OAEP_SHA_256` (part of #23).
