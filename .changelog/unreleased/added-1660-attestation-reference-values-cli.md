- **`xkmsctl attestation reference-values put|get|list|delete` manage the Verifier's reference values.** `put <name> --corim <file> [--repository <ref>]` loads a COSE_Sign1 signed CoRIM (a missing or empty file is refused before any call), `get <name>` and `list` show the records (`-o json` prints the response) and `delete <name>` removes one. Each calls the sdk/go `Client` verb of the same name; xkmsd verifies the CoRIM (go-xkms#1660).
