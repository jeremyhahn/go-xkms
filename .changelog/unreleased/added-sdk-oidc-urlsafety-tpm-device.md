- **`sdk/go/oidc`, `sdk/go/urlsafety` and `xkms.OpenTPMDevice`: the OIDC client core, the URL launch guard and the TPM device opener through the SDK.** v0.48.0-alpha moved the OIDC core to a shared `pkg/oidc` and wired `xkmsctl oidc`, xkey's OIDC commands and GUI services, xkey's AWS sign-in and xkey's TPM probes straight to `pkg/oidc`, `pkg/urlsafety`, `pkg/api/transport` and `pkg/tpm2/tpmdev` -- which the Architecture Gates job forbids (xkey and xkmsctl production code depend on `sdk/go` only). `sdk/go/oidc` re-exports the client side of `pkg/oidc` (templates and flows, `Provider`/`Client`, PKCE, state, DPoP, the loopback callback listener and the token stores) as aliases, `sdk/go/urlsafety` re-exports `ValidateLaunchURL`, and `xkms.OpenTPMDevice` re-exports `tpmdev.Open` with its refusal of the host's hardware TPM inside a test binary. xkey and xkmsctl now import these, and the OIDC credential client types from the existing `sdk/go/transport`; `xkmsctl`'s vault key factors use the existing `sdk/go` storage, key-type, service-backend and `sdk/go/localtpm`/`sdk/go/vaulttoken` re-exports. Exported-API growth, so this is a MINOR release.
