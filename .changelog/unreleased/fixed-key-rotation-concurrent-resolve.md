Key versions: a sign, encrypt or other key operation that runs while the same key rotates no longer fails with `KeyVersionMissingError` for the new version. Key resolution lists the backend keys before it loads the version record, so a rotation completing between the two left a record naming a version the listing had missed. Resolution now lists once more when the record names a version, other than a retired one, that the first listing did not find. Rotation creates the backend key before it records the version, so that second listing always holds it (#1720).
