- **A tenant's first `SignCoRIM` no longer generates a release key on AWS KMS, Azure Key Vault or Cloud KMS.** Those backends name and list keys without the tenant, so the new key was invisible to the tenant, every retry created another remote key, and on AWS KMS each one replaced the shared release-signing key metadata. Provisioning now refuses these backends before generating anything, with a `ReleaseKeyProvisionError` wrapping the new `ErrReleaseKeyBackendUnsupported`; a tenant on them binds a release key it already holds (go-xkms#1956).
