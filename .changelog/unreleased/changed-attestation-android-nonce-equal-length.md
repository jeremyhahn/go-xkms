- **Android attestation nonce tests (#1794)** — `TestVerifyKeyAttestation_NonceMismatch` is now a table test: besides a nonce of a different length, `VerifyKeyAttestation` must refuse with `ErrNonceMismatch` an expected nonce of the challenge's length that differs in its last byte, and one that is a strict prefix of the challenge. A regression that kept only the length check and dropped the constant-time compare now fails a test.
