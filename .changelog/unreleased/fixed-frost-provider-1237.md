- **The standalone FROST key-provider factory could never construct a working backend.** `pkg/xkms/register_frost.go`'s `newFROSTKeyProvider` (registered under `xkms.BackendFROST` for SDK/embedded callers, e.g. `xkms.AutoInitialize`) built its internal PKCS#8 secret store with `pkcs8.Config{KeyStorage: secretStorage}` and no way to ever set `AllowPlaintextKeys`, so the very next step -- provisioning the FROST wrapping key via `seal.EnsurePrivateSealKey` -- failed unconditionally with `pkcs8.ErrPlaintextKeyNotAllowed`. `pkg/server/backend_frost.go`'s `initFrostBackend` (the xkmsd daemon's own FROST wiring, driven by `backends.frost.enabled`) does **not** call this factory -- it resolves `backends.frost.secret_backend` against an already-initialized, already-protected `s.keyProviders` entry (the same `pkcs8`/`software`/`tpm2`/etc. backend every other consumer of that entry uses) -- so xkmsd itself was never blocked from enabling FROST; only the generic registry factory was unusable. `newFROSTKeyProvider` now accepts an `"allow_plaintext_keys"` config key, threaded through to its internal `pkcs8.Config` exactly as `newPKCS8KeyProvider` already does for the standalone `pkcs8` backend -- the same knob, same fail-closed default (`false`), no new secret source invented. With no protected-store source configured, construction still fails closed with the identical typed/sentinel `pkcs8.ErrPlaintextKeyNotAllowed`, never a plaintext store.
  - Files: `pkg/xkms/register_frost.go`.
  - Verified by `pkg/xkms/register_frost_test.go` (`newFROSTKeyProvider` fails closed with `pkcs8.ErrPlaintextKeyNotAllowed` on both a nil and an empty config; with `allow_plaintext_keys: true`, two providers built through the factory complete a full 2-of-2 trusted-dealer keygen, nonce generation, signing, aggregation and verification round trip) and `pkg/server/backend_frost_test.go`'s new `TestInitializeBackends_FrostWithPKCS8SecretBackend_StartsCleanly` (the real `Server.initializeBackends` -- the same call `Server.New` makes -- with `backends.pkcs8` and `backends.frost` both enabled and `secret_backend: pkcs8`, proving xkmsd starts cleanly with FROST enabled).
