- **Web console User Detail view (#1443)** — `#/users/detail` looks one user up by username through `GET /api/v1/users/{username}` (`users.get` in sdk/ts) and shows the read-only record: the numeric user ID the N-factor endpoints key on (as the string the API returns), display name, roles, enabled state, created time and last login (or "Never"); a 404 reads "User not found". The nav entry sits under Identity & Access and shows only with `users:read`.
