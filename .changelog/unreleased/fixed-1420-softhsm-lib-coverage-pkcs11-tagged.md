- **`make coverage-pkcs11-tagged` runs on SoftHSM 2.7 on hosts with an older SoftHSM.** The new `scripts/softhsm-lib.sh` prints the module the PKCS#11 suites load: the installed one when `softhsm2-util` reports 2.7.0 or newer, otherwise the pinned release built once by `scripts/build-softhsm.sh` into `~/.cache/go-xkms/softhsm-<version>` without root and reused after. The target exports it as `SOFTHSM2_LIB`, so the gate no longer fails on the distribution SoftHSM 2.6.1, which cannot report PKCS#11 tamper (#1418, #1420).
