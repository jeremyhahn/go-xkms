- **go-qrdb v0.28.1-alpha.** Every module moves to go-qrdb and its `sdk/go` v0.28.1-alpha. go-qrdb v0.27 serves leases on a standalone node, so a clustered-config xkmsd advertises its API endpoints on a standalone qrdb node too, and the OIDC credential locker takes a real lease there (it keeps its in-process fallback for a backend that refuses leases). The init-ceremony and audit consequences of v0.28 have their own entries. xkms's object scope rule (`pkg/scope`) still lets a system-tenant identity, or a request with no identity, address every tenant's shared and service objects; go-qrdb v0.28 no longer grants that lift, and the decision for xkms is #1406.
