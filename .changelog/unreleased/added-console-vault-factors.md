- **Web console: manage your password-vault factors and recover a locked vault.** The Passwords view gains *Vault factors* (list your factors; add a passphrase, change one in place, remove a factor -- the server's refusal to remove the last one is shown) and *Use recovery code* on a locked vault (recovery code plus a new passphrase; the next code is shown once). The TS SDK types the vault status's `recovery` factor (`PasswordVaultFactorInfoType`). Covered by vitest component tests and a Playwright mock-API spec (`e2e/password-vault.spec.ts`).
