- **First-use release-key provisioning works on non-extractable backends.** When a backend's `GenerateKey` returns no private key (AWS KMS, Azure Key Vault, GCP KMS), the keystore now reads the public key from the backend's signer instead of failing with `ErrPublicKeyExtraction` after the remote key exists, so `SignCoRIM` and `SignImage` no longer report `ReleaseKeyProvisionError` on those backends (go-xkms#1956).
