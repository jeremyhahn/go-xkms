- **A failed SSH profile rename or move no longer leaves a duplicate** -- renaming a profile or moving it to another folder stores it under its new ID before deleting the old record; when that delete failed, both records stayed behind and the error said only that the delete failed. The new record is now removed again, so the store is left as it was and the rename can be retried; if that cleanup fails too, both failures are reported. File: `pkg/ssh/profile/store.go`.
