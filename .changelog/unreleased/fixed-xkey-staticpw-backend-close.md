- **xkey releases the file-backed static password store when it closes** -- the password store left its storage backend with the caller, but the `password` commands, `backup`, `extension serve --no-barrier`, the FIDO2 daemon and the GUI's no-barrier path kept only the store, so closing it never closed the backend: each open leaked file descriptors and, on the Pebble engine, the GUI's store stayed locked after shutdown. The CLI's store now owns its backend and closes it with the store, also when construction fails; `extension serve` closes its store on exit; the GUI keeps the backend and closes it after the store. Files: `xkey/cmd/xkey/cmd/password.go`, `extension_serve.go`, `xkey/pkg/gui/app.go`.
