- **Test helpers no longer reach production binaries** -- the SDK package `sdk/go` re-exported the PKCS#11 mock module and conformance suite (`pkg/testing/pkcs11test`, which imports package `testing`) and the TPM simulator helpers (`pkg/tpm2/tpm2test`), so every binary built on the SDK linked them. They move to the new test-only package `sdk/go/xkmstest`: `xkms.NewPKCS11TestModuleFactory`, `xkms.NewPKCS11TestSuite` and `xkms.EnrollSimulatorPlatformSRK` become `xkmstest.NewPKCS11ModuleFactory`, `xkmstest.NewPKCS11Suite` and `xkmstest.EnrollPlatformSRK`. The throwaway simulator IAK certificate minter has a production caller (the ACME client's simulator device mode), so it moves out of `tpm2test` into `pkg/acme/client/service.ProvisionSimulatorIAKCertificate`, and `xkms.ProvisionSimulatorIAKCertificate` is removed. The new `make check-test-helpers` (`scripts/check-test-helpers.sh`, tested by `make test-scripts`) walks every module's production packages with `go list -deps`, under the default and the full feature tags, and fails on any production import of a test-only helper.
