- **go-enclave v0.11.1-alpha and go-qrdb v0.58.5-alpha (HeadSignerProvider, image-signed vlog append).** Protected buffers are `enclave.ByteAccess` (Freeze on `enclave.Freezer`); a barrier password change proves the current password first, so the xkey `BarrierService.ChangePassword` takes the current and new password; the SDK Shamir share is `ShamirProtectedShare`; each tenant is its own SPIFFE trust domain and only the cluster trust domain is pinned.
- **TPM2 simulator access is serialised.** One command/response pair runs on the TPM2 transport at a time, and seal and unseal run one at a time, so concurrent callers no longer read each other's responses or exhaust the simulator's session and object slots (go-enclave v0.11.1 concurrent provider conformance).
- **The tenant metadata store forwards compare-and-swap.** The barrier wrapper handed to go-qrdb passes `CompareAndSwap` through, so `UpdateTenant` commits plan, quota and entitlement changes against the record it read instead of refusing with `ErrTenantUpdateNotAtomic`.
