- **The Android attestation status list refuses a response its own caching metadata already expired (#1721).** `HTTPStatusList` applies RFC 9111 §4.2 exactly, `freshness_lifetime > current_age` with the lifetime per §4.2.1 and the age per §4.2.3, the round trip included without an Age field: a response with `max-age=0`, an `Expires` in the past or invalid, or an invalid `max-age` is stale, so it is revalidated once and refused if still stale, where it was used. A response with no max-age or Expires is still used once and never cached. RFC 9111 is copied to `docs/references/rfc-9111.txt`.
