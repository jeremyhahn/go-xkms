- **xkey pairing bridge wipes secret results** -- `remote.decrypt`, `remote.deriveKey`, `remote.activateCredential` and `remote.importSharedKey` results now zero the plaintext, ECDH shared secret, recovered credential secret or exported symmetric key material with `secure.Wipe` as soon as the response is encoded, including when the audit write fails, and the pairing message loop wipes the encoded response once the Noise session has encrypted it. The phone-initiated listeners (`xkey device listen`, the TCP pairing server and the BLE peripheral) likewise wipe the encoded bridge result, the decrypted request and the response plaintext once Noise has encrypted the response. The wire format is unchanged (#623).
