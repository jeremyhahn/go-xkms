A key used while it was being rotated could fail with `version N of key "K" has no backend key "K--vN"` (`*xkms.KeyVersionMissingError`). Resolving a key listed the backend keys and then read the version record, so a rotation recorded between the two named a version the listing did not hold. A rotation creates its backend key before it records the version, so a resolve that reads a record naming a version its listing lacks now lists the keys again. A recorded version whose backend key is really gone is still refused (DS-4012).
