- **Key-version records are go-qrdb DAO entities, written as xkms's service principal** -- `keyversion.NewStore(daos)` now takes a `*qrdbsdk.DAOFactory` serving the `keyversion` database (`keyversion.DatabaseName`, SDK `KeyVersionDatabase`) instead of a `storage.Backend`, and stores one `key_versions` entity per rotated key, named `{tenant}/<backend>/<keyID>`. xkmsd opens the database on its datastore, whose `datastore.WithCallContext` runs the records' reads and writes as the embedded node's `xkms` service principal. `compose.BuildKeyVersionStore(daos)` replaces the storage form, and `compose.Databases` always names the key-version database. `datastore.DatabaseKVStore` now scopes before it ensures, so a client with no database plane is refused with `*datastore.ErrDatabaseScope` instead of panicking. `compose.StorageKeyVersions` and `keyversion.ErrNilStore` are gone (`keyversion.ErrNilDAOFactory` replaces the latter). Records written under the old `key-versions` storage are not read.
