- **CI adopts ci-template v1.29.5 (rulings 220(5), 226(15), 239(8), 255(10)/(11)(c), 261(c), 262(a)).** v1.29.0: the integration image's CI tag covers the Alpine package index. `scripts/apk-index-sum.sh`, the handbook template's v1, reads the package-index checksum of the devcontainer's base image into `APK_INDEX_SUM` in every job that names the integration image (ci-images, image, integration, soak). `make -s it-image` hashes it, and `make docker-build-it` passes it as `--build-arg APK_INDEX_SUM`. go-xkms's base is the pinned Debian `GO_IMAGE`, which has no apk, so the value is the constant `none` and the Dockerfile is unchanged. An unset value, as on a local or lane-verify build, leaves the tag the tree's alone. v1.29.1: the lint-gates job runs `make lint-gates` without `-k`, so the first failing gate ends the step and the job instead of the other gates running on after it. v1.29.2: comments only, the note that a path-gated CUSTOMIZE job needs the image job and tests an image job output in its `if:`. v1.29.3: a repository has one schedule run at a time (its concurrency group is `schedule-<repository>`), and a new `schedule-guard` job holds a schedule run's bigdisk jobs (ci-images, image, lint-gates, integration, soak, and the CUSTOMIZE jobs through ci-images) off while a main push run is in flight; CI Gate then posts `skipped`, and fails when the guard cannot read the Actions API. v1.29.4 and v1.29.5: every job that can build a CI image first probes the runner's Athens (`DEVCACHE_GOPROXY`, 5 s) and, when it answers, exports `GO_BUILD_PROXY=<Athens>|https://proxy.golang.org|direct`, which `scripts/ci-registry.sh`'s `make docker-build-*` passes quoted as `--build-arg "GO_BUILD_PROXY=..."`. `GO_BUILD_PROXY` defaults to empty, so a local build no longer forwards the caller's `GOPROXY` and takes the Dockerfile default. `scripts/in-toolchain-image.sh` v4 bounds the stage container's memory by the job slot's cgroup limit (8g with none, `IN_IMAGE_MEMORY` overrides) with no swap, and a bridge stage's `GOPROXY` puts Athens first; its `/var/tmp` scratch volume (#1733) is unchanged.
