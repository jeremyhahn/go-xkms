- **A tenant status can no longer be set or used as a list filter.** go-qrdb v0.51.0-alpha carries no tenant status, so a status kept in go-xkms was never enforced (a "suspended" tenant still authenticated). `UpdateTenantStatus` and a `ListTenants` status filter now return `*admin.UnsupportedFieldError{Field: "status"}` (`errors.Is(err, admin.ErrTenantStatusUnsupported)`) before any storage read; the admin REST API answers 400 with problem type `urn:trusted-ca:error:tenant-status-unsupported` and gRPC answers InvalidArgument (go-xkms#2092). The gRPC, MCP and QUIC client adapters return the same typed error for a status set or filter without sending a request, and the admin GUI API answers 400 `TENANT_STATUS_UNSUPPORTED` instead of 500.
