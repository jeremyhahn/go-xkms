- **Tenant status is refused, set or filtered.** The pinned go-qrdb v0.51.0-alpha has no tenant status, so `UpdateTenantStatus` and a `ListTenants` status filter now return `*admin.UnsupportedFieldError{Field: "status"}` (`errors.Is` `admin.ErrTenantStatusUnsupported`) before any storage read, and the tenant record is not changed. `PUT /api/v1/tenants/{id}/status` answers 400 with problem type `urn:trusted-ca:error:tenant-status-unsupported`; the REST client maps it back to the typed error, the REST and QUIC clients refuse a status filter without sending a request, and gRPC answers InvalidArgument.
