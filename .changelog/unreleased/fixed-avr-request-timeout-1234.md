- **The AVR backend's `RequestTimeout` now bounds only a call's own exchange with the device, not the time it waits behind other callers** (#1234). `Identity`, `Health`, `GetKey` and `AttestKey` started their per-call timeout before acquiring the wire mutex that serializes every command on the one device link. Under enough concurrent callers, the queue wait used up the deadline, and late callers failed with `context deadline exceeded` even though the device answered every request it received. The deadline now starts inside the lock. The caller's own context still bounds the whole call.
  - Files: `pkg/backend/avr/backend.go`, `pkg/backend/avr/attestation.go`.
  - Verified by `TestRequestTimeoutExcludesQueueing`, where a queue longer than the timeout still succeeds and every exchange fits within it.
