- **Personal password entries no longer reveal names or folders to the tenant key.** A personal entry's ID is now `HMAC-SHA-256(K, lower(folder/name))` (128 bits, 32 hex characters) with `K = HKDF-SHA256(DEK, "xkms/staticpw/personal/v1/names")`, keyed per user, instead of the public xxhash of the name and folder; personal folder markers and aliases are stored under the same MAC of their text, with the folder path in the DEK-sealed value. Holding the tenant barrier key now shows only that a user has a vault, how many personal objects it holds, their sizes and when they change (documented in `docs/password-vault/architecture.md`). Shared, system and xkey-local stores keep the public `GenerateID` scheme. **No migration:** personal vaults written before this change are not read back under the new keys; the only deployment holding them (the burn-in node) is being rebuilt from zero.
