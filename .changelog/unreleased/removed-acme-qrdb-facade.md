- **`pkg/acme/qrdb`, the ACME subsystem's own go-qrdb client facade, is removed** -- its `Service`/`Provider`, `New`/`WithConfig`/`WithKVStore`, `NewKVStoreAdapter`, `MemoryKVClient`/`NewTestService`, `ShutdownManager`, `RaftMetricsCollector`, error codes and predicates are gone, together with the SDK's `CAQRDB*` re-exports in `sdk/go/acme`. ACME storage is built from the injected go-qrdb DAO factory: xkmsd uses `objstore.NewFactory(ds.DAOFactory())` over the server datastore (`objstore.NewTenantAwareFactory` for the tenant-aware form). `admin.NewTenantAwareAdminService` and `client.WithQRDB` take the go-qrdb SDK client directly through the new `admin.QRDBClient` interface (`KV`, `Users`, `Roles`), which `*qrdbsdk.Client` satisfies; not-found is matched with `qrdbsdk.IsErrorNotFound`. `TrustedCA.QRDBService` is renamed `QRDBClient`.
