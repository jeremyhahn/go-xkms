- **CGO-free PKCS#11 key provisioning.** `module.ProvisionECKeyPair` creates a P-256 or P-384 key pair on a remote-mode token with exactly the `CKA_LABEL` and `CKA_ID` the loaded module will find it by, by driving the module in process rather than writing token records by hand; it initializes a new token with the SO PIN and is idempotent. `module.NewRemoteStorage` exposes the token store a remote-mode module reads. Both are re-exported in `sdk/go/signserver`.
