- **`xkey tpm srk enroll` enrols the Platform SRK from the CLI, and `xkey fido2 --backend tpm2` supplies its auth.** After `xkey tpm install`, `xkey tpm srk enroll` enrols the Platform SRK under the user PIN (the SO PIN may be empty when install ran without `--auth`); a second run reports "already enrolled" and exits 0. `xkey fido2 --backend tpm2` now verifies the user PIN against the Platform SRK and uses it as the SRK auth, instead of failing with `Platform SRK unavailable: TPM_RC_HANDLE`. Both take the PIN non-interactively with `--pin-file <path>` (first line) or `--pin-stdin`, or prompt with no echo at a terminal; neither accepts a PIN value on the command line (rulings 993, 994).
