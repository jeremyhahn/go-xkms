- **Credential-free runs resolve first-party modules publicly, and `make check-public-literals` reads its rules from `RELEASABILITY_PATTERNS`.** With no module credential source, the Makefile and the integration compose files pass the caller's `GOPRIVATE` through without a first-party default, so first-party modules resolve from proxy.golang.org and sum.golang.org like any other. The credential-dependent default stays: when a credential source is set and `GOPRIVATE` is empty, the Makefile still sets `GOMODAUTH_GOPRIVATE` to the first-party module path, and the compose files still fall back to it when `GITEA_HOST` is set. `scripts/check-public-literals.sh` no longer carries its rules in the public tree: it reads `class<TAB>regex` lines from `RELEASABILITY_PATTERNS`, the private text ci.yml's Releasability step reads, fails on an unusable line by number without quoting it, fails when the variable is set but holds no rule, and prints a notice and passes when it is unset (DS-7983).
