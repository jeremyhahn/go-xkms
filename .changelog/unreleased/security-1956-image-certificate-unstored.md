- **Image signing no longer stores its code-signing certificate in the CA's certificate store.** The certificate is named after the caller's repository and the store is keyed by common name alone, so two tenants signing the same repository replaced each other's certificate, and a repository named after an existing CA or TLS certificate replaced that certificate. `SignImage` now issues through the new `CA.SignCSRUnstored`, which returns the certificate with the signature without storing it; the issuing tenant is still recorded by serial for revocation (go-xkms#1956).
