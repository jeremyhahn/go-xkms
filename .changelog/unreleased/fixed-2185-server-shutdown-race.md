- **xkmsd shutdown drains in-flight requests before closing the datastore** -- `Server.Shutdown` stopped the embedded qrdb node, which serves every transport, only after it had dropped the shared datastore and storage backend, so a request still running (the first one builds the module REST binding through the datastore) could dereference a nil datastore or race the close. The node now stops and drains its transports first; the datastore and storage handles are atomic, and a caller that reaches for the datastore after shutdown gets `ErrNoDatastore` (go-xkms#2185).
