SSH: the remote signers (REST, gRPC, MCP) implement `ssh.AlgorithmSigner` and carry the signature algorithm on the wire (`algorithm` in the REST and MCP sign request, `SSHSignRequest.algorithm` on gRPC), so an RSA key held by xkmsd signs with `rsa-sha2-256` or `rsa-sha2-512` (RFC 8332 §3) and authenticates to OpenSSH 8.8+ servers, which refuse `ssh-rsa` (SHA-1). The server refuses an algorithm the key type does not allow, or a signer that cannot select one, as a bad request (#1755).
