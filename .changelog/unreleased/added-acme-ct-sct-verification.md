- **ACME CT verifies every SCT and is enabled per log** — `pkg/acme/ct` verifies each SCT's RFC 6962 §3.2 signature over the precert_entry (including Precertificate Signing Certificate chains) and refuses a wrong log ID, an unsupported algorithm or a bad signature with typed errors. Each log is configured with its URL, public key, a log ID derived from the key and an `Enabled` flag; CT is off when no log is enabled, and invalid or duplicate logs are refused. `MockLogSubmitter` moved to test code.
