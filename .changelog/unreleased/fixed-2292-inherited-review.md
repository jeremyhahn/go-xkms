apimodule: `NodeCORS` falls back to the module's `WithCORS` policy when no REST resolver is set or it yields none, so node auth refusals still carry the CORS headers (#2296).
webauthn: a stale first-credential claim cleanup deletes only the claim generation it read, never a replacement claim an invitation retry committed in between (#2296).
test/integration/web: the web fixture configs raise `auth.session.login_rate_per_min` to 6000 like the webauthn-browser fixture, so serial ceremonies from one address are not throttled; the passkey node suite provisions operators by administrator invitation instead of anonymous sign-up (#2296).
