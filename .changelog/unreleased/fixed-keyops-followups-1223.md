- **Four follow-ups from the key-ops service-layer and nonce-guard work (#1218, #1216, #1201, #1220) are closed.** `transport.CopyKeyRequest` and MCP's `CopyKeyParams` lose `KeyType`, `KeySize` and `Curve`, which `XKMSService.CopyKey` has always ignored — the copy takes those attributes from the source key. They are also gone from the xkmsctl `key copy` flags (`--key-type`, `--key-algorithm`, `--key-size`, `--curve`) and the TypeScript SDK's `CopyKeyRequest` mirror, which also drops `key_size`, `curve`, `hash` and `aes_key_size` so it matches the REST wire type exactly rather than describing fields REST has never had. A refused AEAD nonce reuse (`aead.ErrNonceReuse`) and a full nonce tracker (`aead.ErrNonceTrackerFull`) — from both the generic `Encrypt` RPC and `WrapKeyByID`'s AES-GCM wrap — used to fall through every transport's catch-all as a `500`/`Internal`/JSON-RPC internal error; a new shared `apierrors.AEADSentinelClasses` table classifies them to `ClassAlreadyExists` / `ClassResourceExhausted`, consulted by gRPC's and MCP's `mapKeyOpError` and mirrored in REST's `keyOpSentinelStatus`, so a reuse is `409`/`AlreadyExists`/the MCP duplicate code and a full guard is `503`/`ResourceExhausted` on every transport. The AWS KMS, GCP KMS, Vault Transit and paired-phone symmetric `Encrypt` paths silently dropped a caller-supplied nonce because those backends' remote encryption service manages its own; they now refuse it outright with a new `backend.ErrCallerNonceNotSupported` sentinel, classified as `ClassInvalidArgument` via the existing `apierrors.ImportExportSentinelClasses` table — `400`/`InvalidArgument`/MCP Invalid params. `CopyKey` re-validates the copied key's RSA modulus against the 2048-bit floor with `types.ValidateRSAKeySize` directly (rather than the source attributes' own, broader `Validate()`, which #1220 found rejected copies of legitimately partial attribute sets) before ever touching export or import, refusing a sub-2048 source with the same `*xkms.ErrValidation` path every other key-op validation failure uses.
