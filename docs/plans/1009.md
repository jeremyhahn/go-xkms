# Plan 1009: WebAuthn browser registration 500 (ruling 1009)

## Objective

main's Integration job fails 7 Playwright tests in
test/integration/webauthn-browser (registration finish answers 500). At
start-up qrdb refuses the default volume pool because
`EmbeddedNodeStorageConfig` hands it `filepath.Join(cfg.Datastore.Path,
"tenant-volumes")` unresolved, and the harness sets a relative
`datastore.path`. Fix it in xkmsd: resolve the datastore path to an
absolute path before qrdb sees it.

## Slices

1. Test first (`pkg/embeddednode`): `EmbeddedNodeStorageConfig` with a
   relative datastore path and the seal enabled yields an absolute
   default volume pool path equal to `Join(Abs(path), "tenant-volumes")`,
   and an absolute raft data dir. Fails at main.
2. Fix: resolve `cfg.Datastore.Path` with `filepath.Abs` once in
   `EmbeddedNodeStorageConfig` and use it for the raft data dir and the
   volume pool; if Abs fails, log it and keep the configured path.
3. Changelog entry `.changelog/unreleased/fixed-1009-volume-pool-abs-path.md`.

## Out of scope

- The Playwright specs and their config.yaml (unchanged).
- `make integration-test-webauthn-browser` needs Docker; CI runs it.
