# Epic #2084: xkey-sdk-only (docs/SPEC.md:180)

## Objective

xkey reaches go-xkms through `sdk/go` only: no xkey file imports root
`pkg/*`. A surface `sdk/go` lacks is re-exported from `sdk/go` (with a test
asserting the re-export), never imported raw.

## Slices on row/2084-xkey-sdk-only (PR #2117), in order

1. truststore through `sdk/go/truststore`
   (plan: docs/plans/xkey-sdk-only-truststore.md; PR #2108 merged in).
2. oidc through `sdk/go/oidc` (docs/plans/xkey-sdk-only-oidc.md; PR #2107
   merged in). Tests: sdk/go/oidc re-export assertions.
3. pairingproto through `sdk/go/pairingproto`
   (docs/plans/xkey-sdk-only-pairingproto.md). Tests: sdk/go/pairingproto
   re-export assertions, FlagFirstFragment.
4. fido2/authenticator through `sdk/go/fido2/authenticator`
   (docs/plans/xkey-sdk-only-fido2-authenticator.md). Tests: re-export
   assertions.
5. pkg/types names through the `sdk/go` root package
   (docs/plans/xkey-sdk-only-types.md). No new tests: no behaviour change.
6. Merge origin/main; gofmt the test imports. Gates: xkey `make test`,
   `make test-sdk-go`, xkey `make integration-test-{cli,fido2,phone,password}`.

## Out of scope (later slices of this epic)

- The other root `pkg/*` imports in xkey tests (pkg/storage,
  pkg/testing/fipstest, pkg/xkms, pkg/tpm2, pkg/ca, pkg/auth and the rest).
- Wiring standalone xkey through `NewEmbeddedClient` (TPM, SSH, password
  store, CA verbs, GUI connection).
