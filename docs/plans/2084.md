# Row #2084: xkey-sdk-only (docs/SPEC.md:180)

## Objective

xkey keeps every feature in both modes (standalone and remote) and reaches
go-xkms through sdk/go only: no non-test xkey file imports root pkg/*, xkey
tests move to the sdk/go surface, and standalone xkey goes through
NewEmbeddedClient (sdk/go/embedded.go). One row = one branch
row/2084-xkey-sdk-oidc = one PR #2107 (ruling 573).

## Done on the branch

- Folds: PR #2108 head 08e694e1a and PR #2117 head 3316e7efe are ancestors
  of the branch (merged by earlier lanes).
- No non-test xkey file imports root pkg/*.
- Test imports moved to sdk/go, one plan file per group: types, storage,
  truststore, oidc, bootstrap, pairingproto, fido2 authenticator,
  fido2 keybackend, fipstest, pkg/xkms, pkg/auth, fido2 uhid/virtualdevice,
  pkg/autofill (sdk/go gains TOTPPolicyAuto; TestReexport_AutofillPolicyNames).

## Remaining slices, in order

Each slice adds the sdk/go alias it lacks first (test commit for it, then
feat), then moves the imports (refactor). Groups still imported by xkey tests:

1. pkg/testutil/vaulttest, vaulttest/vaultservice, barriertest, secrettest,
   pkg/testing/enclavetest (cmd, gui/services, config, usb tests).
2. pkg/tpm2, pkg/tpm2/store, pkg/tpm2/tpm2test, pkg/localtpm (cmd pin test,
   pairing tests, test/integration/password).
3. pkg/ca, pkg/ca/provider (cmd CA tests).
4. pkg/oidc/credential, pkg/attestation/android,
   pkg/backend/pkcs11, pkg/pivcert.
5. xkmsd_harness_test.go: pkg/api/grpc, grpc proto, pkg/api/rest,
   pkg/certstore, pkg/crypto/spki, pkg/testutil (a server harness; may need
   an sdk/go test-server surface, a separate sdk/go row if so).
6. Standalone wiring through NewEmbeddedClient: local TPM
   (tpm_policy.go), SSH (ssh.go), file password store (password.go), CA
   verbs (ca.go) and the GUI connection (connection_service.go) gain an
   embedded path, with a test per feature in each mode. Open decision:
   NewEmbeddedClient (sdk/go/embedded.go:94) builds a software backend only
   (EmbeddedServiceConfig: KeyDir, BackendName, KeyStorage), while the GUI's
   initLocalKeyStore (xkey/pkg/gui/app.go:1385) already reaches sdk/go via
   AutoInitialize + NewEmbedded with TPM2/PKCS#11 backend configs. Moving it
   onto NewEmbeddedClient as-is would drop those backends, which the row
   forbids; EmbeddedServiceConfig first needs backend configs and a datastore
   (an sdk/go surface change, per SPEC.md:180 its own sdk/go row).
7. Mark the row shipped in docs/SPEC.md.

## Out of scope

Anything under pkg/; go.mod/go.sum changes beyond tagged pins; removing any
xkey feature or mode.
