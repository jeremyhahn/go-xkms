# Plan: SPEC row optee-sealed-blob (#2191)

## Objective

Ship SPEC row `optee-sealed-blob` (docs/SPEC.md): the codec
`pkg/enclaveprovider/opteeblob` (`DeriveKey`, `Seal`, `Unseal`) for the
sealed blob of trusted-firmware's OP-TEE TA, a tagged COSE_Encrypt0 under
A256GCM with the TA UUID as external_aad, keyed by HKDF-SHA-256 of the TA's
`PTA_SYSTEM_DERIVE_TA_UNIQUE_KEY` output. It refuses a bad version, header,
algorithm, truncation, encoding, key length or tag with typed errors and
recomputes `testdata/vectors.json`.
