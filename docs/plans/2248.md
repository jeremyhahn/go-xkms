# #2248: keep test unix socket paths under the sun_path limit

Lane mf2248a, main-fix (ruling 742). Base HEAD 81a1a5fb3 (GitHub main).

## Cause

Race Detector on main (run 43982318997) runs on a self-hosted pool whose
TMPDIR is /home/runner/_work/_temp. t.TempDir() under it, plus a long test
name and a socket file name, passes the 108-byte sun_path limit, so
`bind: invalid argument` in cmd/xkmsctl, cmd/xkmsd, pkg/api/unix,
pkg/server, pkg/ssh/agent and pkg/ssh/connect.

## Fix

- internal/testtmp.Short(run func() int) int creates a short directory
  /tmp/xkNNNN (4 random base-36 characters; falls back to os.MkdirTemp under
  os.TempDir()), sets TMPDIR to it for the run, then restores TMPDIR and
  removes the directory. os.MkdirTemp's 10-digit suffix was not enough:
  pkg/api/unix TestPeerCredentialTransport_ServerHandshakeUnreadableCredentials
  came out at 109 bytes under /tmp/xk1003153494.
- Each of the six packages gets testmain_test.go with
  `func TestMain(m *testing.M) { os.Exit(testtmp.Short(m.Run)) }`
  (cmd/xkmsd already has a main_test.go, hence the file name).
- No production code changed; no test weakened.
