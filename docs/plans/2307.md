# Plan: #2307 bound apt fetches and Integration steps

## Objective

A hung apt fetch during an image build (the bake-hang root cause, ruling 978)
must fail its step, not stall the CI run for the job's 180-minute limit.

## Slices

1. ap2307a (done): every `apt-get` RUN in every Dockerfile runs under
   `timeout` (300 s; 600 s for `playwright install --with-deps`), and every
   step of the Integration job in `.github/workflows/ci.yml` has its own
   `timeout-minutes` (unmeasured, conservative values).
   Tests: `internal/buildgates/apt_timeout_test.go` real-tree tests (fail at
   e0d8ce46, pass at the tip) plus a CanFail test for the checker.
2. ap2307c / af2444 (done): merge current main into the row branch; the
   buildgates tests re-check every Dockerfile main added.

## Out of scope

- Measuring step durations to tighten the `timeout-minutes` values.
- Timeouts on jobs other than Integration.
- apt mirror or proxy changes.
