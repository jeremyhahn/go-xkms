# Plan: row 1763, pkcs11 module test timeout

## Objective

The `test/integration/pkcs11/module` package took 485 s at normal load and
went past the old 10m (600 s) `-timeout` on a loaded bigdisk runner, where it
timed out mid-fsync rather than hanging. The row raises the Makefile default
`PKCS11_TEST_TIMEOUT ?= 20m` so that every pkcs11 integration target, which
all pass `-timeout $(PKCS11_TEST_TIMEOUT)` to `go test`, has headroom on
loaded runners. It changes no test and adds no retry or skip.

## Slices

1. Makefile `PKCS11_TEST_TIMEOUT` 10m -> 20m with changelog entry
   `.changelog/unreleased/fixed-1763-pkcs11-module-test-timeout.md`
   (commit 68772f46e). No new test: the change is a CI time budget.
2. Verify-ready pass (this plan): show the value reaches `go test`, run the
   pkcs11 unit packages and `make lint`.
