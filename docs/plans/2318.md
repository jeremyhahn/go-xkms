# Plan: #2318 in-house pins at the latest tag or held with a written reason

## Objective

Every in-house module go-xkms requires (root, sdk/go, web/desktop, xkey)
sits at its latest published tag, or is held below it with the reason in
the commit that holds it.

## Slices

1. Bumps and holds (done in the branch's first commits): go-frost,
   go-codec, go-xkms/sdk/go bumped; go-truststrap and go-luks2 held
   (their latest tags need a go-enclave the tree cannot take yet).
   Tests: the existing build, vet and unit gates on all four modules.
2. Red head fix (this slice): reproduce the failing
   `Devcontainer image [lint, gosec, build, test]` job's steps with
   their Makefile targets, fix the cause on this branch, merge main.
   Tests: the failing target, unit tests of the touched packages.

## Out of scope

- Releasing the held modules' upstream fixes (go-enclave v0.10/v0.11).
- Any code change beyond what a bump forces.
