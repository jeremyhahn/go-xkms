# Plan 2520: go-enclave v0.11.1-alpha with the dependency releases built on it

CA m2520 (unblocks go-luks2 #212).

## Objective

Lift the go-enclave v0.8.0-alpha `replace` ("held") in the four modules
(root, sdk/go, web/desktop, xkey) and move to go-enclave v0.11.1-alpha with
the dependency releases built on go-enclave >= v0.10, then migrate the
go-xkms callers to the new APIs with no behaviour change.

## Slices

1. Dependency bump (lane mf2520b, done as a wip commit; does not build yet).
   go-enclave v0.11.1-alpha, go-luks2 v1.0.3-alpha, go-objstore v0.9.1-alpha,
   go-truststrap v0.7.1-alpha, go-qrdb + go-qrdb/sdk/go v0.58.2-alpha, and
   go-quicraft v0.24.3-alpha (go-qrdb v0.58.2-alpha requires it; v0.24.2-alpha
   is refused by go get). With go-qrdb v0.51.0-alpha kept (measurement A), the
   build fails inside go-qrdb v0.51.0-alpha itself, so the go-qrdb bump is required.
2. go-enclave caller migration: `*enclave.MemoryEnclave` becomes
   `enclave.ByteAccess` (an interface: `Handle` plus `WithBytes`, `EqualTo`),
   and `NewMemoryEnclaveSized` becomes `NewMemorySized` (Freeze through
   `enclave.Freezer`). Packages: pkg/pintpm2, pkg/luks, pkg/storage/sealed,
   pkg/trust/bootstrap, cmd/xkmsctl, xkey/pkg/usb, plus test doubles.
   Tests: the existing unit tests of each package, updated to the new types.
3. go-qrdb sdk migration: in v0.58.2 the embedded constructors moved out of
   the sdk root: `NewMemoryStorage`/`NewPebbleStorage` go to `sdk/go/storage`,
   `NewFastStateMachine` to `sdk/go/statemachine`, `NewLocalBackend` to
   `sdk/go/backend`, and `ServerOption` to `sdk/go/server`. Packages:
   pkg/storage/qrdb (factory.go), pkg/testutil (firstbootnode.go).
   Tests: pkg/storage/qrdb and pkg/testutil unit tests.
4. Gates: build, vet, tagged root build, make lint, make fmt-check in each module.

## Out of scope

Behaviour changes, other dependency bumps, CI files.
