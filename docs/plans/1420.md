# Plan: #1420 SoftHSM 2.7 in the lane-verify environment (ruling 991 (3))

## Objective

`make coverage-pkcs11-tagged` must run on SoftHSM 2.7.0+ (the minimum that
reports PKCS#11 tamper, go-xkms#1418) everywhere, including the lane-verify
image, which ships the distribution SoftHSM 2.6.1 and has no root.

## Slices

1. test(softhsm): `test/scripts/softhsm-lib.test.sh`, wired next to
   `softhsm-pin.test.sh`. With stubs on PATH it proves `scripts/softhsm-lib.sh`
   - prints the system libsofthsm2.so when `softhsm2-util --version` is 2.7.0+;
   - builds the pinned release into the user cache and prints that library
     when the system reports 2.6.1;
   - reuses a cache build that is already there without rebuilding.
2. fix(softhsm): `scripts/softhsm-lib.sh` and the coverage-pkcs11-tagged
   recipe exporting `SOFTHSM2_LIB=$$(scripts/softhsm-lib.sh)`.
   - The cache defaults to `$HOME/.cache/go-xkms/softhsm-<pinned version>`
     (`SOFTHSM_CACHE` overrides); the build is `DESTDIR=<cache>
     scripts/build-softhsm.sh /usr` into a temporary directory renamed into
     place, so no root is needed and a failed build leaves no cache.
   - Build output goes to stderr; stdout is only the library path.
   - internal/softhsmtest already honours SOFTHSM2_LIB and points
     SOFTHSM2_CONF at a per-test config, so the cache build never reads
     /etc/softhsm.
3. Codex round 1 (ruling 1000): test(softhsm) adds two concurrent cold-cache
   invocations (one build, module never removed under either) and a relative
   `SOFTHSM_CACHE` (absolute path and DESTDIR); fix(softhsm) resolves the
   cache to an absolute path and holds `flock` on `<cache>.lock` across the
   recheck, build and publication.

## Out of scope

- Workflows, docs/SPEC.md, internal/softhsmtest candidates, go.mod/go.sum.
- The lane-verify image itself (claude-agents
  scripts/factory/variants/go-xkms.Dockerfile:27 installs distro softhsm2);
  with this change the gate no longer depends on it.
- Other PKCS#11 targets (integration tests run in images built with
  scripts/build-softhsm.sh).
