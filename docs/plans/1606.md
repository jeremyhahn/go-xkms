# Epic #1606 ota-image-keys: landing PR #2099

## Objective

Land PR #2099 (rulings 950, 951 (3)): main merged in, the Codex round-2
findings fixed, the gates green. The PR pins the go-qrdb OTA grants
([ota-image-keys-grant-pin.md](ota-image-keys-grant-pin.md)) and exports
the board public key on every transport
([ota-image-keys-public-export.md](ota-image-keys-public-export.md)).

1. Merge origin/main (signed merge commit, no conflicts).
2. Codex P1, ineffective integration test: `test(sdk)` rebuilds
   `test/integration/sdk/go/ota_image_key_integration_test.go` on the
   production `XKMSService` (software backend in memory, key-version store)
   and asserts the rotated version 2, the COSE_Key x, y and kid, and the
   64-byte r || s signature. It passed at once against the real service:
   the defect was the test double, not the export.
3. Codex P2, docs: api.md and engineering.md name every transport that
   carries the export (gRPC RPC, `transport.Client`, `xkmsctl`).
4. Codex P1, scope: the docs/SPEC.md ota-image-keys row now names the
   public-key export (trusted-firmware #104 requirement 10) so the row
   covers the surface this PR adds. Owner approval of that row text is
   for the coordinator; the export code stays.
5. Devcontainer image check (lint, gosec, build, test): reproduced with
   `make lint` and the touched packages' tests; fixed at the cause if red.
