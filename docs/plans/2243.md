# #2243: pull the toolchain and CI images from CI_IMAGE_REGISTRY (ruling 752)

The third server's CI pools are cut. Each job builds about 8 GB of toolchain and CI images on the host's Docker, and six concurrent jobs tripped the root-disk guard. Infra set `CI_IMAGE_REGISTRY` (LAN, plain HTTP, no auth) in the runner env of the third server's pools.

## Change

- `scripts/ci-registry.sh use` (every CI job takes its toolchain and integration image through it): when `CI_IMAGE_REGISTRY` is set, probe `http://$CI_IMAGE_REGISTRY/v2/` (5 s), `docker pull $CI_IMAGE_REGISTRY/<content tag>` (e.g. `go-xkms-toolchain:<hash>`) and tag it to the local content tag.
- On a miss, build (or pull main's digest from the forge) as now, then tag and `docker push` to the registry.
- `CI_IMAGE_REGISTRY` is read before any `GITHUB_SERVER_URL` logic.
- `scripts/in-toolchain-image.sh` builds no image, so it is unchanged. ci.yml's only direct build is the CLI image scanned by `trivy image`: the commit's own product image, not a CI image, so out of scope.

## Rules

- The tag is the existing content-hash tag (`make <family>-image`), so a pulled image matches the build byte for byte.
- A failed pull falls back to the build. A failed push is one log line. Neither turns the job red.
- The pull and the push are bounded by `CI_IMAGE_TIMEOUT` (default 900 s); a closed port fails the probe and the registry is not used.
- No credentials are used or logged.
- One outcome line per image: `pulled <ref> <digest>`, `miss, built and pushed <ref>`, or `miss, built, push failed`.
- When the variable is unset, nothing changes.

## Tests

## DS-9239 fallback (ruling 752, P1)

- A consumer never turns a job red because no image of main's can be had: every pull miss (CI_IMAGE_REGISTRY or the forge, after three attempts), an unset `CI_IMAGE_REGISTRY`, and an empty ref on a push to main (`CI_PUBLISH=true`) build the image on the runner.
- The ref checks still fail: a ref outside the forge's registry host or the publishing namespace, or one that is not a digest reference, is refused before any pull.
