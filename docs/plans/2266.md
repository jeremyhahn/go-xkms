# Plan: #2266 build the integration compose images once per Integration run

## Objective

`make integration-test` builds the softhsm, swtpm and xkms-server compose
images once per run. Its PKCS#11 suites start those prebuilt per-run tags
instead of running `up -d --build xkms-server` each time, which rebuilt all
three images in every suite (7-14 min each).

## Slices

   `integration-images` target builds the three services in one
   `$(DOCKER_COMPOSE) build`; `integration-test` runs it after
   `clean-test-containers`; `compose_up_xkms_server` takes its build flag
   only from `XKMS_SERVER_UP_BUILD` (default `--build`), which
   `integration-test` sets empty. `TestIntegrationTestRunsBootstrapFirst`
   asserts bootstrap is the first suite. (done)
2. Makefile: the `integration-images` target, the prerequisite, the
   target-specific `XKMS_SERVER_UP_BUILD :=` and the flag in
   `compose_up_xkms_server`. (done)
3. Finish PR #2362: the `Integration [integration image]` check failed with
   exit code 2 on 74b9d15a3. Fix its cause from the job log once it is
   available to the lane (the lane container has no Docker and no forge
   access, so it cannot run or read the job). Main (7826cdf4b) is merged
   in; a static review of the compose path (same project, per-run image
   tags, secrets and services as the old `up --build`) found no cause, so
   the fix waits for the job log or a CI rerun on the merged head. Main
   6957270447 (#2404, plan archive) merged in cleanly on 2026-11-24;
