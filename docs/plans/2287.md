# #2287 — login 500: the refresh-token store writes under the anonymous request context

## Objective

PIV/mTLS and WebAuthn login on a qrdb-backed xkmsd return 500 with
`auth/token: refresh store put failed: qrdb/auth: unauthenticated`. Login
routes are public, so the request context carries no identity, and
`QRDBRefreshStore` writes the go-qrdb KV with it. The refresh store's own
bookkeeping must run as the node's service principal
(`pkg/embeddednode/serviceprincipal`, via `Node.ServiceContext`).

## Slices (in order, one commit each)

1. test(auth): regression tests against an embedded, authenticating go-qrdb
   node configured with `serviceprincipal.Option()`:
   - `pkg/auth/token/store_servicectx_test.go`: `QRDBRefreshStore` with the
     binder saves, reads, rotates and revokes (family, subject) under a
     context with no identity; without the binder the put is refused as
     unauthenticated.
   - `pkg/api/rest/login_qrdb_test.go`: PIV/mTLS certificate login returns
     200 with a token pair, the access token authenticates
     `GET /api/v1/auth/me`, and `POST /api/v1/auth/refresh` rotates the
     refresh token; the WebAuthn finish step reaching Mint does the same.
   Both fail at 9a4449afb with the unauthenticated refresh-store error.
2. fix(auth): `token.CallContext` binder (`token.WithCallContext` option on
   `NewQRDBRefreshStore`, nil = caller context) applied in Save, Get,
   MarkRotated, RevokeFamily and RevokeBySubject; `rest.TokenIssuerParams`
   and `rest.HostConfig` gain `ServiceContext`; pkg/server passes
   `s.qrdbNode.ServiceContext`, apimodule passes its `WithServiceContext`
   binder.
3. fix(rest): debug log of the Mint error on the 500 path of the PIV and
   WebAuthn login handlers (error string, user and tenant only; no token
   material).
4. changelog: `.changelog/unreleased/fixed-2287-login-refresh-store.md`.

## Out of scope

- The service principal's grant (unchanged).
- Any other public-route qrdb call; if the refresh path's user re-check
  needs a permission the grant lacks, the lane stops and reports it.
