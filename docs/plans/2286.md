# Plan: #2286 web console UI prefix and build-web deps

## Objective

The xkms web console loads at /ui/ but every /ui/assets/* file fails, because
pkg/server passes a trailing-slash prefix ("/ui/") to apimodule.WithWebUI and
RegisterHTTP registers "/ui/" and "/ui//*". A clean `make build-web` also
fails, because sdk/ts/svelte-auth has no node_modules for its @go-xkms/sdk
devDependency.

## Slices (in order)

1. test(apimodule): TestModule_WithWebUI_TrailingSlashPrefix (module_extra_test.go)
   passes "/ui/" and routes the recorded handlers through chi: no pattern
   with "//", /ui/assets/app.js 200, /ui/ 200, /ui not 404, root redirect to "/ui".
2. fix(apimodule): WithWebUI trims one trailing slash from the prefix.
3. test(make): test/scripts/build-web-deps.test.sh checks that `make -n build-web`
   runs npm ci in sdk/ts/svelte-auth before the web/app build; registered in
   test-scripts.
4. fix(make): build-web runs npm ci in $(SVELTE_AUTH_DIR).
5. Changelog entry .changelog/unreleased/fixed-2286-ui-prefix.md.

## Out of scope

- #2286 item 3 (capabilities version).
- The prefix "/" (it trims to ""; behaviour unchanged).
