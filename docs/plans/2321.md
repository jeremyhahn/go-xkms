# Plan: row #2321 cli-protocol-matrix

## Objective

Every xkmsctl command family runs end to end over every SDK transport named
in docs/SPEC.md (cli-protocol-matrix): embedded, unix, gRPC, QUIC, REST, MCP.
The shared harness is `test/integration/api/commands` and
`TestAllCommandsAllProtocols` (`test/integration/api/protocol_parity_test.go`).

## Slices

- (a) **done** — MCP and embedded transports in the CLI matrix (ruling 1034 B).
  - `CLIProtocols()` yields unix, rest, grpc, quic, mcp, embedded.
  - `SkipReason` / `MatrixCellFor`: every skipped (family, transport) cell
    names its reason; `TestAllCommandsAllProtocols` logs each skipped cell.
  - Embedded runs pass one `--transport embedded` and the run's `--key-dir`.
  - `make integration-test-api-all` runs MCP.
  - Tests: `matrix_test.go` (unit, no Docker); the matrix itself in CI.
- (b) key, cert and TLS families: setup-dependent commands (key-info, sign,
  verify, delete, cert-info) run in the matrix with their setup steps.
- (c) sealing and TPM policy families: seal/unseal and tpm-policy-* with setup.
- (d) **done** — password, pin and piv families (ruling 1034 B).
  - `PasswordCommands`, `PINCommands`, `PIVCommands` in `commands/secrets.go`,
    in `AllCommands` and `CommandFamilies`; `SecretsSetupOrder` orders them.
  - `TestCLISecretsMatrix` (`cli_secrets_matrix_test.go`) runs each verb on
    all six transports after its setup; PIV uses the software backend.
  - Named skips: passkey unlock/enroll/recover (no FIDO2 key), recover when
    the vault predates the run, embedded password session (per-invocation
    server), PIV verbs a backend reports as needing a physical token.
  - Tests: `secrets_commands_test.go` (unit); the matrix itself in CI.
- (g) CA family: ca-sign-csr, ca-revoke, ca-status with setup.
- (e) FROST and FIDO2 families: dealer and participant workflows on every
  transport the family supports; FIDO2 cells name the hardware gap.
- (f) admin and user families: command definitions and their matrix cells.

Each slice removes the skip reasons it resolves; a slice is done when its
families' cells all run or carry a reason the SPEC row accepts.

## Out of scope

- New server or SDK protocol stacks (the SDK MCP client transport exists).
- docs/SPEC.md changes; CI workflow changes.
