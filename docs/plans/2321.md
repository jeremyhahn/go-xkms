# Plan: row #2321 cli-protocol-matrix

## Objective

Every xkmsctl command family runs end to end over every SDK transport named
in docs/SPEC.md (cli-protocol-matrix): embedded, unix, gRPC, QUIC, REST, MCP.
The shared harness is `test/integration/api/commands` and
`TestAllCommandsAllProtocols` (`test/integration/api/protocol_parity_test.go`).

## Slices

- (a) **done** — MCP and embedded transports in the CLI matrix (ruling 1034 B).
  - `CLIProtocols()` yields unix, rest, grpc, quic, mcp, embedded.
  - `SkipReason` / `MatrixCellFor`: every skipped (family, transport) cell
    names its reason; `TestAllCommandsAllProtocols` logs each skipped cell.
  - Embedded runs pass one `--transport embedded` and the run's `--key-dir`.
  - `make integration-test-api-all` runs MCP.
