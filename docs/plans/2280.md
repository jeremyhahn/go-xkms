# Plan: #2280 xkmsctl key decrypt defaults to RSA-OAEP SHA-256

## Objective

`xkmsctl key decrypt` uses RSA-OAEP with SHA-256 by default and takes a
`--padding` flag to pick the scheme explicitly; an unknown value is a usage
error. PR #2357 carries the work.

## Slices

1. Tests: `cmd/xkmsctl/key_decrypt_padding_test.go` (default OAEP SHA-256,
   `--padding` validation) and the embedded decrypt round trip in
   `cmd/xkmsctl/key_test.go` naming the RSA algorithm.
2. Fix: `cmd/xkmsctl/key.go` adds the flag and default; `cmd/xkmsctl/errors.go`
   adds the padding usage error.
3. Finish: merge current main into the branch (merge commit), re-run the
   `cmd/xkmsctl` unit tests and the xkmsctl integration target.
