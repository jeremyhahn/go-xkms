# Plan: #2280 xkmsctl key decrypt defaults to RSA-OAEP SHA-256

## Objective

`xkmsctl key decrypt` uses RSA-OAEP with SHA-256 by default and takes a
`--padding` flag (`oaep-sha256`, `pkcs1v15`, ...) that is validated before any
request is sent, so the CLI matches the server's default RSA decryption.

## Slices

   value is rejected (`cmd/xkmsctl/key_decrypt_padding_test.go`); the embedded
   decrypt round trip names the RSA algorithm (`cmd/xkmsctl/key_test.go`).
2. Fix: `--padding` flag and OAEP default in `cmd/xkmsctl/key.go`, the padding
   error in `cmd/xkmsctl/errors.go`.
3. Finish: merge main (which reverts #2355, the stderr error printing) and
   re-run `make test-xkmsctl`, `make test-sdk-go`, `make test-xkey`; the
   Integration tier (`make integration-test-cli`) runs in CI (needs Docker).
