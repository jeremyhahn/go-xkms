# Plan #2091: authz-device-onboarding (row docs/SPEC.md:54, PR #2114)

## Objective

`XKMSService.CreateUser` mints an activation invitation for an account created
with an email login key. An invitation is minted only for a caller allowed
go-qrdb's users:invite, decided on the caller's full identity, audited (allow
and deny, failing closed) on every host: xkmsd and the self-built
ServiceModule host.

## Slices (done)

1. users:invite in `CreateUser` (pkg/xkms/servicer_user.go): test
   servicer_user_invite_authz_test.go (create-only refused, no user left;
   create+invite minted; `WithoutEmailLoginKey` needs users:create only; no
   authorizer unchanged). Docs: docs/user-onboarding/engineering.md, changelog.
2. Transports: no route change (redemption is public; users:create stays the
   create gate). The refusal maps to REST 403, gRPC PermissionDenied, MCP
   ErrCodeForbidden: *_invite_authz_test.go in pkg/api/{rest,grpc,mcp}.
3. Self-built host (pkg/apimodule): `hostStores` wires the RBAC authorizer
   when the host sets none (`XKMSService.Authorizer`); a host with auth off
   sets `auth.NewAuthorizer(nil)`. Test module_host_invite_authz_test.go.
4. Full identity: `auth.NewNodeAuthorizer` decides on ScopePermissions
   (pkg/auth/authorize_scope_test.go); xkmsd uses it in
   `initializeAuthorization` (pkg/server/rbac_scope_permissions_test.go).
5. Audit: `CreateUser` decides through `authorizeAudited`; a failed write
   returns `AuditGateError` and creates nothing
   (servicer_user_invite_audit_test.go). pkg/server hands the service its
   sink; the self-built host uses the node's audit plane under the caller's
   context (tenant trail), and no sink when the node has no audit client
   (module_host_invite_audit_test.go).
6. Finish (draft > 6 h): main merged; this plan moved to docs/plans/2091.md
   and condensed. No code change.
