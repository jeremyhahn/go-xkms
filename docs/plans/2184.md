# Plan: SPEC row tpm-policies (#2184)

## Objective

Ship SPEC row `tpm-policies` (docs/SPEC.md): named, TPM-authorized policies
(PolicyAuthorize with NV-counter revocation) shared by keys and sealed objects,
`UpdatePolicy` from a signed CoRIM, `verify` reporting the approved branch on
every transport and in xkey and xkmsctl, the `.tpmpolicy` binding record and
its static `PolicyBindingResolver` exported through `sdk/go`. One row = one
branch `row/2184-tpm-policies` = one PR (CA ruling 573).

tests come with it and must pass here.

   tests of the touched packages and `make integration-test-<feature>`.

   per slice, oldest first. Tests: each PR's `web/app/test/*.test.ts`; shared
