# Plan: #2261 split the Devcontainer image job

## Objective

The CI `image` job ran lint, the go-xkms checks, gosec, build and
`make coverage` in one 240-minute job on one runner, although only coverage
needs the 24 GB container (#2063). Split it into three jobs with the same
permissions, env, setup and tear-down (rulings 833-835).

## Slices

1. Tests first (`internal/buildgates`): pin the split.
   - `ci_sched_devcontainer_test.go`: no `image` job; `lint` and
     `image-build` hosted (ubuntu-latest), `coverage` on the runner_docker
     routing; each needs preflight and ci-images; coverage needs
     image-build with no status function in its `if:` (#2240); lint and
     image-build time out within 120 min and below coverage.
   - `ci_gate_test.go`: CI Gate code tier (verdict run, not docs-only).
   - `ci_image_digest_test.go`: revert hits lint first; consumer floor
     rises by the two new toolchain jobs.
2. Workflow (`.github/workflows/ci.yml`):
   - `lint` (hosted, 90 min): make lint, go-xkms checks, make gosec,
     docs-only releasability test; runs on docs-only PRs; Gate tier pr.
   - `image-build` (hosted, 90 min): build-tag assertion and make build;
     skips on docs-only PRs; tier code.
   - `coverage` (runner_docker, 150 min): make coverage; needs
     image-build; tier code.
   - CI Gate needs lint, image-build and coverage instead of image.
3. Finish: merge origin/main (merge commit), `make test-buildgates` green.

## Out of scope

- Runner pool sizing and template selection changes (#2346).
- Any change to what coverage, lint or build run.
