## Before the fold (why the cluster default was open)

go-qrdb `config.AuthConfig.ClusterTrustDomain` is the trust domain of
cluster-peer node identities (`spiffe://<td>/node/<raftAddress>`, pinned by
`clusterkeys.Receiver`/`Sender`) and the tenant principals' trust domain when
`SPIFFETrustDomain` is empty; empty means `"qrdb.cluster"`. go-xkms never set
it, so xkms node SANs (`spiffe://xkms.cluster/node/...`) and qrdb's peer pin
(`qrdb.cluster`) disagreed.
