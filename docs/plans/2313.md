# Plan: issue #2313, MCP port 9444 everywhere

## Objective

The shipped configs, the config defaults, every deployment caller and the SDK
use one MCP port: the SDK default 9444.

## Slices

1. Shipped configs and config defaults (done, PR #2356).
   - Test: `pkg/config/mcp_port_test.go` checks the defaults, the five shipped
     configs and a load with `mcp_port` omitted against the SDK default.
2. Devcontainer stack (Codex P1 on PR #2356, round 1).
   - `build/docker/devcontainer/compose.yaml` points `KEYSTORE_MCP_ADDR` at
     `xkms-server:9444` and publishes the host MCP port to container port 9444.
   - Test: `TestMCPPort_DevcontainerComposeMatchesSDK` in the same file reads
     the compose file and checks both references against the SDK default.

## Out of scope

- Changing the SDK default itself.
- Other transports' ports.
