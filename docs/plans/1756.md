# Plan: #1756 ssh DialClient cancel closes the connection

Row: ssh-dialclient-cancel. Branch `row/1756-ssh-dialclient-cancel`, PR #2170.

## Objective

`session.DialClient` must stop the SSH handshake as soon as its context
ends, not only when `Timeout` expires. Before this row, a context cancelled
without a deadline (or before it) left `ssh.NewClientConn` blocked on the
socket until the dial timeout.

## Slices

1. Fix (865dbc9df, done): `pkg/ssh/session/dial.go` registers a
   `context.AfterFunc` that closes the socket the moment the context ends,
   which unblocks `ssh.NewClientConn` at once. If the handshake wins the
   race against the cancel, the client is closed and the call returns a
   `TimeoutError`; it never returns a client with a closed socket.
   `closeAfterFailedHandshake` drops `net.ErrClosed` and returns any other
   close error.
   Tests in `pkg/ssh/session/dial_gaps_test.go`:
   - `TestDialClient_InputGuards`, `TestDialClient_DialError`,
     `TestDialClient_Timeout`, `TestDialClient_HandshakeError`
   - `TestDialClient_CancelDuringHandshakeClosesConn`
   - `TestCloseAfterFailedHandshake_DropsErrClosed`,
     `TestCloseAfterFailedHandshake_ReturnsOtherCloseErrors`
2. Verify-ready pass (this commit): tests and lint re-run on the row tip,
   with no code change needed.
