# Row #2186: authz-token-perms

SPEC row `authz-token-perms` (docs/SPEC.md), parent `authz-tenant-iam`.

## Objective

`pkg/acme/auth.TokenClaims.Permissions` carries a permissions list in ACME
admin tokens that no authorization decision reads; decisions come from
`qrdbsdk.Authorizer`. The field and its copy on refresh in `MemoryClient`
go, and the row is marked shipped in docs/SPEC.md.

     with `"permissions"` decodes and re-encodes without that key, and a
