# #2250: main a4d3c0924 red: unix socket paths exceed sun_path

Main-fix lane aq2250 (ruling 742: fix forward). Base main a4d3c0924.

## Objective

Race Detector and Nested Module Tests (run 44019644959) fail with
`bind: invalid argument`. Socket paths under the self-hosted runner's
/home/runner/_work/_temp plus long test names go past the 108-byte sun_path.
The tests must pass when TMPDIR and GOTMPDIR are both longer than 90 bytes.

## Slices

1. The #2248 work (PR #2249, branch row/2248-race-short-socket-dirs)
   cherry-picked: internal/testtmp.Short and its test; testmain_test.go in
   cmd/xkmsctl, cmd/xkmsd, pkg/api/unix, pkg/server, pkg/ssh/agent,
   pkg/ssh/connect; xkey/cmd/xkey/cmd shortTMPDIR copy, its TestMain and
   test. See docs/plans/2248.md.
2. GOTMPDIR (Codex P1 on 3cd1d15fa): t.TempDir prefers GOTMPDIR, so both
   helpers set and restore TMPDIR and GOTMPDIR. New tests bind under a deep
   GOTMPDIR; they fail without the change.
3. sdk/go/client/ssh: TestMain with a module-local shortTMPDIR (sdk/go cannot
   import internal/), plus its tests. Without it,
   TestStartAgent_SocketDirServesAnotherWorkingDirectory fails under a deep
   TMPDIR.

bytes>: `go test -race -tags "$T"` passes on the six root packages,
xkey ./cmd/xkey/cmd/... and sdk/go ./client/ssh/...
