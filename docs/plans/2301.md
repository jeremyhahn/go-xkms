# 2301: WebAuthn browser registration answers 500 (red main Integration)

## Objective

`make integration-test-webauthn-browser` fails: every registration answers
`500 internal_error`. Cause: the WebAuthn relying party's qrdb user store
calls the node's `Users()` client on the request context. The ceremony is
unauthenticated and the embedded node enforces authentication, so qrdb
refuses with `qrdb/auth: unauthenticated: no valid credentials provided`.
The datastore's DAO calls already run as the node's service principal
(`datastore.WithCallContext(node.ServiceContext)`); the user calls did not.

## Slices

1. test(webauthn): `pkg/server` test boots a standalone qrdb node with the
   service principal, builds the WebAuthn service with
   `initializeWebAuthnService` and runs begin + finish over HTTP with the
   software authenticator; asserts success and a token. Fails with the 500.
2. fix(webauthn): the qrdb user store takes a call-context binder
   (`QRDBUserStoreOptions.CallContext`, `WebAuthnServiceParams.CallContext`);
   xkmsd passes the datastore's binder (`Datastore.CallContext`). The
   handler logs the cause of an internal error at Error level.

## Out of scope

- `webauthn.allow_public_registration` (r979).
- Playwright specs, workflows, SPEC.
- The integration target itself needs Docker (CI runs it).
