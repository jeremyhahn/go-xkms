# Row 1719: xkey local.verifyUser (with #1712)

## Objective

Ship the ruling-180 `local.verifyUser` verifier in xkey: a local user
verification step whose refusals carry distinct, typed codes end to end
(pairingproto wire codes, error-registry rows, SDK and CLI), so a client can
tell a dismissed phone prompt, an unloadable trust store and a real UV
failure apart. A dismissed prompt or an unloadable trust spends no UV retry.
