# #2405 Phone protocol: ML-DSA keys from the phone

## Objective

The phone app generates ML-DSA-44/65/87 keys (COSE -48, -49, -50),
software or hardware backed (xkey-android#339). The desktop side speaks it:

- `local.generateKey` accepts `ML-DSA-44`, `ML-DSA-65`, `ML-DSA-87` and an
  optional `keyBacking` (`hardware` | `software`; absent = the phone picks).
- `local.getCapabilities` lists the ML-DSA names among the supported
  algorithms and adds `hardwareAlgorithms`.
- `local.getPublicKey` returns an X.509 SubjectPublicKeyInfo for ML-DSA;
  `local.sign` signs pure ML-DSA (the message, not a digest).
