# Plan: #2282 ACME order finalize commit hooks

## Objective

TCG CSR (and standard x509) order finalize hooks must not leave consumer
state behind for a certificate that is never delivered. Finalize hooks stage
state before persistence; commit hooks run after the certificate and order
saves, told whether they succeeded, and commit or undo the staged state.

## Slices

1. Commit hook registry and wiring (done, PR #2354).
   - OrderFinalizeCommitHook / registry in hooks.go, Params and SDK exports.
   - sendFinalizeResponse runs the commit hooks after the saves, with the
     save error on a certificate or order save failure.
   - Tests: TCG success, certificate save failure, order save failure,
     standard success (order_finalize_commit_hook_test.go).
2. Codex round 1 (this slice).
   - Commit hooks also run with the error when a finalize hook vetoes
     issuance (TCG and standard paths) or the TCG path aborts after the hooks.
   - Tests: staging hook followed by a vetoing hook, TCG and standard.
   - The commit hook test file carries the codec_json build constraint of
     the helpers it uses.

## Out of scope

- Consumers (go-trusted-platform) adopting the commit hook.
- Changing the response when a commit hook runs; hooks cannot alter it.
