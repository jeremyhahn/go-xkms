# Plan: row #1755, SSH remote signers as ssh.AlgorithmSigner (RFC 8332)

## Objective

Remote SSH signers (gRPC, MCP, REST clients in sdk/go/client/ssh) implement
`ssh.AlgorithmSigner` and send the requested signature algorithm to the
server, so an RSA key held by the server signs with `rsa-sha2-256` or
`rsa-sha2-512` instead of the SHA-1 `ssh-rsa` default. Servers that accept
only SHA-2 RSA signatures (OpenSSH 8.8+) then accept these keys.
