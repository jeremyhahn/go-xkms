# Plan: xkmsctl prints command errors and a usage hint (#2279)

## Objective

xkmsctl exits 1 with no output on flag, argument and RunE errors, because
rootCmd sets SilenceErrors and SilenceUsage and main discards the error.
Every returned error is printed to stderr as `Error: <err>`; usage errors
(unknown flags, bad arguments, missing required flags, flag-group
conflicts) also get `Run '<command path> --help' for usage.`.

## Slices

1. test(xkmsctl): `cmd/xkmsctl/exec_errors_test.go` drives `run` with an
   unknown flag, bad arguments, a missing required flag and a RunE error,
   and checks the stderr text and exit code.
2. fix(xkmsctl): `run(args, stderr) int` in `cmd/xkmsctl/root.go` executes
   rootCmd, prints the error, and adds the hint while
   `commandStarted` is false; rootCmd.PersistentPreRunE validates required
   flags and flag groups before it sets `commandStarted`. `main` exits
   with `run`'s code.
3. Merge main; finish the PR's red `Integration [integration image]`
   check (needs Docker and the CI log; not reproducible in a lane).

## Out of scope

- Changing commands that print and exit through `handleError`.
- Subcommands with their own PersistentPreRunE (they keep Cobra's own
  required-flag checks; runtime errors there also get the hint).
