# Plan: SPEC row authz-xkey-uid0 (#2188)

Row: `authz-xkey-uid0` (docs/SPEC.md); one row = one branch = one PR.

## Objective

xkey authorizes audit reads over go-qrdb's identity and RBAC through
go-xkms `sdk/go`'s go-qrdb re-export, writes its audit events to go-qrdb's
audit store, and keeps no local authorizer. The uid-0 `IsAdmin` is already
gone (#1605).
