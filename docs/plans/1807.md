# Plan: SPEC row #1807 ssh-keys

## Objective (issue #1807)

A key held by xkms and used through a remote signer (REST, MCP or gRPC SDK
client) must authenticate to a modern OpenSSH server. Remote signers implement
`ssh.AlgorithmSigner` and carry the requested signature algorithm over the
wire, so an RSA key signs with `rsa-sha2-256` or `rsa-sha2-512` (RFC 8332)
and never falls back to SHA-1 `ssh-rsa`.

## Proving test

`TestRemoteSigner_RSAAuthenticatesWithSHA2`
(`pkg/api/rest/ssh_handlers_test/remote_signer_rfc8332_test.go`): an RSA key
from a remote signer authenticates to an in-process `x/crypto/ssh` server
that accepts only the SHA-2 public-key algorithms.
