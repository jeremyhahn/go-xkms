# Row enrolment-imx95-e2e (#2258): enrolment against the i.MX 95 board

Objective: prove device enrolment end to end from a lab node against the
xkmsd that runs on the board (main f422814e9; software and pkcs8 backends;
passphrase barrier; mTLS admin), through to an issued certificate.

Script: `test/e2e/enrolment-imx95.sh` (BOARD=host:port of the API listener;
optional ACME_DIR, ACME_CLIENT, WORK, STRICT=1). It runs the steps that
work, prints `OK step N`, `GAP step N: <call> -> <answer>` or `NOT REACHED`,
and exits 0 at a recorded gap (1 only when the board is unreachable).

Out of scope for this lane: any fix, any change on the board, init,
credentials. Known defects #2252-#2257 are filed and not fixed here.
