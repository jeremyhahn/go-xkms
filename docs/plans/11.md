# Epic 11: releasability, public module resolution (PR #2028, DS-7983)

## Objective

A public checkout resolves go-xkms's modules through proxy.golang.org and
sum.golang.org: no build file names an in-house module in GOPRIVATE,
GONOSUMDB, GONOPROXY or GOINSECURE, under any variable name, with or without
module credentials. check-public-literals.sh reads its rules from
RELEASABILITY_PATTERNS, never from the tree.

## Slices

1. Done (rel7983, rel11): the RELEASABILITY_PATTERNS parse in
   check-public-literals.sh with its script tests; the public GOPRIVATE default
   for a checkout with no credentials; buildgates/goprivate_test.go.
2. Codex P1 on a77f8f575 (this slice): main's #2057 merge put the in-house
   default back behind GOMODAUTH_GOPRIVATE_DEFAULT and a `${GITEA_HOST:+...}`
   compose fallback.
   - Tests first: goprivate_test.go matches every GO*PRIVATE / NOSUMDB /

   - Fix: Makefile passes $(GOPRIVATE) in every branch; every compose file's
     GOPRIVATE becomes `${GOMODAUTH_GOPRIVATE:-${GOPRIVATE:-}}`; changelog.
